# 自治体（高齢者支援部署）向け 企画提案書

**対象**: 市区町村の高齢者支援課／長寿福祉課／社会福祉協議会／地域包括支援センター（自治体直営）
**用途**: 行政企画提案・地域連携協定の打診・公益事業協力の打診

## 1. はじめに

### 1.1 提案の趣旨

近年、高齢化の進展に伴い、終活への関心が広く高まる一方、ご自身の人生を「形」として遺す手段は限られています。当事業者は、AI 技術と専門編集者の力を組み合わせ、わずか 10 枚程度の写真から自分史ムービーを制作するサービス **「人生タイムラプス」** を提供しています。

本提案は、〔自治体名〕様の高齢者支援事業の一環として、以下のような協力体制をご検討いただきたく、ご案内申し上げます。

- **無料体験イベントの共催**
- **モニター制作の提供**（無償または特別価格）
- **地域包括支援センター・社協への情報提供協力**

---

## 2. 提案の背景

### 2.1 高齢者の方々が抱える課題

- 「人生を振り返り、家族に何かを遺したい」という気持ちはあるが、**具体的な手段がわからない**
- 写真は持っていても、**整理・活用ができない**
- 自分史を書く ＝ ハードルが高い／時間がかかる
- 大手企業のサービスは**敷居が高く、価格も高い**（35 万円超のケースもあり）

### 2.2 行政としての関心領域

- **健康寿命の延伸**（自分の人生を振り返ることのウェルビーイング効果）
- **孤独・孤立の予防**（家族との会話・対話機会の創出）
- **地域コミュニティの活性化**（地域の歴史継承への寄与）
- **介護予防**（活動的な時間の確保）

### 2.3 当事業との接点

「人生タイムラプス」は、上記の課題・関心領域に対し、以下の角度で貢献できます。

| 行政の関心領域 | 当事業の貢献 |
| --- | --- |
| 健康寿命延伸 | 人生の意味づけによる QOL 向上 |
| 孤独・孤立予防 | 家族との写真整理を通じた対話機会 |
| 地域コミュニティ活性化 | 地域の歴史を映像で記録（個人史 → 地域史） |
| 介護予防 | アルバム整理という認知活動の促進 |
| 終活支援 | エンディングノートと並ぶ新しい終活手段 |

## 3. ご提案する協力モデル

### 3.1 モデル A：**無料体験イベントの共催**

```
イベント名：「あなたの人生を、動画で遺す」
                  〜 終活カフェ 特別企画 〜

日時：例）月 1 回・2 時間
場所：地域包括支援センター・公民館・福祉センター 等
対象：地域の高齢者・そのご家族
定員：20〜30 名／回

プログラム例：
　0〜15 分　：自治体担当者様のご挨拶／趣旨説明
　15〜45 分 ：当事業者によるサービス説明・サンプル動画上映
　45〜90 分 ：参加者ワークショップ
　　　　　　・「人生で大切な節目」を書き出す
　　　　　　・写真を持参いただき、テーブルで整理体験
　90〜120 分：個別相談・質疑応答
```

**当事業者の費用負担**：講師料・資料代・サンプル動画上映費すべて無料
**自治体様の費用負担**：会場費・広報費のみ

---

### 3.2 モデル B：**モニター制作の無償提供**

地域の高齢者の方の中から、〔10 名〕程度のモニター参加者を募集いただき、無償または特別価格で人生タイムラプスを制作するモデルです。

| 項目 | 内容 |
| --- | --- |
| 対象者 | 自治体様にて選定（経済的事情等を考慮可） |
| 制作内容 | スタンダードプラン相当（通常 39,800 円） |
| 提供価格 | 無償または 5,000 円（実費・郵送料相当） |
| 制作本数 | 10 本（年間） |
| 引換条件 | 完成動画を**地域の事例として活用可能**（個人情報保護に配慮した形で） |

**当事業者のメリット**：実績・事例の蓄積、社会貢献としての PR
**自治体様のメリット**：住民サービスの拡充、メディア・議会への報告事例

---

### 3.3 モデル C：**情報提供協力**

地域包括支援センターや高齢者相談窓口でのご案内協力です。

| 内容 |
| --- |
| パンフレット・チラシの設置（無料配布） |
| ご相談された高齢者・ご家族への情報提供 |
| 定期的なサンプル動画の更新提供 |

**当事業者から自治体様への対価**：なし（社会貢献として）
**自治体様の費用負担**：パンフレット設置スペースのみ

---

### 3.4 モデル D：**地域史アーカイブ事業への連携**

地域の高齢の方々の写真と人生をまとめ、**地域の歴史アーカイブ**として活用する事業の連携モデルです。

```
例：「〇〇町の歴史を、町民 100 人の人生でつづる」
      アーカイブ事業

・町内の高齢者 100 名にご協力いただき、自分史動画を制作
・全動画を町立図書館・公民館でアーカイブとして公開
・町の歴史教育・地域学習資料として活用
```

**当事業者の役割**：制作技術提供、ディスカウント価格での制作
**自治体様の役割**：参加者募集、予算確保、公開運営

## 5. プライバシー・倫理面への配慮

公的事業として実施する場合、特に以下に配慮します。

| 配慮事項 | 内容 |
| --- | --- |
| 個人情報保護 | 個人情報保護法に基づく厳重管理／自治体個人情報保護条例にも準拠 |
| 同意の取得 | 制作・公開・事例利用すべてに書面同意を取得 |
| 高齢者保護 | 認知症リスク等、判断能力への配慮、ご家族の同席推奨 |
| AI 倫理 | AI 補完オプションは公的事業では原則使用しない（実写のみ） |
| 経済的弱者への配慮 | 無償・低額枠の設定で利用しやすく |

# 自治体アプローチの実務メモ

### 1. アプローチ先の優先順位

| 部署 | アプローチ難易度 | 反応速度 |
| --- | --- | --- |
| 地域包括支援センター（自治体直営） | 低 | 速い |
| 高齢者支援課・長寿福祉課 | 中 | 中 |
| 社会福祉協議会 | 低〜中 | 速い |
| 市民相談課 | 低 | 速い |
| 議会対応の必要な大型企画 | 高 | 遅い |

→ **まずは地域包括支援センター・社協** から始めるのが現実的

### 2. 提案時の注意点

- **「営業」ではなく「協力事業」のトーン**
- スーツ姿、名刺持参、A4 紙提案書（電子データより紙が好まれる傾向）
- 担当者・係長・課長と段階的に話を進める（即決はほぼない）
- 予算化の意思決定は前年度（12〜2 月頃）に集中するため、それを意識したスケジュール

### 3. 提案後のフォロー

- 1 週間後にお礼メール
- 2 週間後に進捗確認の電話（自治体側からは可）
- 1 ヶ月反応がなければ、別のアプローチに切り替える

### 4. 競合・先行事例の調査
- 全国でも「自治体 × AI 自分史動画」の事例はまだ少ない（差別化の好機）
- 似た取り組み：自治体の「写真展」「地域回顧プロジェクト」「人生 100 年セミナー」等
- これらの事業を補完・進化させる位置づけで提案
