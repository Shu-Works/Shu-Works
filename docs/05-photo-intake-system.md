## 2. ツール選定

### 2.1 アップロード受付：**Google Drive（共有フォルダ）** ＋ 案件別サブフォルダ

**選定理由**：
- 月額 0 円（既存の Google アカウントで運用可、容量増は Google One 月 250 円〜）
- 大容量対応（1 ファイル最大 5 TB）
- SSL 暗号化・Google のセキュリティ
- スマホからもアップロード可能
- お客様側にアカウント不要（リンク 1 つで完結）

**代替案**：

| サービス | 月額 | 特徴 | 採否 |
| --- | --- | --- | --- |
| **Dropbox File Request** | 約 1,500 円 | 案件別 URL を発行できて綺麗 | △ コスト高 |
| **WeTransfer** | 無料〜 | リンク 7 日間で消える／高齢者には簡単 | △ 期限が短い |
| **ギガファイル便** | 無料 | 国産・知名度高い／広告表示が多い | △ 信頼感に難 |
| **Filestack / Uploadcare** | 月 約 7,000 円〜 | サイト埋め込み可・プログラム的に扱える | △ オーバースペック |
| **Google Drive 共有フォルダ** | 無料 | 案件別フォルダ・期限なし・モバイル対応 | ◎ 採用 |

### 2.2 案件管理：**Notion**

**選定理由**：
- 月額 0 円（個人プラン）または 1,650 円/月（プラスプラン）
- データベース機能で案件ステータス・写真枚数・納期を一元管理
- メールテンプレ・チェックリスト・お客様情報を同じ場所に保管
- スマホアプリで本業の合間にも進捗確認可能

**代替案**：

| ツール | 月額 | 特徴 | 採否 |
| --- | --- | --- | --- |
| **Airtable** | 無料〜 | データベース志向で見やすい | ○ 次点 |
| **Google スプレッドシート** | 無料 | 一番シンプル | ○ ミニマム構成 |
| **kintone** | 1,500 円〜 | 国産・本格的 | △ 単独運用には重い |
| **Notion** | 無料〜 | DB ＋ メモ ＋ ファイル ＋ アプリ | ◎ 採用 |

### 2.3 メール送信：**Gmail（テンプレ機能 / 返信定型文）**

- 普段使いの Gmail でテンプレート機能を有効化
- お客様への返信は手動だが、テンプレ呼び出しで秒で送信可能
- 大量送信時は **Mailchimp 無料プラン** や **Notion → Make.com → Gmail** で自動化も可能（後日検討）

### 2.4 ファイル送付・納品：**Google Drive** ＋ **物理メディア（DVD/Blu-ray/USB）**

- 完成動画は案件専用フォルダ内に納品リンクを生成
- 物理メディア希望者には**ヤマト宅急便コンパクト**で発送（追跡可・補償あり）

## 3. 案件 ID 体系

```
JT - 2026 - 0001
│    │       │
│    │       └─ 連番（年内通算）
│    └─ 年（西暦）
└─ Jinsei Timelapse の頭文字
```

例：`JT-2026-0042`

**用途**：
- メールの件名先頭に必ず付与（追跡しやすく）
- Google Drive フォルダ名にも付与（`JT-2026-0001_山田太郎様`）
- Notion カードのプライマリキーとして使用

## 4. Google Drive のフォルダ構造

```
人生タイムラプス 案件管理/
├── 00_テンプレート/
│   ├── _案件フォルダ雛形/
│   │   ├── 01_受領写真_デジタル/
│   │   ├── 02_受領写真_郵送スキャン/
│   │   ├── 03_デジタル化補正後/
│   │   ├── 04_AI生成シーン/
│   │   ├── 05_編集中/
│   │   ├── 06_納品ファイル/
│   │   └── 07_お客様共有/
│   └── お客様送付資料/
│       ├── 写真送付ガイド.pdf
│       └── 同意書類.pdf
├── JT-2026-0001_山田太郎様/
│   └── （上記の構造）
├── JT-2026-0002_佐藤花子様/
└── ...
```

**お客様への共有方法**：
- `07_お客様共有/` フォルダのみを「リンクを知っている人全員」で共有
- 完成動画とアップロード用サブフォルダを設置
- お客様には共有フォルダ URL のみを送信（他の案件にはアクセス不可）

### お客様用アップロード用サブフォルダの作り方

`07_お客様共有/` 内に `アップロードはこちら/` フォルダを作成し、共有設定：

| 設定項目 | 値 |
| --- | --- |
| アクセス | リンクを知っている人 |
| 役割 | **編集者**（ファイル追加可能、他ファイル閲覧不可にするためサブフォルダ専用） |
| 有効期限 | 受領完了後に「閲覧者」へ降格、または共有解除 |

## 5. セキュリティ・プライバシー対策

| 項目 | 対策 |
| --- | --- |
| データ漏洩 | Google Drive 二段階認証必須／業務用 Google アカウントで個人用と分離 |
| 共有ミス | 案件フォルダ単位での共有徹底／全体共有・組織内共有は使わない |
| アクセスログ | Google Workspace 利用時は監査ログを定期確認（個人プランでは不可） |
| バックアップ | 重要な原本写真スキャンは外部 HDD に月次バックアップ |
| 削除タイミング | プライバシーポリシーに基づき、納品 90 日後にデジタルデータ削除 |
| 端末紛失 | スマホ・PC は OS レベルで端末暗号化 ＋ リモートワイプ設定 |
