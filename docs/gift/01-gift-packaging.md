## 3. 和紙メッセージカード デザイン（5 種類）

各カードのテンプレートを Canva / Illustrator で作成し、お客様が選択。

### カード 1：「**寿**」シンプル
```
表面：「寿」の墨字（中央）
裏面：メッセージ欄（10 行）
色：白和紙＋金縁
サイズ：B5 二つ折り（210×148mm 折り後）
```
用途：すべての長寿祝いに使える定番

### カード 2：「**還暦・赤**」
```
表面：紅葉のイラスト＋「還暦御祝」
裏面：メッセージ欄
色：白和紙＋朱色装飾
```
用途：60 歳還暦専用

### カード 3：「**喜寿・古希・卒寿・紫**」
```
表面：紫陽花のイラスト＋年齢別タイトル
裏面：メッセージ欄
色：白和紙＋紫色装飾
```
用途：70 代・90 歳

### カード 4：「**米寿・傘寿・金茶**」
```
表面：稲穂のイラスト＋「米寿（または傘寿）御祝」
裏面：メッセージ欄
色：白和紙＋金茶装飾
```
用途：80 歳・88 歳

### カード 5：「**敬老の日・父の日・母の日**」
```
表面：季節の花（カーネーション・あじさい・コスモス等）
裏面：メッセージ欄
色：それぞれの行事に合わせた色味
```
用途：年中行事

## 4. メッセージ文例集（お客様提案用）

お客様が文章に悩まれることが多いため、文例を提案できるようにしておく。

### 還暦（60 歳）

```
例 1：
お父さん、還暦おめでとうございます。
これまでの 60 年間、本当にありがとう。
これからもお父さんらしく、健やかにお過ごしください。
                                  ○○より

例 2：
60 年、お疲れさま。
私たちがいるのは、お父さんとお母さんのおかげです。
これからも家族みんなで、楽しい時間を重ねていきましょう。
```

### 古希・喜寿（70 代）

```
例 1：
おじいちゃん、古希のお祝いに心を込めて。
おじいちゃんの人生を、家族みんなで振り返れる動画です。
これからも長生きしてください。
```

### 米寿（88 歳）

```
例 1：
88 年間、本当にお疲れさまでした。
お母さんが歩んでこられた道のりは、私たち家族の宝物です。
ありがとう。これからもどうぞお元気で。
                       ○○家一同
```

### 父の日・母の日

```
例：
いつも本当にありがとう。
言葉では伝えきれない感謝を、動画にしました。
これからも、長く長く、元気でいてください。
```

### 敬老の日（孫から）

```
例：
じいじ、ばあば、いつもありがとう。
じいじとばあばの人生を、家族で観られる動画ができたよ。
ずっとずっと元気でいてね。
                          孫一同
```

## 5. 包装・梱包の標準オペレーション

### 梱包作業の手順（プレミアムの場合）

```
1. DVD のレーベル印刷
   ・テンプレ：和紙風背景＋お祝い年＋お名前
   ・タイトル「○○ ○○様の歩み」
   ・小さく「人生タイムラプス」ロゴ

2. DVD ケースに収納
   ・透明プラケース or 紙ジャケット

3. 桐箱の中にクッション材を敷く
   ・薄い和紙、防湿シート

4. DVD ケースを桐箱に納める

5. メッセージカードを上に重ねる
   ・和紙風カードの場合は丁寧に折る

6. 桐箱を風呂敷風包装紙で包む

7. 発送箱に詰める
   ・割れ物注意のシール
   ・「のし」相当の宛名タグを外側に
```

### 所要時間：約 15〜20 分／件

### 必要な備品
- 桐箱（小・中、各サイズ常備）
- DVD 用ジャケット（白無地・パターン入り）
- 和紙メッセージカード（5 種類×20 枚）
- 風呂敷風包装紙
- 緩衝材
- 発送用クラフト箱（DVD サイズ用）
- 「メモリアル」シール（外装用）
- 宛名タグ

## 6. 配送方法

### 通常便（プレミアム）
- ヤマト宅急便コンパクト or ゆうパック
- 追跡可能・到着日指定可
- 料金：800〜1,000 円（プラン料金内）

### お祝い日指定便（プレミアムプラス）
- お祝い当日午前中着で時間指定
- 在宅確認の電話なし（プライバシー配慮）
- 「不在時持ち戻り」設定で、置き配は避ける

### 海外配送（ご親族が海外在住の場合）
- 個別見積もり（EMS 利用）
- 別途追加料金 3,000〜10,000 円

## 7. のし・水引のご対応

伝統的な「のし」付きをご希望のお客様向け：

| ご要望 | 対応 |
| --- | --- |
| 紅白蝶結び（一般的なお祝い） | デフォルト提供（無料） |
| 紅白結び切り（一回限りのお祝い） | 古希・米寿等で選択可 |
| 表書きの記載 | 「祝 還暦」「御祝」「寿」等から選択 |
| 内のし（包装紙の内側） | デフォルト |
| 外のし（包装紙の外側） | お祝い感を強調したい場合 |

実装は印字されたシール対応で十分（伝統的な水引現物は別注扱い）
