## 2. テンプレート構造

### タイムライン構成（DaVinci Resolve）

```
Track 5：字幕（チャプター字幕「○歳 七五三」など）
Track 4：演出（memory マーク、フレーム枠、ロゴ）
Track 3：BGM
Track 2：効果音（必要時）
Track 1：映像（写真静止 + AI 補間 + Memory Fill）
```

### 全体の流れ（テンプレート）

```
00:00 [オープニング ロゴ + 「人生タイムラプス」タイトル] 3 秒
00:03 [タイトルカード「○○様の人生」] 3 秒
00:06 [写真 1（幼少期）] + [字幕「○歳 ○○」] 4 秒
00:10 [AI 補間 写真1→2] 5 秒
00:15 [写真 2] + [字幕] 4 秒
00:19 [AI 補間 写真2→3] 5 秒
...
最後 [写真 N（最近）] 6 秒
+10  [エンディング「人生タイムラプス」ロゴ] 3 秒
+13  [全 ○分○秒]
```

### 計算式

```
動画尺 = 写真枚数 × (静止 4 秒 + 補間 5 秒) + オープニング 6 秒 + エンディング 3 秒
       ＝ 写真枚数 × 9 + 9 秒

例：
20 枚 → 20 × 9 + 9 = 189 秒（約 3:09）→ スタンダードプラン
30 枚 → 30 × 9 + 9 = 279 秒（約 4:39）→ プレミアム下限
```

→ 想定動画尺に合わせて、写真静止時間を 3〜6 秒で調整

## 4. BGM 配置

### 楽曲選定（Audiostock より）

| プラン | 楽曲構成 |
| --- | --- |
| ライト | 1 曲（3 分） |
| スタンダード | 1〜2 曲（7 分 / 切替で表情変化） |
| プレミアム | 2〜3 曲（12 分 / 章別に表情変化） |

### 章ごとの楽曲表情案

```
幼少期 → 学童期：     しっとり ピアノ
青春期 → 結婚：       明るく リズミカル
子育て期 → 中年：     温かい オーケストラ
老年期 → 現在：       荘厳 弦楽四重奏
```

### 音量調整
- BGM：-18dB から -20dB（聞き取りやすく）
- 字幕表示時に少し下げる（-22dB）：注目を字幕に
- ナレーション併用時：BGM を -26dB まで下げる

## 5. オープニング・エンディングテンプレート

### オープニング（3 秒）

```
背景：和の茶系グラデーション（#8a6240 → #c89b6a）
要素：
  ・「人生タイムラプス」 ロゴ（中央）
  ・「あなたの歩んできた道のりを」のサブコピー
  ・優しいフェードイン
BGM：本編冒頭の楽曲を 3 秒前から先取り
```

### タイトルカード（3 秒）

```
背景：白和紙風テクスチャ
要素：
  ・「〇〇 〇〇様の歩み」
  ・〔生年〕年生まれ
フォント：明朝体・大きめ
```

### エンディング（3 秒）

```
背景：和の茶系
要素：
  ・「人生タイムラプス」ロゴ
  ・「ご視聴ありがとうございました」
  ・小さく当社情報・案件番号
```

### テンプレート作成方針
- DaVinci Resolve の **「Compound Clip」** または **「Power Bin」** で再利用可能化
- 案件ごとに名前を差し替えるだけで使い回せるように

## 6. 編集作業の標準フロー

### 6.1 素材取込（15 分）

```
1. DaVinci Resolve でテンプレートプロジェクトを開き、新規プロジェクト名「JT-2026-XXXX」で保存
2. Media Pool に下記をインポート：
   - 03_デジタル化補正後/ の写真すべて
   - 04_AI生成シーン/ の補間動画すべて
   - 05_想い出補完/ の補完動画（あれば）
   - BGM ファイル
3. ビン構造で整理：
   - Photos/
   - Bridges/
   - MemoryFill/
   - BGM/
   - Templates/
```

### 6.2 タイムライン構築（1〜1.5 時間）

```
1. 新規タイムライン作成（テンプレートから複製）
2. オープニング→タイトルカード→本編→エンディング の順に配置
3. 写真と AI 補間を交互に配置
   - 写真：4 秒静止
   - AI 補間：5 秒
4. チャプター字幕を追加
5. BGM を配置・フェードイン/アウト調整
```

### 6.3 細部の仕上げ（30 分）

```
□ トランジション（クロスフェード）を補間が破綻している箇所に追加
□ カラーコレクション（全体の色味統一）
□ 音量レベル調整（BGM・字幕タイミング）
□ 想い出補完シーンに memory マーク・セピア演出を追加
□ エンディング前の余韻（無音 1 秒）
```

### 6.4 書き出し（15 分）

#### 配信用（メイン）
```
Format: MP4
Codec: H.264
Resolution: 1920×1080
Frame Rate: 30 fps
Quality: High (10〜20 Mbps)
Audio: AAC 192 kbps
```

#### DVD 用
```
Format: MPEG-2
Resolution: 720×480
Frame Rate: 29.97 fps
Audio: AC-3
（DaVinci Resolve の「DVD Master」プリセット使用）
```

#### Blu-ray 用
```
Format: MPEG-4 AVC
Resolution: 1920×1080
Frame Rate: 29.97 fps
Audio: LPCM 48kHz
```

## 7. 品質チェックリスト（15 項目）

納品前に必ず通しでチェック：

### 内容チェック
- [ ] お客様氏名・生年が正確（タイトルカード）
- [ ] チャプター字幕の年齢・イベント名が正確
- [ ] 字幕の誤字脱字がない
- [ ] 写真の順序が時系列で正しい
- [ ] 写真の上下・向きが正しい
- [ ] 想い出補完シーンに必ず「memory」マーク等の演出
- [ ] 想い出補完シーンの開始字幕が表示されている

### 技術チェック
- [ ] 動画尺がプラン規定内（ライト 3 分 / スタンダード 7 分 / プレミアム 12 分 ±30 秒）
- [ ] 解像度 1920×1080 / 30fps
- [ ] 音声が出る（無音箇所が意図的でない場所にない）
- [ ] BGM の音量が適切（小さすぎず、字幕と被らない）
- [ ] AI 補間が不自然に崩れていない（顔・体の連続性）
- [ ] トランジションが滑らか

### 体感チェック（重要）
- [ ] 通しで視聴して **泣ける** 仕上がりか
- [ ] お客様に「ご家族と一緒に観たい」と思っていただける品質か

→ 1 項目でも NG なら、対応してから初稿提出

## 8. お客様確認フロー

### 8.1 初稿提出

メールテンプレ 6 番（`docs/06-mail-templates.md`）に従って送付：

```
■ 視聴 URL：（限定公開）
■ 視聴期限：2 週間
■ 修正回数：1〜2 回まで無償
```

### 8.2 修正対応

#### 軽微な修正（無償・1 回まで）
- 字幕の誤字訂正
- 写真の順序変更
- BGM の音量調整
- 静止時間の微調整

#### 中規模な修正（無償・1 回）
- 写真の差し替え（同枚数内）
- 字幕の文言変更（複数箇所）
- BGM の楽曲変更
- AI 補間の再生成（1〜3 シーン）

#### 大規模な修正（別途見積もり）
- 写真の大幅追加（プラン上限を超える）
- 全面的なリテイク
- 構成の大幅変更

### 8.3 最終承認

お客様から **「OK です」のメール返信**を受領後、最終納品。
