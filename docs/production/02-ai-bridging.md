# 動画生成ワークフロー：「動き × 編集」方式

**改訂**: v2.0（2026-07-04）
**改訂理由**: 社長による実機テスト（Google Flow / DomoAI、新生児→学童→高校生→成人の実写ペア）で、旧方式（写真 A→B の直接 AI 補間）が破綻することを確認。同時期のファクトチェックで、SNS でバズっている成長動画も「1 本の長い補間」ではなく「短い変化の積み重ね＋編集」で作られていることを確認。本ドキュメントを全面改訂する。
**旧版の核心的な誤り**: 「年齢差の大きい実写写真 2 枚を AI が滑らかに補間できる」という前提。**現行の AI 動画ツールでは実用レベルで不可能**。

---

## 1. 設計思想の転換

### 旧方式（v1.x・廃止）

```
[写真A] ──AI補間──> [写真B] ──AI補間──> [写真C] …
          ↑ 大きな年齢差の補間を AI に丸投げ
          → 顔が別人化 or ただのカット切替に劣化（実測済み）
```

### 新方式（v2.0・採用）：3 層構造

```
第 1 層【動き】   各写真を「1 枚ずつ」AI で動かす（3〜5 秒の微動）
                  例：微笑む・まばたき・髪が風に揺れる・ゆっくりズームイン
                  → 現行 AI（Google Flow / Kling）の得意領域。安定して成功する

第 2 層【編集】   写真間の「時間の経過」は編集で表現する
                  例：クロスディゾルブ／アルバムめくり演出／「○歳 七五三」字幕
                  ／BGM の起伏／余白（黒 0.5 秒）
                  → Filmora（所有済み）で実施。ここが職人の腕の見せ所

第 3 層【限定ブリッジ】 条件を満たすペアのみ、AI トランジションを使う
                  条件：年齢差 1〜3 年以内・撮影条件が近い・顔の角度が近い
                  → Kling AI の始点・終点フレーム指定（下記 §4）
                  → 1 本の動画で 1〜3 箇所の「ここぞ」でだけ使う
```

### なぜこれが正しいか

1. **社長の実測**：大年齢差の直接補間は「面白みのないスライドショー」に劣化した
2. **業界の実態**：バズっている成長記録 AI 動画は CapCut / Filmora のテンプレート等で「複数写真を短い変化で繋ぐ」方式（出典：[trend-sakidori 解説](https://trend-sakidori.com/tiktok-growth-record-ai/)、[Filmora 公式](https://filmora.wondershare.jp/ai/grow-up-video-generators.html)）
3. **AI の特性**：「1 枚の写真に小さな動きを与える」は image-to-video の本来の得意領域。「2 枚の別々の写真を同一人物として繋ぐ」は最も苦手な領域

### 差別化の言い直し（LP・営業資料と統一）

- ✗ 旧：「写真と写真の間を AI が補間し、時が流れるように繋ぐ」
- ○ 新：「**止まっていた写真が、一枚ずつ生き返る。人生の節目を、物語として編む。**」

一般的なスライドショーとの違いは（a）各写真が動くこと、（b）節目字幕と編集の物語性、で立てる。誇大にならず、実現可能な約束。

## 3. 第 1 層：写真を動かすプロンプト集

### 基本テンプレート（Google Flow / Kling 共通・英語推奨）

```
Subtle natural motion. The person gently smiles / blinks softly.
Slow cinematic camera push-in. Hair and clothing move slightly as if
in a gentle breeze. Identity fully preserved — no morphing, no distortion.
Photorealistic, vintage Japanese family photo aesthetic preserved.
```

### 場面別の差し替え句

| 写真の種類 | 追加プロンプト |
| --- | --- |
| 赤ちゃん（寝顔） | `The baby breathes peacefully, tiny movements of sleep.` |
| 学童（直立ポーズ） | `The child's smile brightens slightly, proud posture.` |
| 結婚式 | `Gentle joyful expressions, soft warm lighting shimmer.` |
| 集合写真 | `Very subtle collective motion, no individual face distortion.` |
| 白黒・古写真 | `Keep monochrome throughout. Film grain preserved.` |

### 設定

| 項目 | 推奨 |
| --- | --- |
| 尺 | 3〜5 秒 |
| カメラ | Static または Slow Push-In のみ |
| 解像度 | 1080p 以上 |

### 禁止事項

- 大きなカメラワーク（顔が崩れる）
- 「aging」「growing」等の変化系プロンプト（第 1 層では時間を進めない）
- 表情の大きな変化指示（不気味の谷に落ちる）

## 4. 第 3 層：AI トランジションの適用ルール

### ペア適格条件（全て満たす場合のみ実施）

- [ ] 年齢差 **1〜3 年以内**
- [ ] 顔の角度・大きさが近い（±30% 以内）
- [ ] 撮影条件（屋内外・光）が近い
- [ ] 白黒 or カラーが揃っている
- [ ] Kling 始点・終点フレーム指定で生成 → 顔の同一性を目視確認

### 不適格ペアの繋ぎ方（編集で解決）

| 状況 | 編集手法（Filmora） |
| --- | --- |
| 年齢差大（5 年超） | 黒フェード 0.5 秒＋「— あれから ○ 年 —」字幕 |
| 白黒→カラー切替 | 白黒側の最後をカラー化演出でオーバーラップ |
| 場面が大きく変わる | アルバムめくり／ページ風トランジション |
| 章の変わり目 | チャプター字幕カード（「○歳 成人式」）を 2 秒挟む |

## 5. 1 本の動画の組み立て（スタンダードプラン・写真 20 枚の例）

```
オープニング（3 秒）
 ↓
[写真 1 動き 4 秒] → 編集トランジション → [写真 2 動き 4 秒] → …
 ↓（要所 1〜3 箇所のみ AI トランジション 5 秒）
[最終写真 動き 6 秒]
 ↓
エンディングメッセージ字幕（4 秒）＋ロゴ（3 秒）

尺の計算：20 枚 ×（動き 4 秒＋繋ぎ 1 秒）＋ AI トランジション 3 本 × 5 秒＋前後 10 秒
        ≒ 約 2 分 05 秒 〜 静止秒数の調整で 7 分まで伸縮可
```

### 工数目安（1 本・写真 20 枚）

| 工程 | 時間 |
| --- | --- |
| 写真補正（Luminar 一括） | 1 時間 |
| 各写真の動き生成（20 本、生成待ち含む） | 1.5 時間 |
| AI トランジション（3 本、再生成込み） | 0.5 時間 |
| Filmora 編集（字幕・BGM・書き出し） | 2 時間 |
| 品質チェック | 0.5 時間 |
| **合計** | **約 5.5 時間**（旧試算 6.5 時間から短縮） |
