# 写真補正・高解像度化 ワークフロー

**作成日**: 2026-05-26
**対象**: お預かりした写真を AI 補間に使える品質まで整える工程

---

## 1. このフェーズの目的

| 課題 | 解決すること |
| --- | --- |
| 古い紙焼き写真の **退色・黄ばみ** | 自然な色味に復元 |
| **解像度不足**（スキャン後 800×600 等） | 4K 動画に耐える 1920×1080 以上にアップスケール |
| **キズ・破れ・折れ** | 復元・補修 |
| 顔の **ピンボケ** | AI で顔をシャープに |
| 多人数写真で **特定人物のみ使いたい** | 顔抽出・トリミング |

---

## 2. ツール選定

### メインツール：**Topaz Photo AI**（買切 約 30,000 円）

#### 採用理由
- 写真補正 4 機能（**高解像度化／ノイズ除去／ぼやけ補正／顔シャープ化**）を 1 本でカバー
- バッチ処理対応（複数枚を一度に処理）
- 月額課金なし（永久ライセンス）
- 古い人物写真への補正精度が業界トップクラス

#### 代替案
| ツール | 料金 | 用途 |
| --- | --- | --- |
| **Adobe Photoshop**（Photographyプラン） | 月 1,180 円 | 細かい補修・生成塗りつぶし |
| **Real-ESRGAN**（OSS） | 無料 | 予算抑制時の代替 |
| **GFPGAN**（OSS） | 無料 | 顔復元特化 |
| **Pixelcut / Remini**（コンシューマ） | 月数百円〜 | 簡易補正・スピード重視 |

### 補助ツール：**Adobe Photoshop**
- Topaz では対応できない複雑な修復：破れ・人物切り抜き・背景延長
- Generative Fill（生成 AI 塗りつぶし）で破れた箇所を自然に補完
- 1 案件あたり 1〜3 枚程度の利用なら、月額 1,180 円のフォトプランで十分

## 3. 工程フロー

### 3.1 取込・仕分け（30 分）

```
[受領写真] → [Google Drive 案件フォルダ]
  ・01_受領写真_デジタル/  ← お客様送付のデジタル写真
  ・02_受領写真_郵送スキャン/  ← 当社でスキャンしたもの
                              ↓
[ローカル PC へダウンロード]
                              ↓
[作業フォルダで年代別に仕分け]
  ・00_幼少期/
  ・01_学生時代/
  ・02_社会人/
  ・03_中高年期/
  ・04_最近/
```

### 3.2 一次選別（30 分）

選定基準：

| 採用 OK | 採用 NG |
| --- | --- |
| 顔がはっきり写っている | ピンボケが著しい |
| 単独 or 主役として写っている | 集合写真で人物が小さい（5% 未満） |
| 表情が良い | 目をつぶっている |
| 年代の特徴がわかる（背景・服装） | 似たような写真の重複 |
| ライフイベントを示す（七五三・結婚等） | プライバシーで気になる人物が一緒（要相談） |

10〜40 枚の中で、**人生の節目をバランスよく**選ぶ（幼少／学生／社会人／結婚／子育て／晩年）。

### 3.3 Topaz Photo AI による補正（30〜45 分／20 枚）

#### 起動・設定

```
1. Topaz Photo AI を起動
2. 「File」→「Open」→ 選定済み写真をすべて選択（一括取込）
3. 各写真ごとに「Autopilot」を実行
   → 自動で必要な補正を提案してくれる
4. 補正項目を確認：
   - Upscale：解像度（推奨：2x または 4x、最終目標は 1920×1080 以上）
   - Sharpen：ぼやけ補正（古い写真ほど Strong に）
   - Denoise：ノイズ除去（フィルムノイズ対策）
   - Face Recovery：顔シャープ化（人物写真は必須）
5. 「Save All」で一括書き出し
   - 保存形式：PNG または高品質 JPEG
   - 保存先：03_デジタル化補正後/
```

#### 注意点
- **やりすぎ注意**：補正を強くしすぎると「AI 感」が出て不自然に
- 古いモノクロ写真は元の質感を尊重（過剰なシャープ化禁止）
- 補正前後を必ず見比べる（Compare 機能）

### 3.4 Photoshop による細部補修（必要に応じて 15〜30 分／枚）

#### よくある修復例

| 状態 | 対応 |
| --- | --- |
| 折れ・スクラッチ | スポット修復ブラシ |
| 紙の破れ・欠け | 生成塗りつぶし（Generative Fill） |
| 黄ばみが部分的 | カラーバランス調整 |
| 背景が暗すぎる | レベル補正・トーンカーブ |
| 不要な人物の除去 | 生成塗りつぶし（要お客様同意） |

#### 第三者の写り込み対応
- 同意のない第三者が写っている場合：
  - 顔をぼかす（最小限の対応）
  - クロップでフレーム外へ
  - お客様に確認のうえ判断
- お客様の許可なく**勝手に削除しない**（記録性が損なわれる）

### 3.5 カラー化（白黒写真がある場合 / 15 分／枚）

#### ツール候補
- **DeOldify**（OSS、自前で動かす場合）
- **Pixelcut の AI Colorize**（手軽）
- **MyHeritage In Color**（旅行家系図サービスの機能）
- **Hotpot AI**

#### 運用方針
- **基本は白黒のまま使う**（時代感が失われるため）
- お客様が「カラーにしたい」と希望する場合のみ実施
- カラー化したものは、最終動画でも色調を抑えめにして元の雰囲気を尊重

### 3.6 命名規則・整理

すべての補正後ファイルは、以下の命名規則で統一：

```
JT-2026-0001_001_1955年頃_幼少期.png
JT-2026-0001_002_1958年_七五三.png
JT-2026-0001_003_1965年_小学校入学式.png
...
JT-2026-0001_020_2024年_米寿祝い.png
```

- 案件番号 + 連番 + 年代 + イベント名
- ファイル名で年代順に並ぶように番号付け
- 年代不明な場合は「不明_家族写真」等で記載し、ヒアリングで確定

## 4. 品質基準

補正後の最低品質（AI 補間工程に進める基準）：

- [ ] 解像度 1920×1080 以上
- [ ] 顔が認識可能（人物特定できる）
- [ ] 主要な色味が自然
- [ ] 露骨なノイズ・キズが残っていない
- [ ] 不要な情報（被写体以外の文字・看板等）が読み取れない場合は OK

---

## 5. トラブルシューティング

### Topaz Photo AI が落ちる
- GPU メモリ不足の可能性
- 1 枚ずつ処理する／解像度設定を 2x に下げる

### 補正後に顔が AI っぽくなる
- Face Recovery の強度を下げる
- 重ね合わせモードで「Original + 補正版」をブレンド

### 黄ばみが取れない
- Photoshop の「カラーバランス」で青みを足す
- 「写真フィルター」のクーリングフィルターを適用

### 古い写真に印刷ノイズ（網点）がある
- Topaz Denoise の「Severe Noise」モード
- それでもダメな場合は Photoshop でガウシアンぼかし → シャープ化
