# パンダ先生への確認メモ（講座の紹介について）

> 使い方：下の「送る文章」を、先生とのやり取りでいつも使っている場所（LINE やメッセージなど）にコピーして送る。
> **返事は文字で残してもらう**のがポイント。口頭で聞いた場合も、あとで「確認ですが〜で合っていますか？」と文字で送っておく。

---

## 送る文章

```
パンダ先生、いつもありがとうございます！

講座の紹介のお話、とてもうれしいです。
Threads で発信を始める予定なので、紹介する前に、
きちんと理解しておきたいことをいくつか教えていただけますか？
読んでくださる方に正確にお伝えしたいのと、
あとで私が勘違いして先生にご迷惑をおかけしないようにしたくて🙏

【紹介のしくみについて】
① 私がご紹介した方も、同じように講座を紹介できるようになりますか？
　（それとも、紹介できるのは私だけでしょうか？）
② 紹介料は、講座代金の半分と伺いましたが、
　分割払いの方の場合や、キャンペーン価格の場合はどうなりますか？

【お申し込みとお支払いについて】
③ お申し込みの受付と、代金のお受け取りは、先生の側でしていただけますか？
　（私は紹介だけ、という形で合っていますか？）
④ お申し込みの前に、個別の相談（Zoom など）はありますか？
　ある場合、どなたが担当されますか？

【返金について】
⑤ 講座の返金のルールはありますか？
⑥ 返金があった場合、紹介料はどうなりますか？

【紹介料について】
⑦ 私がご紹介した方だと、どうやってわかる形になりますか？
　（紹介コード、専用リンク、お名前の申告など）
⑧ 紹介料のお支払いの時期と方法を教えてください。
　（請求書の発行が必要かどうかも教えていただけると助かります）

【発信のしかたについて】
⑨ 紹介するときに、使ってはいけない表現や、気をつけることはありますか？
⑩ 受講生さんの実績（収益額など）を、私の発信で紹介してもよいですか？

お手数をおかけしますが、よろしくお願いします🐼✨
```

---

## 返事を読むときのチェックポイント（自分用）

| # | 返事 | 安心 | 要注意 |
| --- | --- | --- | --- |
| ① | 紹介された人も紹介できる？ | 紹介できるのはあなただけ、または限られた人だけ | **紹介された人も、次の人を紹介して報酬がもらえる** → マルチ商法（連鎖販売取引）の規制に当たるおそれ。紹介は止めて、もう一度相談しよう |
| ③ | 受付と代金は誰が？ | 先生の側 | あなたが代金を受け取る → 特定商取引法の表示などが、あなたにも必要になる |
| ④ | 個別の相談は？ | 相談で無理にすすめない | 電話や Zoom で強くすすめる形 → 契約のトラブルが起きやすい。クーリング・オフが関係することもある |
| ⑤⑥ | 返金のルール | ルールがはっきりしている | ルールがない、または「返金なし」だけ |
| ⑦⑧ | 紹介の判定と支払い | 仕組みと時期が決まっている | 「そのときに考える」 |
| ⑨⑩ | 表現のルール | 「稼げる」と言わないなど、ルールがある | 「月〇万円稼げると書いていい」 → 景品表示法の問題になりうる。**あなたは使わない** |

---

## 返事が来たら

先生の返事を、そのままチャットに貼ってね。
一緒に読んで、「紹介してOK」「ここだけ気をつける」「今はやめておく」を判断しよう。
