# 公務員アカウント 手動予約用 1週間分（1日1本・21:00）

> 自動化ができるまでのつなぎ。Threads アプリの予約投稿で使う。
> リンクなし（ASP 登録前なので、フォロワーを増やすことだけに集中する週）。
> すべての投稿にトピックタグ「公務員」を付ける。投稿後30分以内にコメントへ返信する。
> 型は、Threads で伸びやすいとされる一般的な傾向をもとにしている。実際の競合アカウントの分析はまだしていない（スクショか Web 検索で後日やる）。

## この週に使う型

| 型 | ねらい | 使う日 |
| --- | --- | --- |
| 問いかけ型 | 1行目で質問 → 最後も質問で終わる。返信が増えると、おすすめに乗りやすい | 1日目・7日目 |
| 〇〇な人の特徴3つ型 | 動画で紹介された勝ちパターン。自分ごと化しやすい。最後はやさしい一言で締める | 2日目 |
| ビフォーアフター型 | 公務員時代と今の対比。物語として読まれる | 3日目 |
| 誤解を解く型 | 「よく言われるけど、実は」。意外性で指が止まる | 4日目 |
| 保存したくなるリスト型 | あとで見返したい情報。保存・再投稿されやすい | 5日目 |
| 本音告白型 | キラキラしていない正直さで信頼をつくる | 6日目 |

共通ルール：1行目は短く／1行を短くして改行を多めに／200〜350字／数字や体験は、確かな事実以外は書かない。

## 1日目 9/30（水） 21:00　問いかけ型

```
公務員を辞めたいと思ったこと、ありますか？

理由は人それぞれですよね。
・人間関係
・給料
・やりがい
・将来への不安

私の場合は
「成長してる実感がなくなったこと」でした。

20年近く勤めて、昨年、本当に辞めました。

あなたの「辞めたい」は、どれに近いですか？
```

## 2日目 10/1（木） 21:00　〇〇な人の特徴3つ型

```
公務員を辞めて後悔しやすい人の特徴3つ。

① 辞める理由が「今がつらい」だけ
② 辞めた後のお金を計算していない
③ 辞めて何をしたいかが、ぼんやりしている

もし当てはまっても、大丈夫。

辞める前に気づけたなら、
準備する時間があるということだから。
```

## 3日目 10/2（金） 21:00　ビフォーアフター型

```
公務員時代と、辞めた今。
いちばん変わったこと。

【公務員時代】
給料は毎月、決まった日に入る
次の仕事は、異動で決まる
成長している実感は、なかった

【辞めた今】
収入は、まだ安定していない
何をやるかは、全部自分で決める
わからないことだらけで、毎日が勉強

どっちがいいかは、人それぞれ。
私は、後者を選びました。
```
> 📝 「毎日が勉強」があなたの実感に合わなければ直してね。

## 4日目 10/3（土） 21:00　気づき＋リスト型（競合分析をふまえて差し替え）

```
公務員を20年近くやって、辞めてから気づいたこと。

異動で「お金系」と「現場系」を行き来した経験は、
思っていたより財産でした。

【お金系の部署で身についたこと】
① 数字の間違いに気づく目
② ルールを根拠から確かめるクセ
③ 期限から逆算して動く段取り

【現場系の部署で身についたこと】
④ 初めての相手にも、わかりやすく説明する力
⑤ 立場の違う人の間に入る調整力
⑥ 予定どおりにいかないときの対応力
⑦ 異動のたびに、ゼロから覚え直す根性

役所の中では「当たり前」でも、
外に出ると、ちゃんと強みです。

異動ばかりで専門性がない、と悩んでいる公務員さん。
あなたの経験にも、名前を付けてあげてください。
```

## 5日目 10/4（日） 21:00　保存したくなるリスト型

```
公務員を辞める前に、確認しておきたいお金のこと。

□ 退職金の見込み額
□ 辞めた翌年の住民税（前の年の収入で決まるので、意外と重い）
□ 健康保険をどうするか（任意継続か、国民健康保険か）
□ 年金の切り替え
□ 貯金で何か月暮らせるか

辞めた後に「こんなはずじゃ…」とならないために。

保存して、辞める前に見返してください。
```

## 6日目 10/5（月） 21:00　本音告白型

```
正直に言います。

公務員を辞めて1年。
まだ大きくは稼げていません。

でも、辞めたことは後悔していません。

「このままでいいのか」と思いながら
毎日を過ごすより、
わからないことだらけでも
自分で選んだ道を進むほうが、私には合っていました。

キラキラした話じゃなくて、
こういう途中経過も、正直に書いていきます。
```

## 7日目 10/6（火） 21:00　問いかけ型（選択肢）

```
公務員のみなさんに質問です。

今の仕事、定年まで続けるつもりですか？

① 続けるつもり
② 正直、迷っている
③ できれば辞めたい
④ もう辞めた

ちなみに私は④です。

番号だけでもいいので、
コメントで教えてもらえたらうれしいです。
```
