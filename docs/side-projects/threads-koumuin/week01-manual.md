# 公務員アカウント 手動予約用 1週間分（1日1本・21:00）

> 自動化ができるまでのつなぎ。Threads アプリの予約投稿で使う。
> リンクなし（ASP 登録前なので、フォロワーを増やすことだけに集中する週）。
> 型は、Threads で伸びやすいとされる一般的な傾向をもとにしている。実際の競合アカウントの分析はまだしていない（スクショか Web 検索で後日やる）。

## この週に使う型

| 型 | ねらい | 使う日 |
| --- | --- | --- |
| 問いかけ型 | 1行目で質問 → 最後も質問で終わる。返信が増えると、おすすめに乗りやすい | 1日目・7日目 |
| 〇〇な人の特徴3つ型 | 動画で紹介された勝ちパターン。自分ごと化しやすい。最後はやさしい一言で締める | 2日目 |
| ビフォーアフター型 | 公務員時代と今の対比。物語として読まれる | 3日目 |
| 誤解を解く型 | 「よく言われるけど、実は」。意外性で指が止まる | 4日目 |
| 保存したくなるリスト型 | あとで見返したい情報。保存・再投稿されやすい | 5日目 |
| 本音告白型 | キラキラしていない正直さで信頼をつくる | 6日目 |

共通ルール：1行目は短く／1行を短くして改行を多めに／200〜350字／数字や体験は、確かな事実以外は書かない。

---

## 1日目　問いかけ型

```
公務員を辞めたいと思ったこと、ありますか？

理由は人それぞれですよね。
・人間関係
・給料
・やりがい
・将来への不安

私の場合は
「成長してる実感がなくなったこと」でした。

20年近く勤めて、昨年、本当に辞めました。

あなたの「辞めたい」は、どれに近いですか？
```

## 2日目　〇〇な人の特徴3つ型

```
公務員を辞めて後悔しやすい人の特徴3つ。

① 辞める理由が「今がつらい」だけ
② 辞めた後のお金を計算していない
③ 辞めて何をしたいかが、ぼんやりしている

もし当てはまっても、大丈夫。

辞める前に気づけたなら、
準備する時間があるということだから。
```

## 3日目　ビフォーアフター型

```
公務員時代と、辞めた今。
いちばん変わったこと。

【公務員時代】
給料は毎月、決まった日に入る
次の仕事は、異動で決まる
成長している実感は、なかった

【辞めた今】
収入は、まだ安定していない
何をやるかは、全部自分で決める
わからないことだらけで、毎日が勉強

どっちがいいかは、人それぞれ。
私は、後者を選びました。
```
> 📝 「毎日が勉強」があなたの実感に合わなければ直してね。

## 4日目　誤解を解く型

```
「公務員は民間で通用しない」

よく言われるけど、半分は誤解だと思っています。

異動が多い公務員は、
・知らない仕事を、ゼロから覚えてこなす
・ルールや制度を、正確に読み解く
・立場の違う人の間に入って、調整する

これを何年も続けてきた人たちです。

民間ではこれを
「適応力」「コンプライアンス感覚」「調整力」と呼びます。

通用しないんじゃなくて、
自分の強みに名前を付けていないだけかもしれません。
```

## 5日目　保存したくなるリスト型

```
公務員を辞める前に、確認しておきたいお金のこと。

□ 退職金の見込み額
□ 辞めた翌年の住民税（前の年の収入で決まるので、意外と重い）
□ 健康保険をどうするか（任意継続か、国民健康保険か）
□ 年金の切り替え
□ 貯金で何か月暮らせるか

辞めた後に「こんなはずじゃ…」とならないために。

保存して、辞める前に見返してください。
```

## 6日目　本音告白型

```
正直に言います。

公務員を辞めて1年。
まだ大きくは稼げていません。

でも、辞めたことは後悔していません。

「このままでいいのか」と思いながら
毎日を過ごすより、
わからないことだらけでも
自分で選んだ道を進むほうが、私には合っていました。

キラキラした話じゃなくて、
こういう途中経過も、正直に書いていきます。
```

## 7日目　問いかけ型（選択肢）

```
公務員のみなさんに質問です。

今の仕事、定年まで続けるつもりですか？

① 続けるつもり
② 正直、迷っている
③ できれば辞めたい
④ もう辞めた

ちなみに私は④です。

番号だけでもいいので、
コメントで教えてもらえたらうれしいです。
```
