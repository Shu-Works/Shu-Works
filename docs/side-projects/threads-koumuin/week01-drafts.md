# 公務員アカウント 第1週 投稿案（14本）

> 1日2本 × 7日。比率は ①認知＋②興味関心 が10本、③検索＋④行動 が4本（約7:3）。
> 週末の確認で見るところは3つだけ：
> 1. **自分の体験と違うところ**はないか → 違ったら直す、または消す
> 2. **身バレ**しそうなところはないか
> 3. **【要確認】**の数字を、出典で確かめたか

---

## 共通ルール（AIが守ること）

- あなたの確かな事実は次の8つだけ。**これ以外の体験は作らない**
  - 地方公務員を20年近く務めた
  - お金系と現場系の4部署を経験した
  - 成長を感じられなくなって辞めた
  - 辞めたのは昨年
  - 今は在宅で自分の仕事をしている
  - まだ大きく稼げてはいない
  - 辞めるときに転職エージェントは使っていない
  - 収益化のめどが立ったら起業したい
- 役所を下げない。「自分で選んだ」という前向きな軸で書く
- 内部事情や具体的な案件、旦那さんの職場の話は書かない
- 数字には出典を付け、確かめるまでは【要確認】を付けておく
- リンクは本文に貼らない。コメント欄に PR 表記と一緒に置く
- エージェントは「使った人」としてではなく、「選択肢の一つとして紹介する人」として書く。独立もすすめすぎない

---

## プロフィール（確定候補）

> 元地方公務員｜20年近く勤め、お金系と現場系の4部署を経験｜「このままでいいのか」と成長を感じられなくなり、昨年退職｜今は在宅で自分の仕事に挑戦中｜公務員の転職・辞め方・民間で活きるスキルを本音で発信｜※紹介リンクはPRを含みます

## Day 1

### 1-A ①認知（自己紹介・固定投稿の候補）
```
公務員を20年近くやって、昨年辞めました。
今は在宅で、いつか起業するための準備中です。

理由はシンプルで、
「成長してる実感がなくなったから」。

給料も安定してたし、職場の人もいい人だった。
でも、このまま定年まで同じ毎日かと思ったら、動けなくなりそうで怖かった。

ここでは、
・公務員の転職のリアル
・辞める前に知っておきたかったこと
・民間で活きる公務員のスキル
を本音で書いていきます。

迷っている公務員さんの判断材料になれたらうれしいです。
```

### 1-B ②興味関心
```
公務員の「異動ばかりで専門性がない」問題。

私も20年近くで4つの部署を回って、ずっとそう思ってました。

でも辞めてみてわかったのは、
異動が多い人ほど持っている力があるということ。

・知らない仕事でも、ゼロから覚えてこなせる
・ルールや制度を正確に読み解ける
・立場の違う人の間に入って調整できる

これ、民間では「適応力」「コンプライアンス感覚」「調整力」と呼ばれてます。

専門性がないんじゃなくて、
自分の強みに名前を付けてなかっただけかも。
```

② 家計の固定費を書き出して、何か月もつか計算する

まずは「選べる状態」を作るだけで、気持ちがかなり楽になります。

## Day 3

### 3-A ①認知
```
公務員の平均年齢と、転職する人の年代。

実は転職する人が一番多いのは20代。
でも最近は、30代・40代で転職する人も増えています。【要確認：出典を付ける】

「公務員は一生公務員」の時代は、もう終わりかけているのかもしれません。
```
> 📝 数字の出典（総務省の調査、転職サービスの公開データなど）を確かめてから出す。確かめられなければ、この投稿は差し替える。

### 3-B ④行動
```
転職エージェントって、登録したら
「すぐ転職しないといけない」と思ってませんか？

実は違います。

・登録は無料
・相談だけでもOK
・合わなければ断っていい

「今すぐ辞める」ためじゃなく、
「自分にどんな選択肢があるか知る」ために使う人も多いです。

公務員のうちに、外の世界の相場を知っておく。
それだけでも、今の仕事の見え方が変わります。

ちなみに私は、使わずに勢いで辞めた側です。
独立を選んだことに後悔はないけど、
「外から見た自分の値段」を知らないまま決めたのは、ちょっと無防備だったなと思っています。
```
> 📝 最後の3行は、本当にそう思う場合だけ残す。思わないなら消す。

## Day 4

### 4-A ②興味関心
```
公務員の経験、職務経歴書にどう書けばいい？

「〇〇課で窓口業務」だけだと、民間の人には伝わりません。

書き方のコツはこれ。

× 窓口で住民対応をした
○ 1日〇件の問い合わせに対応し、制度をわかりやすく説明した

× 予算の担当をした
○ 〇千万円規模の予算を、ルールに沿って管理した

「何をしたか」より「どれくらい」「どうやって」。
数字を入れるだけで、一気に伝わる経歴書になります。
```
> 📝 例文の〇は空欄のまま。あなたの実際の数字は入れない（身バレ防止）。

### 4-B ①認知
```
公務員を辞めて1年。
転職じゃなく、独立を目指す道を選びました。
正直に言うと、まだ大きくは稼げていません。

でも、後悔はしていません。

毎日「今日は何を学んだか」を考えられるようになったから。

辞めたら全部うまくいく、なんてことはない。
だからこそ、辞める前の準備が大事なんだと思います。

キラキラした話より、こういう本音のほうが役に立つと信じて書いてます。
```

## Day 5

### 5-A ②興味関心
```
公務員が民間に転職するときに、よく言われること。

「公務員は仕事が遅い」
「前例がないと動けない」

これ、半分は誤解で、半分は本当だと思います。

誤解なのは、
公務員は「遅い」んじゃなくて「間違えられない」環境にいるだけ。

本当なのは、
その環境に慣れすぎると、スピード感を忘れてしまうこと。

だからこそ、面接では
「正確さ」を強みとして語り、「スピード」は自分から意識していると伝える。

これだけで印象がかなり変わります。
```

### 5-B ③検索
```
公務員からの転職で、転職エージェントを使うなら。

大手の総合型エージェントがおすすめです。理由は3つ。

① 求人の数が多い（業界を決めていなくても探せる）
② 公務員から民間に転職した人の事例を持っている
③ 経歴書の書き方や面接の対策を無料で見てもらえる

特に「公務員の経験をどう伝えるか」は、
自分だけで考えるより、外の人に一緒に考えてもらったほうが早いです。
```
> コメント欄：【紹介文テンプレート】を使う。案件は ASP で提携が決まってから入れる。

## Day 6

### 6-A ①認知
```
公務員を辞めると言ったときに言われた言葉、ランキング。

1位「もったいない」
2位「なんで？安定してるのに」
3位「次は決まってるの？」

どれも心配してくれてるのはわかるんです。
でも、「もったいない」で人生を決めたくなかった。

公務員を辞めるか迷ってる人、
周りにどう言われるのが一番こたえますか？
```
> 📝 実際に言われた言葉に合わせて直す。言われていないなら、「よく言われる言葉」に書き換える。

### 6-B ②興味関心
```
公務員が辞める前に確認しておきたいお金の話。

・退職金は、勤続年数と辞め方で大きく変わる
・住民税は前の年の所得で決まるから、辞めた翌年が重い
・健康保険は、任意継続か国民健康保険かを選ぶ
・年金は、厚生年金から国民年金に切り替える（転職しない場合）

特に住民税は、
辞めたあとに「こんなに払うの！？」となりやすいので要注意。

お金の不安を先に消しておくと、落ち着いて次を選べます。
```
> 📝 制度の中身は、確定させる前に公式情報で確かめる【要確認】。

## Day 7

### 7-A ④行動
```
転職エージェントに登録すると、何が起きるのか。

① 登録フォームに入力（名前・経歴・希望条件くらい）
② 担当の人から連絡が来る（電話やメール）
③ 面談で、希望や経歴を話す
④ 合いそうな求人を紹介してもらう

「電話がかかってくるのが怖い」という人は、
面談の日時を自分で指定できるか、登録するときに確かめておくと安心です。

まずは①だけ。
それだけで、自分の市場価値が見えてきます。
```
> コメント欄：【紹介文テンプレート】を使う。登録の流れは、紹介する案件の公式情報に合わせて直す。
