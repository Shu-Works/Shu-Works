## わかったこと（勝ちパターン）

1. **返信がいちばん多いのは「迷いの吐露」**（A：表示9.1万・返信57）。答えを言い切らず、「〜した方がいいのかな…」で終わると、読者がアドバイスしたくなる
2. **具体的な数字・場面がリアリティを生む**（B：3月25日 → 4月1日）。ただし SORA は身バレ防止のため、自治体を特定できない「どこでもある」場面にとどめる
3. **1行目は「辞めてわかったこと」**（C）。変化・気づきから入ると、指が止まる
4. **リストは多めが保存される**（C：10個）。3個より7〜10個
5. **最後は読者への直接の呼びかけ**（C：「公務員さん、自分を過小評価しないでほしい」）
6. **トピックタグを付けている**（「公務員」「保育士 就職」など）。検索とおすすめの入口になる
7. **投稿者がコメント欄で返信している**（C'）。会話が続くと、さらに表示が伸びる

## SORA が真似しないこと

- B の「べらんめえ口調」や、役所を強く批判する書き方（旦那さんの職場と、役所を下げないルールのため）
- C のスキル10個をそのまま使うこと（型だけ借りて、中身は「4部署を回った」自分の角度で書く）
- 体験していない迷いや出来事を作ること（A の型は、本当に迷っていることがあるときだけ使う）

### わかったこと
- 今回見た中で最大の伸び。**強い感情（怒り・あきれ）＋内部の人しか知らない話**は、表示が桁違いに伸びる
- 誤解されそうな部分を、投稿者が**返信で補足**している（「本当に辛い方のことは否定していません」）
- 荒れそうな話題では、**返信できる人を制限**している

### SORA は使わない（理由）
- 同僚の病気休暇など、**職場の人の健康や人事の話**は、守秘義務とプライバシーの問題になりうる
- 特定の世代や、心の不調で休む人を責める内容は、傷つく人が出る。アカウントの信頼も失う
- 旦那さんが現役の公務員なので、職場の内部の話は書かない

### 借りられるところ
- **「感情」を入れる**：怒りではなく「悔しさ」「もやもや」「ほっとした」など、自分の感情を正直に書く
- **誤解されそうな投稿は、自分で補足の返信を付ける**
- **読者の立場は、責める側ではなく寄り添う側に立つ**（例：新人が1年目で折れやすい理由を、責めずに書く）
