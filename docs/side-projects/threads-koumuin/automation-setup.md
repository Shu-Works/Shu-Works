# Threads 自動運用の仕組み：設計と準備手順

## 決まったこと

| 項目 | 決定 |
| --- | --- |
| 投稿本数 | 1アカウント1日2本から始め、最終的に3本 |
| 投稿の仕組み | Make ＋ Threads 公式 API（Buffer・Metricool は使わない） |
| 予定表 | Google スプレッドシート |
| コメント欄のリンク | 本文を投稿したあと、その返信として Make が自動で付ける |
| 確認と承認 | **Discord** に届く → Discord で返事する |
| 分析 | Make が数字を毎日集める → AI が毎朝分析して、Discord にレポートする |
| 方針の見直し | 毎日は気づきのメモと小さな修正だけ。型や比率の見直しは毎週 |
| 安全装置 | 「OK」が付いていない投稿は、絶対に出さない |

---

## 全体の流れ

```
【日曜の朝】AI が来週分の投稿案を予定表に書き、Discord に送る
     ↓
【あなた】Discord で返事する（「全部OK」「OK 1-12」「5 もっとやわらかく」）
     ↓
【Make】返事を読んで、予定表の「状態」を更新する
     ↓
【毎日・時間になったら】Make が「OK」の投稿を出す → 返信でリンクを付ける → 「投稿済み」にする
     ↓
【毎日】Make が閲覧数・いいね・返信を集めて、予定表に書き込む
     ↓
【毎朝】AI が分析して、Discord に3行レポートを送る。未確認の案を直す
```

## ステップ0：Threads アカウントを作る

1. 公務員用に、**新しい Instagram アカウント**を作る
   - 名前・アイコン・メールアドレスは、本名やスピリチュアルのアカウントとつながらないものにする
   - Instagram では投稿しなくていい
2. その Instagram アカウントで Threads に登録する
3. プロフィールを設定する（week01-drafts.md のプロフィール案を使う）
4. **公開アカウント**にしておく（API で投稿するため）

## ステップ1：Meta の開発者登録とトークン発行

> 画面の名前や場所は、Meta の更新で変わることがある。見つからないときは、画面のスクショを送ってね。

### 1-1. 開発者として登録する
1. https://developers.facebook.com を開き、Facebook アカウントでログインする
   - 開発者アカウントは、Threads のフォロワーからは見えない
2. 「開発者として登録」を選び、電話番号の確認などを済ませる

### 1-2. アプリを作る
1. 「マイアプリ」→「アプリを作成」
2. 用途（ユースケース）で **「Threads API にアクセス」** を選ぶ
3. アプリ名を付ける（例：`threads-scheduler`。人には見えない）

### 1-3. 権限を付ける
ユースケースの設定で、次の権限を追加する。

| 権限 | 使い道 |
| --- | --- |
| `threads_basic` | 基本（必須） |
| `threads_content_publish` | 投稿と、コメント欄への返信 |
| `threads_manage_insights` | 閲覧数・いいねなどの数字 |
| `threads_read_replies` | 読者からの返信を読む（あとで使う） |

### 1-4. 自分の Threads アカウントを「テスター」に追加する
1. アプリの「アプリの役割」→「役割」→ **Threads テスター** を追加 → 公務員用の Threads ユーザー名を入れる
2. Threads 側で招待を受ける：Threads（Web）の「設定」→「アカウント」→「ウェブサイトのアクセス許可」→「招待」→ **承認**

自分のアカウントだけで使うので、Meta の審査（アプリレビュー）は不要。

### 1-5. アクセストークンを発行する
1. ユースケースの設定画面にある「ユーザートークン生成ツール」で、公務員用アカウントのトークンを発行する
2. トークンは **60日で切れる** ので、Make で自動更新する流れを作る（ステップ3で AI が作る）

### ⚠ セキュリティ：トークンとアプリシークレットの扱い
- **トークンとアプリシークレットは、チャットに貼らない**
- **Make の画面に直接入力する**（入れる場所は、ステップ3で AI が案内する）
- 人に見せたり、スクショに写したりしない。漏れたら、アカウントを乗っ取られたのと同じになる
