# 公務員アカウント ASP 案件の選び方

> 承認率・報酬額・成果条件は、ASP にログインしないと見られない。
> ここにあるのは「候補」と「確かめ方」まで。**最終決定は、ASP の管理画面で下のチェック表を埋めてから。**

---

## 読者の前提

| 項目 | 想定 |
| --- | --- |
| 年代 | 30〜40代が中心（20代の若手公務員も一部） |
| 状況 | 在職中。すぐ辞めるより「まず選択肢を知りたい」人が多い |
| 住まい | **地方が多い**（ここが案件選びの落とし穴になる） |

---

## 候補の案件

### メイン（まずはこの2つ）

| 案件 | 合う理由 | 注意点 |
| --- | --- | --- |
| **doda** | 総合型の大手。求人が多く、年代の幅が広い。業界が決まっていない公務員でも探せる | 成果条件の年齢・地域を確認 |
| **リクルートエージェント** | 国内最大手。地方の求人もある。公務員から民間に移った人の事例も多いとされる | 扱っている ASP が限られる（afb など）。4つの ASP で見つからなければ、バリューコマースも候補 |

→ 投稿での使い分け：総合的な話は doda、比較の投稿（③検索）で両方を紹介する。

### サブ（読者の反応を見てから足す）

| 案件 | 合う読者 | 注意点 |
| --- | --- | --- |
| マイナビエージェント | 20〜30代の若手公務員 | 年齢条件で否認されやすいので、若手向けの投稿だけで使う |
| JAC リクルートメント | 40代で係長・課長級の経験がある人 | ハイクラス向け。年収や経験の条件が厳しく、承認率が下がりやすい |

### 使わない案件

| 種類 | 理由 |
| --- | --- |
| 既卒・フリーター向けのエージェント | 在職中の公務員とは読者が合わない → 否認されやすい |
| 有料のスクール（IT スクールなど） | 「無料で相談」という投稿の軸と合わない |
| ビズリーチ | 無料で登録できるが有料プランもあり、「完全無料」と書けない。あとで検討 |

## ASP で確かめるチェック表

候補ごとに、管理画面の案件ページで埋める。

| 確認項目 | doda | リクルートエージェント | 見るポイント |
| --- | --- | --- | --- |
| 報酬額 | | | 8,000円前後が目安 |
| 承認率 | | | **70%以上** |
| 成果条件：年齢 | | | 30〜40代が入っているか |
| 成果条件：地域 | | | **首都圏だけ、などの条件がないか**（地方の読者は否認される） |
| 成果条件：就業状況 | | | 在職中でも OK か |
| **SNS での宣伝** | | | **Threads（SNS）で宣伝してよいか**。禁止なら使えない |
| 禁止されている表現 | | | 「絶対」「必ず年収アップ」など |
| 否認される条件 | | | 重複登録、いたずら登録など |

---

## 絶対にやらないこと

- **自分のリンクから自分で登録しない**（自己アフィリエイトの禁止。規約違反で報酬がなくなる）
- **旦那さんや家族に、自分のリンクから登録してもらわない**（同じく規約違反になりやすい）
- 成果条件に合わない人（年齢・地域）に向けて、無理にすすめない

---

## 手順

1. 4つの ASP（A8.net、afb、TCSアフィリエイト、seedApp）に登録する
   - サイト（媒体）の登録で Threads アカウントの URL を使うため、**Threads アカウントを先に作っておく**
   - 媒体の審査があるので、プロフィールと数本の投稿を先に出しておくと通りやすい
2. 各 ASP で「doda」「リクルートエージェント」を検索する
3. 上のチェック表を埋める
4. 条件を満たした ASP で提携申請する（同じ案件が複数の ASP にあれば、報酬額と承認率が一番いいところを選ぶ）
5. 承認されたら、自分専用のリンクを発行する
6. 投稿案の【紹介文テンプレート】の [案件名] と [アフィリエイトリンク] を埋める
