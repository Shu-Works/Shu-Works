**作成日**: 2026-05-26
**用途**: ブランドアイデンティティ確定のための社内提案

## 1. ブランドコンセプト

| 項目 | 内容 |
| --- | --- |
| サービスの本質 | 写真と写真の「あいだ」を AI でつなぎ、人生を一本の物語にする |

## 2. サービス名候補（5案）

### 案 A：人生タイムラプス（現在の仮称）
- **長所**：機能を直接的に表現／検索性が高い／覚えやすい
- **短所**：「タイムラプス」が高齢者世代に馴染みが薄い可能性

### 案 B：**おもかげ**（俤／面影）
- **長所**：日本語として情緒豊か／「亡き人を偲ぶ」「過ぎ去った日々」のニュアンスを含む／高齢者世代の感性に強く訴える
- **短所**：終活寄りに偏り、若い贈り主層に届きにくい可能性

### 案 C：**ひととせ**（一年）／ **百年（ももとせ）**
- **長所**：和の情緒／長寿を連想させる
- **短所**：意味がやや抽象的

### 案 D：**いまむかし**
- **長所**：「今」と「昔」を AI でつなぐサービス内容を端的に表現／日本語として親しみやすい
- **短所**：商標確認が必要

### 案 E：**Lifelapse（ライフラプス）**
- **長所**：「Life」＋「Timelapse」の造語で機能直結／英字でモダン／海外展開を視野に
- **短所**：高齢者層には英字が伝わりにくい

### 推奨

| ターゲット重視度 | 推奨案 |
| --- | --- |
| シニア本人（終活）を重視 | **B：おもかげ** |
| 贈り主世代（40〜60代）を重視 | **D：いまむかし** または **A：人生タイムラプス** |
| 機能訴求・拡張性を重視 | **A：人生タイムラプス**（メイン）＋ **E：Lifelapse**（サブブランド） |

→ **第一推奨：A「人生タイムラプス」をメインに据え、英字併記で「Jinsei Timelapse」とする**。
   理由：機能直結／既に企画ドキュメントで使用中／検索流入を取りやすい。

## 3. ロゴデザイン方針

### コンセプト
- **「点と点を線でつなぐ」**：写真（点）を AI（線）でつなぐビジュアルメタファー
- **ひらがな・漢字＋小さな英字**の構成
- 縦組み・横組み両対応

### モチーフ案

| モチーフ | イメージ |
| --- | --- |
| **A：流れる時間の線** | 点線が左から右へ、徐々に実線になっていく図 |
| **B：写真フレーム＋川の流れ** | 写真の枠から水墨の流れが伸びるイメージ |
| **C：年輪** | 同心円が広がる／長寿のイメージ |
| **D：和暦の○年** | 「令和○年」のような書体の中に時間の流れを内包 |

**推奨**：**A：流れる時間の線** ＋ ロゴタイプ「人生タイムラプス」明朝体

## 4. ブランドカラー

### メインカラー：**和の茶（茜茶 / Akane-cha）** `#8a6240`
- 日本古来の伝統色／落ち着き・上質・温もり
- すでに `index.html` で採用済み

### サブカラー：**淡茜（Awa-akane）** `#c89b6a`
- メインカラーの明色／アクセント・ボタン・装飾

### 補色：**生成（Kinari）** `#fdf9f3`
- 背景／優しい白に近い和紙のような質感

### アクセント：**朱（Shu）** `#b8453d`
- 価格・重要箇所のみに使用／控えめに

### 文字色：**焦茶（Kogecha）** `#3a2d1f`
- 本文／読みやすさを担保

### カラーパレットの理由
- **和の伝統色**で「人生」「老い」「敬意」を自然に表現
- 葬儀の黒・グレー系を避け、**温かい茶系**で前向きな印象に
- アクセントの朱は祝い事（還暦・古希等）の色味とも親和性が高い

## 6. ブランドボイス（コピー設計）

### NG ワード
- 「最新テクノロジーで」「AI が自動で」「効率的に」「コスパ」
- 葬儀色の強い「亡き」「故」「冥福」（追悼用途以外で）

### OK ワード
- 「お預かりする」「お届けする」「お一人おひとり」「丁寧に」「物語として」
- 「あなたの歩み」「過ごされた時間」「節目」「想い出」

### キャッチコピー候補

1. 「**写真と写真の、あいだの時間まで。**」
2. 「**あなたの人生を、一本の物語に。**」
3. 「**10 枚の写真から、人生は動き出す。**」
4. 「**おじいちゃん、おばあちゃんの人生は、こんなにも色鮮やかだった。**」
5. 「**たいせつな歩みを、たいせつな人へ。**」

→ **第一推奨：1 と 3 を組み合わせて使用**
   - メインビジュアル：「写真と写真の、あいだの時間まで。」
   - サブコピー：「たった 10 枚の写真から、人生は動き出す。」
