# BGM ライセンス選択肢 比較・推奨（ドラフト v0.1）

> ⚠️ **これは社内検討用の調査メモです。**
> 契約締結前に各団体・サービスの最新の利用規約を必ず再確認してください。

---

## 1. ライセンス区分の基礎知識

完成動画に使用する楽曲には、以下の 2 つの権利処理が必要です。

| 権利 | 内容 | 主な管理団体・主体 |
| --- | --- | --- |
| **著作権**（作詞・作曲） | 楽曲そのものを使う権利 | JASRAC、NexTone、楽曲ごとの著作権者 |
| **著作隣接権**（原盤権） | 既存の音源（レコーディング）を使う権利 | レコード会社・実演家 |

**注意**：JASRAC・NexTone と契約しても、**原盤権はカバーされません**。既存の CD 音源を使う場合は、別途レコード会社との交渉が必要です。

## 2. 選択肢の比較

### 選択肢 A：JASRAC / NexTone と直接契約（著作権のみ）

| 項目 | 内容 |
| --- | --- |
| 対象 | 著作権管理団体が管理する膨大なレパートリー |
| 料金 | JASRAC：年額固定または使用料率制（売上の◯%）<br>NexTone：個別交渉 |
| メリット | 国内のメジャー楽曲のほぼすべてを利用可能 |
| デメリット | **原盤権は別途処理が必要**／手続きが煩雑／料金が読みにくい |
| 推奨度 | ★★☆☆☆（事業初期にはオーバースペック） |

### 選択肢 B：商用利用可のロイヤリティフリー音源サイト

| サービス | 月額／年額 | 楽曲数 | 商用利用 | クレジット表記 |
| --- | --- | --- | --- | --- |
| **Artlist** | 年額 約 200 USD〜 | 約 30,000 曲 | 可 | 不要 |
| **Epidemic Sound** | 月額 約 15 USD〜 | 約 50,000 曲 | 可 | 不要 |
| **Audiostock**（日本） | 1 曲買切 660 円〜 | 約 90 万点 | 可 | 不要 |
| **DOVA-SYNDROME** | 無料 | 数千曲 | 可 | 推奨 |
| **甘茶の音楽工房** | 無料 | 数百曲 | 可 | 不要 |

#### メリット
- 権利処理がシンプル（1 契約で完結）
- 原盤権込み（音源データそのものが使える）
- 初期費用が圧倒的に低い

#### デメリット
- メジャー楽曲（昭和歌謡など）は使えない → **「思い出の曲」リクエスト対応に弱い**

#### 推奨度
**★★★★★（事業初期の主軸として最有力）**

### 選択肢 C：オーダーメイド作曲依頼

| 項目 | 内容 |
| --- | --- |
| 対象 | 個別案件ごとに作曲家に依頼 |
| 料金 | 1 曲 30,000〜100,000 円 |
| メリット | 完全オリジナル／権利問題ゼロ |
| デメリット | コスト高／納期長 |
| 推奨度 | ★★★☆☆（プレミアムプランのオプションとして） |

### 選択肢 D：お客様持ち込み楽曲

| 項目 | 内容 |
| --- | --- |
| 対象 | お客様がリクエストする「思い出の曲」 |
| 権利処理 | 個別に楽曲権利者・レコード会社と交渉 |
| メリット | 顧客満足度が圧倒的に高い |
| デメリット | **権利処理が極めて困難**／コストが読めない／無断利用は法的リスク大 |
| 推奨度 | ★★☆☆☆（条件を絞って提供） |

## 3. 推奨方針（事業初期）

### 基本プラン（19,800 円〜69,800 円）

**選択肢 B（ロイヤリティフリー音源）を主軸**とする。

- メインサービス：**Audiostock 月額または Epidemic Sound 月額** で日本語の和風・ピアノ・抒情系楽曲を主に使用
- お客様には **当社が用意した 30〜50 曲のサンプル**から選んでいただく
- 「BGM はお選びいただいたサンプルから当社編集者が最適に組み合わせ」と LP に明示

### オプション：オーダーメイド BGM（+9,800円〜）

選択肢 C（**Audiostock の有料カスタム楽曲**または個人作曲家への依頼）を組み合わせ提供。

### 慎重対応：お客様持ち込み楽曲

- 原則として「お客様ご自身で権利処理を完了済みの楽曲のみ受付」とする
- 一般的なメジャー楽曲（J-POP、昭和歌謡など）は、**「リクエスト承り → 同等の雰囲気のロイヤリティフリー楽曲を提案」**で代替
- 個別に楽曲権利処理が必要な場合は、別途見積もり（+50,000〜200,000 円程度）

## 4. 契約前のチェックリスト

選定したサービスについて、以下を必ず確認してください。

- [ ] 商用利用の可否（明示的に許可されているか）
- [ ] 完成動画の納品形態（DVD/Blu-ray/USB）に制限がないか
- [ ] お客様への二次提供（DVD を販売することは無いが、お客様が家族に共有する行為）が許諾範囲に含まれるか
- [ ] YouTube・SNS へのアップロードを含む場合の制限
- [ ] 1 契約で複数の編集者が利用できるか（複数ライセンスが必要か）
- [ ] 解約時の既存制作物の継続利用可否
- [ ] クレジット表記義務の有無
- [ ] サポートおよび紛争対応の責任所在
