# AI 補完シーン制作ガイドライン（ドラフト v0.1）

> ⚠️ **これは社内運用ガイドラインです。**
> 編集者・営業担当・カスタマーサポート全員が本ガイドラインに従って業務を行うものとします。
> 更新時は全関係者へ通知してください。

---

## 1. ガイドラインの目的

本ガイドラインは、「想い出補完オプション」を提供するにあたり、以下の 3 つの責任を果たすために定めるものです。

1. **ご依頼者・ご家族の心情への配慮**：感情を害さない、安心して受け取れる仕上がりを担保する。
2. **法的・倫理的リスクの回避**：肖像権・著作権・公序良俗等の問題を未然に防ぐ。
3. **当社サービスへの社会的信頼の維持**：「AI 技術の不適切利用」と見なされる事態を回避する。

## 2. 生成 OK / NG の判断基準

### 2.1 生成 OK（標準対応）

以下に該当する場合は、通常のフローで生成可能。

| 区分 | 例 |
| --- | --- |
| 被写体本人の存命中の姿の補完 | 「3 歳〜5 歳の写真が無い」「20 代の写真が無い」など |
| 故人の生前の姿の補完 | 「祖父が若かった頃の写真が無い」など、ご依頼者が直系親族の場合 |
| 場所の補完 | 当時の住んでいた地域の風景（被写体は写さない） |
| 服装・髪型の再現 | ご依頼者・ご家族からの記憶情報をもとに |

### 2.2 生成 NG（絶対に対応しない）

以下に該当する場合は、**ご依頼があっても明確にお断り**する。

| 区分 | 理由 |
| --- | --- |
| **故人の死後の姿** | 「天国にいる故人」「天使になった故人」等の表現 | 宗教的価値観の押し付け、家族間の感情対立を招く |
| **存在しない出来事の捏造** | 「故人が孫の結婚式に参列する映像」「実際は離婚した夫婦の老後の幸せな様子」等 | 事実誤認・記憶の改変、後の家族不和の原因 |
| **第三者（被写体・依頼者以外）の生成** | 故人の友人、別れた配偶者、未承諾の家族など | 肖像権・パブリシティ権の侵害 |
| **政治・宗教メッセージ性のある内容** | 戦争賛美、特定宗派の宗教儀礼の演出など | 公共性の問題 |
| **性的・暴力的表現** | 不適切な姿態、暴力シーンなど | 言うまでもなく |
| **未成年（13 歳未満）の AI 生成画像** で、依頼者が親族以外 | グルーミング・児童虐待コンテンツのリスク回避 | 国際的な児童保護基準 |
| **生前にデジタル再現を拒否していた故人** | ご依頼者にヒアリングし、故人の意思を確認 | 故人の自己決定権の尊重 |
| **公人・有名人の生成** | 同意なき公的人物の生成 | パブリシティ権の侵害 |

### 2.3 グレーゾーン（ヒアリングのうえ個別判断）

判断に迷う場合、必ず以下を確認のうえ **責任者（〔役職〕）の承認**を得る。

- 生まれてすぐ亡くなった子の「成人した姿」の生成
- 認知症等で生前の意思確認が難しかった故人の生成
- 国際的なバックグラウンドを持つ被写体（文化的配慮が必要な場合）
- ご依頼者の心理状態が不安定と見られる場合（過度な期待・喪失感の長期化）

## 3. 制作プロセスの遵守事項

### 3.1 ヒアリング段階

- [ ] ご依頼者の関係性確認（被写体本人／直系親族／その他）
- [ ] 故人の場合、他の遺族の同意状況の確認
- [ ] 生前にデジタル再現拒否の意思表示がなかったかの確認
- [ ] 生成希望シーンの具体的内容のヒアリング（年齢・場所・服装・状況）
- [ ] 同意書への署名取得
- [ ] **本ガイドラインの NG 項目に該当しないかのチェックリスト記入**

### 3.2 生成段階

- [ ] ベースとなる実写写真の選定（被写体の特徴を最も反映するもの）
- [ ] 同一人物性を保つためのリファレンス設計
- [ ] 初稿生成（候補 3 パターン程度）
- [ ] **「memory」マーク・色調変化等の演出**を施す

#### ツール選定の原則：ローカル処理優先

写真補正・色補正・キズ修復・ノイズ除去・解像度向上等の工程は、**当社内のローカルツール（ローカル GPU で動作する OSS／買い切り型ソフト等）での処理を優先採用**する。クラウド AI の使用は、AI 中間補間（動画化）等、ローカルでの代替が技術的に困難な工程に限る。お預かり写真を継続送信するサブスク型クラウド補正サービス（Remini、Pixelcut 等）は採用しない。

### 3.3 確認・承認段階

- [ ] ご依頼者（および可能であればご家族）への内部試写
- [ ] フィードバックを受けて 1〜2 回まで無償修正
- [ ] 最終版の確認サインを取得（メールでも可）
- [ ] 最終承認後、完成動画に組み込み

### 3.4 納品後

- [ ] 完成動画と同意書を案件番号で紐づけて保管（10 年間）
- [ ] 元の写真等は規定の保管期間後に削除（プライバシーポリシーに準拠）
- [ ] アフターフォロー：納品 1 ヶ月後にお客様の感想をヒアリング

## 4. 演出仕様（必須）

### 4.1 視覚的区別

AI 生成シーンには、以下のいずれか（または複数）を必ず適用する。

| 演出 | 仕様 |
| --- | --- |
| **「memory」マーク** | 動画右上に小さく「memory」のテキストまたはアイコンを表示 |
| **色調変化** | 全体に薄いセピア・水彩風フィルターを適用 |
| **ソフトフォーカス** | 微細なソフトフォーカス効果（実写との触感的な差別化） |
| **エッジのぼかし** | フレーム端にうっすらと羽根ぼかし |

### 4.2 字幕・テロップ

シーン開始時に、以下のような字幕を最低 1 秒間表示する。

- 「想い出補完シーン」
- 「— もし写真が残っていたら —」
- 「memory（記憶より）」

### 4.3 音声の取扱い

- AI 生成シーンには、**当人の声を AI で再現することは行わない**
- ナレーション・BGM のみで構成する

## 5. 編集者・営業担当の心構え

### 5.1 言ってはいけない言葉

| NG ワード | 言い換え |
| --- | --- |
| 「故人を蘇らせる」「復活させる」 | 「想い出を映像として残す」 |
| 「本人そっくり」「本物のような」 | 「当時の様子を想像して描く」 |
| 「AI が勝手に作る」 | 「お客様と一緒に作り上げる」 |

### 5.2 ご依頼者への接し方

- ご依頼者の動機（喪失感の長期化、罪悪感、未練など）に**寄り添うが、無理に解消させない**
- 期待値コントロール：「100% 本人と同じものは作れません。あくまで想像の表現です」を**繰り返し丁寧に伝える**
- 完成物への反応が**予想と異なる場合に備えた対応シナリオ**を準備しておく
- 心理的負荷が大きいと判断した場合、グリーフケア専門家への紹介を提案

## 6. 緊急時対応

### 6.1 ご依頼者・ご家族からのクレーム発生時

1. 編集担当は即座に責任者へエスカレーション
2. 完成動画の納品を一時停止
3. 24 時間以内にご連絡し、ご事情をヒアリング
4. ご希望に応じて、AI 生成シーンの削除・全額返金等で対応

### 6.2 SNS で炎上等の事態が発生した場合

1. 広報担当へ即座にエスカレーション
2. 関係者（ご依頼者・編集者・経営層）への状況共有
3. 公式声明の準備：事実関係・対応方針・再発防止策
4. 必要に応じて弁護士相談

---

## 7. ガイドラインの改訂

本ガイドラインは、以下の場合に必ず見直し・改訂を行う。

- 関連法令（個人情報保護法、AI 関連法等）の改正時
- 社内で重大なインシデントが発生した時
- 同業他社で社会問題化する事例が発生した時
- 6 ヶ月ごとの定期見直し
