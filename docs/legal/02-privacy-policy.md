**個人情報保護方針（プライバシーポリシー）**

〔会社名〕（以下「当社」といいます）は、自分史ムービー制作サービス「人生タイムラプス」（以下「本サービス」といいます）の提供にあたり、お客様の個人情報を適切に取り扱うことが社会的責務であると認識し、以下のとおり個人情報保護方針を定め、遵守します。

## 1. 個人情報の定義

本ポリシーにおいて「個人情報」とは、個人情報の保護に関する法律（以下「個人情報保護法」といいます）第 2 条第 1 項に定める個人情報、すなわち生存する個人に関する情報であって、当該情報に含まれる氏名、生年月日その他の記述等により特定の個人を識別することができるもの（他の情報と容易に照合することができ、それにより特定の個人を識別することができることとなるものを含みます）、または個人識別符号が含まれるものをいいます。

## 2. 取得する個人情報の項目

当社は、本サービスの提供にあたり、以下の個人情報を取得することがあります。

| 区分 | 項目 |
| --- | --- |
| 申込者情報 | 氏名・住所・電話番号・メールアドレス・支払情報 |
| 被写体情報 | お預かりする写真・動画に含まれる人物の容貌・氏名・年齢・関係性 等 |
| ヒアリング情報 | ご本人の人生のエピソード、家族構成、ライフイベントの時期等 |
| 任意提供情報 | ナレーション用音声、ご家族からのメッセージ等 |
| 自動取得情報 | ウェブサイト閲覧時の Cookie・IP アドレス・アクセスログ |

### 要配慮個人情報の取扱いについて

写真には、ご本人の信条・宗教・健康状態・障害等の情報が映り込む場合があります。当社は、これらの**要配慮個人情報**について、お客様からの明示的な同意取得のうえで取得し、本サービスの目的の範囲内でのみ使用します。

## 3. 個人情報の利用目的

当社は、取得した個人情報を以下の目的で利用します。

1. 本サービスの提供（写真の編集、動画の制作、納品等）
2. お客様からのお問い合わせへの対応
3. お客様への重要なお知らせ（納品連絡、規約変更等）
4. お支払いの管理
5. 法令に基づく対応
6. お客様の事前同意を得た場合のみ、お客様事例としてのウェブサイト・SNS・営業資料への掲載
7. お客様の事前同意を得た場合のみ、新サービス・キャンペーン等のご案内

## 4. 個人情報の第三者提供

当社は、以下の場合を除き、お客様の個人情報を第三者に提供しません。

1. お客様の同意がある場合
2. 法令に基づく場合
3. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
4. 国の機関等が法令の定める事務を遂行することに対して協力する必要がある場合
5. 業務委託先（後述）に対して、業務遂行に必要な範囲で提供する場合

## 5. 業務委託先への提供

当社は、以下の業務委託先に対し、業務遂行に必要な範囲で個人情報（写真等を含む）を提供することがあります。委託先には、当社と同等以上の安全管理措置を講じることを契約により義務付けます。

| 委託内容 | 委託先の種別 |
| --- | --- |
| 動画編集・AI 処理 | 編集者・AI クラウドサービス事業者 |
| 物理メディア制作 | DVD・Blu-ray プレスメーカー |
| 配送 | 運送事業者 |
| 決済処理 | 決済代行事業者 |
| サーバ運用 | クラウドホスティング事業者 |

### AI 処理に関する補足

当社は、AI 処理に外部のクラウド AI サービス（例：Runway、Kling、Luma 等）を利用することがあります。利用にあたり、当社は以下の措置を講じます。

- 学習データとして再利用されない契約形態の API を選択
- 処理完了後、速やかに送信データの削除を要請
- 海外サーバへの転送が発生する場合は、第 7 項に従いお客様の同意を取得

## 6. 個人情報の保管期間

| 区分 | 保管期間 |
| --- | --- |
| 紙焼き写真の原本 | 納品後 〔30〕 日以内にお客様へ返送 |
| デジタル写真データ | 納品後 〔90〕 日後にサーバから削除 |
| 完成物のマスターデータ | 納品後 〔1〕 年間保管（再制作対応のため） |
| 申込者情報・取引記録 | 法令の定めに従い、最終取引日から 〔7〕 年間保管 |
| 同意書・契約書 | 取引終了後 〔10〕 年間保管 |

## 7. 外国にある第三者への提供

当社が利用する AI クラウドサービス等の一部は、サーバが海外（主に米国・EU）に所在することがあります。当社は、以下の場合を除き、海外への個人情報の移転は行いません。

1. お客様の同意がある場合
2. 提供先が個人情報保護委員会の規則で定める基準に適合する体制を整備している場合

## 8. 個人情報の安全管理措置

当社は、個人情報の漏えい、滅失または毀損を防止するため、以下の安全管理措置を講じます。

| 区分 | 措置内容 |
| --- | --- |
| 組織的 | 個人情報保護管理者の選任、社内規程の整備、定期的な点検 |
| 人的 | 従業者・委託先への教育、秘密保持契約の締結 |
| 物理的 | 入退室管理、紙写真等の施錠保管 |
| 技術的 | アクセス制御、通信の暗号化（SSL/TLS）、データ暗号化、ウイルス対策 |

## 9. 開示・訂正・利用停止等の請求

お客様は、当社が保有するお客様の個人情報について、以下の請求を行うことができます。

- 利用目的の通知
- 開示（電磁的記録の提供を含む）
- 訂正・追加・削除
- 利用停止・消去
- 第三者への提供の停止

請求の手続きは、第 11 項のお問い合わせ窓口までご連絡ください。本人確認のうえ、合理的な期間内に対応します。

## 10. Cookie の使用

当社ウェブサイトでは、サイト利用状況の把握とサービス改善のため Cookie を使用します。お客様はブラウザ設定により Cookie の受け入れを拒否できますが、一部機能が利用できなくなる場合があります。

| Cookie 種別 | 用途 |
| --- | --- |
| 必須 Cookie | サイトの基本機能維持 |
| 解析 Cookie | Google Analytics 等によるアクセス解析 |
| 広告 Cookie | 広告配信の最適化（ユーザー同意を得た場合のみ） |
