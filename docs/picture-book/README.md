# 人生が変わる3分絵本 — AI絵本チャンネル事業

> 新規事業。既存の「人生タイムラプス事業」とは別ライン。
> 本事業の意思決定もルートの `CLAUDE.md`（Steve Jobs の経営原則）に従う。

---

## 0. ひとことの約束（宇宙にへこみを残す）

**「3分で、誰かの人生のスイッチが入る物語を、毎日届ける。」**

動画を売っているのではない。BGMでも作画でもない。
売っているのは **気づき・希望・勇気** ——つまり「明日の生き方が変わる小さな物語」だ。

---

## 1. なぜやるか

- 感動だけでなく **副業・挑戦・自己肯定感・人生逆転** までテーマを広げられる。市場が大きく、将来の商品化（電子書籍・教材・コーチング）に繋がる。
- 入口は YouTube。そこで **信頼貯金** を積み、LINE で関係を深め、商品で回収する。
- 最初から動画品質に凝らない。**静止画＋ナレーション**で最速検証する。これが現時点で一番効率が良い。

## 2. プロダクトの本質（ここを間違えない）

| 勘違いしやすい | 本当のプロダクト |
| --- | --- |
| 「絵本動画」を作る事業 | **タイトルと物語**を作る事業 |
| 自動化が価値 | 自動化は「タイトル・物語以外の全工程」を消すための手段 |
| 1本でバズる | **30本で当たりの型を見つけるデータゲーム** |

> タイトルは動画内容より大事。感情が動くタイトルだけ作る。
> 例：「誰にも期待されなかった少年が最後に見せた奇跡」「亡くなった父から届いた最後の手紙」

## 3. ビジネスモデル（4フェーズ）

1. **YouTube収益化** — 登録1,000人／視聴4,000時間
2. **LINE誘導** — 信頼を関係に変える
3. **電子書籍・絵本販売**
4. **副業教材・コーチング・コミュニティ**

`入口 YouTube → 信頼 → LINE → 商品`

## 4. ターゲット

30〜60代の会社員・主婦・副業層・人生に悩む人。
提供価値は **感動・気づき・希望・勇気**。

## 5. 制作フロー（静止画＋ナレーション）

```
STEP1 ネタ決め
STEP2 ChatGPT 脚本（10シーン・約1000字）
STEP3 ChatGPT 画像プロンプト生成
STEP4 Google Flow 画像10枚生成   ← ※旧 Magic Light AI から変更
STEP5 AI音声 ナレーション
STEP6 静止画スライド動画化（本編3〜5分）
STEP6.5 ショート切り出し（60〜90秒・副産物＝入口）
STEP7 YouTube 投稿（本編＋ショート）
```

> 尺フォーマット（CEO決裁 2026-06-17）：本編は**3〜5分**。同じ素材から**60〜90秒のショート**を切り出して新規リーチの入口にする。総集編は当たりが出てから束ねる。

1本20〜30分。**社長が触るのは最後の2点だけ**：
- **承認ゲートA**：物語＆タイトルのGO
- **承認ゲートB**：完成動画＆投稿のGO

それ以外は AI社員＋ツール（Make.com / Notion / Drive / Gmail / Calendar / Canva）で自動化する。

## 6. やってはいけない / やるべき

| ❌ やらない | ⭕ やる |
| --- | --- |
| 動画品質に凝る | 毎日投稿 |
| 編集に凝る | タイトル改善 |
| BGM探しに時間を使う | ストーリー量産 |
| 1本でバズろうとする | 数字分析（上位5本の共通点→同ジャンル量産） |

## 7. 成功判断基準

30本投稿 → 分析 → 再生数上位5本抽出 → 共通点分析 → 同ジャンル量産。
