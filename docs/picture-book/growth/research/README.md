# 外れ値ショート調査 — 方法・限界・示唆

**作成**: 2026-06-17 / **担当**: Growth Lead
**指示元**: 社長「大人向け感動系ショートで、直近半年バズったもの。特に小チャンネルなのに高再生の外れ値を、再生数÷チャンネル平均で50本CSV納品」
**成果物**: `viral-outlier-shorts.csv`（同ディレクトリ）

> このリポジトリは「センスで当てない、当たりを観測して増やす」設計（channel-strategy §4）。
> 本調査は他人の当たりデータを盗む第一弾（CLAUDE.md §14）。ただし**数字を捏造しない**ことを最優先した。

---

## 0. 結論サマリ（先に正直に）

- **集めた実在動画：50本**（CSVの全行が実在URL）。
- **再生数まで確認できた本数：36/50**。残り14本は「実在は確認・再生数は未取得」。
- **再生数の確認方法＝動画タイトル/検索スニペットに作者自身が書いた「㊗️200万再生」等の表記**。第三者の計測値ではないため信頼度は**「推定（作者申告）」**。
- **外れ値比（再生÷平均）を算出できた本数：30/50**。ただしこの「平均」は**本調査で拾えた同系統動画だけのサンプル内平均**であり、チャンネルの真の平均ではない（後述§3の限界）。
- **登録者数：全件「未確認」**（YouTube/Social Blade が 403 で取得不可）。よって「登録者が少ないのに高再生」という外れ値の**登録者軸は本調査では実証できていない**。CSVの外れ値比は**再生数の軸のみ**で出している。

正直に言う：社長の指定した「再生数÷チャンネル平均」の理想形（チャンネル全体の平均で割る）は、**機械的なAPI接続なしには本物の数字で埋まらない**。本書§4にその正攻法を具体的に書いた。今のCSVは「実在URL＋作者申告の再生数」という**検証可能な土台**であり、§4を実行すれば確定値に上書きできる設計にしてある。

## 1. 各列の定義

| 列 | 定義 |
| --- | --- |
| 順位 | 外れ値比の降順。算出できない行は再生数順→未確認を末尾に配置 |
| 動画タイトル | 検索スニペットに出た実タイトル（絵文字・装飾は一部整形） |
| チャンネル名 | **「○○系（推定）」＝検索結果からの系統推定**。個別チャンネルページが403で開けず、正式名を断定できないため。確定名は§4で要採取 |
| 登録者数 | 全件「未確認」（403で取得不可） |
| 再生数 | **作者がタイトルに明記した数字のみ**。なければ「未確認」。創作値は一切なし |
| チャンネル平均再生数 | 同系統動画の**本サンプル内平均**（シニア朗読系=120万/2ch感動スレ系=209万）。真の平均ではない（§3） |
| 外れ値比 | 再生数÷上記サンプル内平均。算出不能は空欄 |
| 動画URL | 実在URL（youtube.com/shorts/… 等） |
| テーマ | 親子・介護・シニア恋愛・リストラ・動物・2ch名言 等 |
| フックの型 | わがチャンネル `title-formula.md` の型①〜⑦に分類（活用のため） |
| 投稿日 | スニペット由来。多くは「（推定）」。確証なしは「未確認」 |
| データ信頼度 | 確証/推定/未確認。本調査は構造上ほぼ「推定」or「未確認」 |
| 出典URL | 当該動画URL（一次）。スニペット表示元 |

## 2. 調査方法

1. **WebSearch を15種類以上のクエリで実行**（「感動 shorts 万再生 2025」「スカッと シニア 朗読 万回突破」「2ch感動スレ 迷言集」「泣ける 動物 shorts」「結婚式 サプライズ 父 涙」等）。並行で Explore サブエージェント2体に追加のファンアウト探索を委任。
2. **YouTube/Social Blade への直接 fetch は全て 403 Forbidden**（bot拒否）。よって**検索結果スニペットに出る情報だけを根拠**にした。
3. 再生数は**作者がタイトルに自分で入れた「㊗️○万再生／○万回突破」表記**を採用。これは「作者の自己申告だが実在し、虚偽の動機が薄い（再生数は伸ばし過ぎると後で剥がれる）」という意味で**推定値としては比較的堅い**。それでも第三者計測ではないので信頼度は「推定」。
4. 同系統で複数本の再生数が取れた2クラスタ（シニア朗読系21本／2ch感動スレ系6本）について、**サンプル内平均を出して外れ値比を計算**。

## 3. データの限界（正直な開示）

- **登録者軸が欠落**：社長の狙い「小チャンネルなのに高再生」の核心は登録者数だが、403で全件未取得。**今のCSVは登録者の少なさを証明していない**。
- **「チャンネル平均」が真の平均でない（選択バイアス）**：拾えたのは作者が「○万再生」と誇示した**勝ち動画ばかり**。チャンネルの外れ値でない（=数千〜数万再生の）動画は検索に出ない。
  → つまり**本物の平均はもっと低い**はず。**真の外れ値比はCSVの値より大きく出る**可能性が高い。CSVの比は**保守的な下限**と読むべき。
- **チャンネル名が推定**：同系統に酷似フォーマットが乱立しており、個別動画がどのチャンネルかをページ確認できていない。
- **投稿日が推定**：スニペットの相対表記（「○週間前」等）から逆算した推定を含む。
- **「直近半年」の厳密性**：多くが2025後半〜2026前半に収まるが、参考として #34「草むしり」（2023年）等の期間外も型の参考に1件含めた（信頼度欄に明記）。

## 4. 数字を実数で確定する正攻法（これをやれば推定→確証になる）

社長指定の「再生数÷チャンネル平均」を**機械的に本物の数字で埋める**手順。Make.com（既に ops で接続済みの自動化基盤）から回すのが最短。

### A. YouTube Data API v3（最も正確・推奨）
1. Google Cloud で API キー発行（無料枠：1日1万ユニット。1動画照会=1ユニット程度。本件は十分）。
2. **動画の確定再生数**：`videos.list?part=statistics&id=<videoId>` → `viewCount`（実数）。CSVの videoId（URL末尾）をそのまま投げる。
3. **チャンネルの確定平均**：
   - `search.list?channelId=<id>&order=date&type=video&maxResults=50` で直近50本の videoId を取得、
   - `videos.list?part=statistics&id=<50件カンマ区切り>` で各 viewCount を取得、
   - **平均 = Σ viewCount ÷ 本数**。これが「真のチャンネル平均」。
   - チャンネルの登録者：`channels.list?part=statistics&id=<id>` → `subscriberCount`。
4. **外れ値比 = その動画の viewCount ÷ チャンネル平均**。これで CSV の「推定」列を「確証」に上書きできる。
5. **Make.com 実装**：HTTP モジュール（GET）→ JSON パース → スプレッドシート/Notion 書き戻し。CSVの videoId 列をトリガーに回せば50本を自動充填できる。

### B. Social Blade / vidIQ（API無しの代替）
- **Social Blade**：チャンネルの登録者・総再生・直近の伸びを表示。ただしブラウザ直アクセス前提（本環境からは403）。有料の Social Blade API（Business）なら機械取得可。
- **vidIQ**：ブラウザ拡張で各動画の「再生/登録比」「VPH（時間あたり再生）」を表示。**競合の外れ値を手動で当たる用途に最適**。運用担当のブラウザに入れておく。

### C. 運用ルール化（channel-strategy §4 と接続）
- 上記Aを**月1回バッチ**で回し、本CSVを「確証」値で更新。
- 同時に**自社チャンネルの全動画も同じ式で外れ値比を計算**し、自社の勝ち動画を機械抽出（探索3割・活用7割の「活用」側の根拠データにする）。

## 5. 小チャンネルが跳ねる共通点トップ3（わがチャンネルへの示唆）

※登録者軸は未実証のため、「**同系統で他より跳ねた動画**＝外れ値比が高い動画」の共通点として抽出。CSVの上位（比1.4〜2.3）と下位の差から逆算。

### ① 「肩書き×逆転」の落差が大きいほど跳ねる
- 上位：「""汚い作業着の父""を笑った母親の末路」（比2.33）、「ボロ服の老夫婦を馬鹿にした寿司店主が…」（比1.66）。
- **低い者・侮られた者が、最後に立場を逆転する落差**が大きい動画ほど比が高い。`title-formula.md` 型①「欠落→逆転」のド真ん中。
- **示唆**：わが第1話「49歳リストラ→パン屋」は方向は正しい。**冒頭で""どれだけ低いか""を強く見せる**ほど、ラストの跳ね返りが効く。

### ② 「具体的な数字・セリフ」が入った動画が同系統内で抜ける
- 上位に「5000円の猫」「日給100円のヤクザ」「千円!?加藤茶が絶句」等、**具体的な金額・カギ括弧のセリフ**を持つ動画が集中。
- **示唆**：`title-formula.md` 型⑤（数字の奇跡）・型⑥（セリフ引用）はデータと整合。**抽象語より、生々しい固有名詞・金額・一言**をタイトルに必ず1つ入れる。

### ③ 「日常の一場面＋""見た理由""の空白」がクリックを生む
- 「定食屋で女性がチラチラと私を見る衝撃の理由」（比1.75）、「病院で若い女性が…信じられない理由」など、**ありふれた場面＋""理由が伏せられている""**型が安定して上位。
- **示唆**：型③（目撃）＋型⑦（省略・途切れ）の組み合わせが最強という既存仮説（`viral-benchmark.md`）を裏づけ。**「○○した理由」「○○したこと」で止める語尾**を標準装備にする。

### 補足の構造的発見（外れ値の母体について）
- 跳ねている系統は**「シニア朗読／2ch感動スレ／芸能実話」の量産型**。**同一フォーマットを毎日大量投下し、その中の数本が跳ねる**という、まさに channel-strategy §4 のデータゲームを地で行く構造。
- つまり**「1本を磨いて当てる」より「型を固定して数を撃ち、跳ねた1本を増幅する」**のがこのジャンルの勝ち方。わがチャンネルの量産運用方針は市場の勝ち筋と一致している。
