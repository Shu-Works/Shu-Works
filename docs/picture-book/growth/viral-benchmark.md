## 0. 調査方法と信頼度の正直な開示

- **手段**: WebSearch（YouTube検索結果・業界ブログ）を使用。
- **制約**: YouTube のチャンネル/動画ページへの直接 fetch は **403 でブロックされた**（YouTubeはbot fetchを拒否）。
  そのため**個別動画の正確な再生数・登録者数・尺は一次取得できていない**。チャンネルの実在と方向性は検索結果で確認済み。数値は「推定」と明記する。
- **結論の信頼度**: チャンネルの**実在・ジャンル・フォーマット傾向＝高**。**個別の再生数・登録者数の精密値＝低（要・YouTube実機での再確認）**。
- 次アクション：運用開始時に YouTube Studio / 検索の実機で上位動画の数値を採取し、本書を更新する。本書は「仮説の土台」であり「確定データ」ではない。

## 2. タイトルの当たりパターン（実例から逆算）

検索で表に出た実タイトル例（感ちゃん系）：
> 「【感動する話】独身の俺についてきた子供『お手伝いするから仕事教えて』と言ってきた。すると、子供の母親が現れ…【いい話・泣ける話・朗読】」

ここから抜き出せる**当たりの構造**：

### 抽出パターンA：「セリフを直接引用する」型 ★既存formulaに無い・追加すべき
- 構造：［状況］＋**「キャラの生のセリフ」**＋［…で引く］
- 効く理由：カギカッコのセリフは**人の声に聞こえ**、ナレーション動画との相性が抜群。具体的で生々しく、状況が一瞬で立ち上がる。
- 例：『お手伝いするから仕事教えて』のように、**子ども・弱者・健気な人物の一言**が刺さる。

### 抽出パターンB：「…で途切れさせる」型（省略法）★既存formulaに無い・追加すべき
- 構造：本文の山場の直前で「**すると…**」「**現れ…**」と**三点リーダで切る**。
- 効く理由：未完の文は脳が補完できず、クリックで続きを取りに行く。formula §0「結末をほのめかすが見せない」の**最も実装的な形**。

### 抽出パターンC：「ブラケット・タグ盛り」型
- 構造：本タイトル＋【感動する話】【いい話】【泣ける話】【朗読】を**末尾に複数付与**。
- 効く理由：検索・関連表示でのジャンル一致を稼ぐ。ただし**やりすぎると安っぽい**。我々は冒頭1個＋末尾1個に絞り、情緒で差別化する（CLAUDE.md §6 削るのが達人）。

### 既存 `title-formula.md` との突き合わせ結論
- 既存の5型（欠落→逆転／最後の手紙／目撃／問いかけ／数字の奇跡）は**実在の当たり構造と整合**。方向性は正しい。
- **足りなかった型＝2つ。`title-formula.md` に追記推奨**：
  - **型⑥ セリフ引用型**（パターンA）
  - **型⑦ 省略・途切れ型**（パターンB／既存5型すべてに重ねられる「語尾の技法」）

## 3. サムネの当たりパターン（業界CTRデータ＋顔の効果から）

データ根拠（lel-japan / 0120.co.jp / マーケトランク）：
- **CTRベンチマーク**：3〜5%が普通、**7〜9%が優秀**、10%が理想。（channel-strategy の「5%以上」は妥当な合格ライン）
- **顔は最強**：感情のある顔をアップで、**最低でも画像の1/3**を占める。無表情はダメ、**感情を出す**。カメラ目線が有効。
- **文字は最小**：主メッセージは**15文字以内**。中央 or 左右に大きく。情報を詰めない。

### 我々の当たりサムネ仕様（仮説・A/Bで検証する）
| 要素 | 推奨 | 根拠 |
| --- | --- | --- |
| 顔の有無 | **あり（人物の顔を大きく）** | 顔ありはCTRが上がる。本ジャンルは感情の動画＝表情が商品 |
| 表情 | **泣き顔／うつむき／こみ上げる笑顔**（感情のピーク） | 「感情のある顔」がCTRに効く |
| 文字量 | **9〜13文字、1〜2行まで** | 15文字以内ルール。絵本の美意識的にも少文字が映える |
| 色 | **暖色（夕暮れ・電球色）or 高コントラストの差し色1色** | 感動＝温かみ。ただし埋もれない彩度を1点だけ立てる |
| 構図 | 顔を画面の1/3〜1/2、視線誘導が文字に向かう | CTRデータ＋絵本の余白美 |
| 差別化 | 他社の「安い素材写真」と違い、**統一された絵本タッチの一枚絵** | channel-strategy §2「使い回しで安っぽい競合」との差 |

注：絵本タッチで「顔のアップ＋感情」を成立させる必要あり。**production と要すり合わせ**（サムネ専用カットを各話1枚作る運用）。

## 4. 尺・投稿頻度・フォーマットの傾向 ★最大の発見はここ

業界データ（mteam / frontier-pr / YouTubeヘルプ）から判明した、**正直に言うべき事実**：

### 発見：このジャンルは「尺が二極化」している。2〜3分は実は中途半端な可能性が高い。

1. **収益化の観点**：YouTubeのミッドロール広告は**8分以上**で挿入可能。2〜3分動画は広告枠が前後しか取れず、**1再生あたりの収益が構造的に低い**。
2. **本ジャンルの王道は長尺**：感動朗読・睡眠用・作業用は「**ながら聴き**」需要が太く、**20〜40分以上**の長尺が登録と総再生時間（＝収益化要件4,000時間）を稼ぐ。1本で複数話を束ねる「総集編」型が定番。
3. **一方でショートは入口として最強**：YouTubeショートは**最長3分**まで対応。縦型1〜3分は新規発見（リーチ）に強い。

### 結論：「2〜3分1本勝負」は再考すべき。推奨は二刀流。

| 役割 | 尺 | 目的 |
| --- | --- | --- |
| **ショート（縦型 60〜90秒）** | 短 | **発見・リーチ・登録の入口**。冒頭で泣かせて「続きは本編」へ送客 |
| **本編（横型）初期：3〜5分** | 中 | データゲームの探索弾。1話完結。**質を担保しやすく量産可能** |
| **本編（横型）成長後：15〜30分の総集編** | 長 | **総再生時間4,000時間と収益化**を取りに行く。勝ち話を3〜5本束ねる |

- channel-strategy §4のデータゲーム（毎日量産）は**3〜5分の1話完結＋ショート**で回すのが現実的。
- 登録1,000人/4,000時間の「4,000時間」は短尺だけだと**極めて遠い**。総集編の長尺を**フェーズ途中で必ず投入**する設計に変更すべき。
- **Jobsへの確認事項**：「2〜3分」という当初フォーマット前提を、「**ショート＋3〜5分本編＋総集編長尺**」の三段構成に修正してよいか。これは戦略変更につき要決裁。

### 投稿頻度
- 検索データ・channel-strategy 共通で「**毎日投稿を切らさない**」が鉄則。ショートは特に**日次供給**が効く（アルゴリズムが新規面に出しやすい）。

### 推し3本（Growth Lead の判断）

- **【推し①】#1「リストラされた49歳が、コンビニで拾った一冊のノートに書いてあったこと」**
  第1話そのもの。§2-Bの「途切れ＝続きを取りに行く」が最も綺麗に効く。状況・主語（49歳・自分かもしれない）・空白が三拍子。

- **【推し②】#4「『ここのパン、世界一おいしい』——その一言が、人生を諦めた男を変えた」**
  セリフ引用型（実在の当たり構造Aの直接適用）。ナレーション動画と最も相性が良く、サムネで「泣き笑いの顔＋このセリフ」を組める。サムネ連動が強い。

- **【推し③】#3「誰にも必要とされなかった49歳が、小さなパン屋で起こした奇跡」**
  チャンネルの中核「欠落→逆転」の本命型。最も安定して当たる型で、第1話の保険として外せない。3本でA/Bを回し、勝った型を量産に寄せる。
