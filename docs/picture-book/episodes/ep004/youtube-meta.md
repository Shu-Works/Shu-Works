## タイトル候補（5本）

1. 「主婦のお遊びでしょ」と笑われた一皿のお菓子が、寂れた商店街をもう一度灯した
2. 何もない普通の主婦だと思っていた私を変えたのは、亡き母が遺した一冊のレシピ帳
3. 取り柄なんてないと諦めた45歳。その手のひらに、ずっと宝物が眠っていた【感動絵本】
4. シャッター街でたった一人焼き続けた主婦。ある女の子の一言から、町が動き出した
5. 「私なんかに無理」と言った主婦が、一年後に町中を笑顔にした理由｜3分で泣ける物語

**制作部長の推し**：候補1（型①の構造＝「笑われた（欠落）」＋「商店街を灯した（逆転）」を1文で提示。「一皿のお菓子で町が」という飛距離が好奇心を引く）。A/B用に候補3を予備とする。

その言葉を棘のように抱えてきた、みどりさん。
取り柄も特技もない——そう思い込んでいました。

ある日、古い戸棚の奥から、亡き母のレシピ帳が出てきます。
最初のページには「みどりへ」の文字。

「主婦のお遊びでしょ」。笑われても、彼女は毎朝、焼き続けました。
そして一人の女の子の、たった一言から——。

あなたが「たいしたことない」と思っている、その小さなものは、本当に小さいでしょうか。

3分間、心を温めにきてください。
