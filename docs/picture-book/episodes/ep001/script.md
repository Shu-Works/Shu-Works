# ep001 脚本

**テーマ**: 人生逆転（制作部長判断で「親子」より「人生逆転」を採用）
**選定理由**: ターゲット（30〜60代・会社員・副業層・人生に悩む人）の「もう手遅れかもしれない」という不安に最も直接刺さる。「気づき・希望・勇気」の提供価値を1本で全部届けられる。
**ログライン**: 49歳で会社をリストラされ、すべてを失ったと思った男が、夜のコンビニの片隅で見つけた一冊のノートから、人生をやり直す。

**主人公キャラシート**（image-prompts.md と共通）:

## 【シーン01】
**ナレーション本文**：四十九歳の春、田村さんは会社を追われました。三十年、ただ真面目に働いてきただけの男に、もう居場所はないと言われたのです。
**画面メモ**：夕暮れ。ビルの前に立ち尽くす男の後ろ姿。手には段ボール箱。肩が落ちている。オレンジ色の光。

## 【シーン02】
**ナレーション本文**：家に帰っても、かける言葉は見つかりません。「お父さん、これからどうするの」。娘のひとことが、胸に深く刺さりました。
**画面メモ**：薄暗い居間。テーブル越しに向き合う父と高校生の娘。父はうつむき、娘は不安そう。

## 【シーン03】
**ナレーション本文**：眠れない夜が続きました。自分にはもう、何も残っていない。そう思い込んでいたのです。
**画面メモ**：深夜、窓辺に座る男。月明かり。背中だけが浮かび上がる。静かな孤独。

## 【シーン04】
**ナレーション本文**：ある夜、行き場のない足が、町外れのコンビニへ向かいました。誰もいない、静かな店内。
**画面メモ**：夜のコンビニの外観。青白い蛍光灯。ガラス越しに一人の客の影。雨上がりの路面が光る。

## 【シーン05】
**ナレーション本文**：レジの横の、忘れられた一冊のノート。表紙には、こう書いてありました。「やりたかったこと、ぜんぶ。」
**画面メモ**：レジ脇に置き忘れられた古いノートのクローズアップ。手書きの文字。男の手が伸びる。

## 【シーン06】
**ナレーション本文**：開いてみると、知らない誰かの夢が、びっしりと綴られていました。パン屋になりたい。海を見たい。もう一度、笑いたい。
**画面メモ**：ノートを開く男。ページに手書きの夢のリストが並ぶ。ひとつひとつの文字が温かく光る。

## 【シーン07】
**ナレーション本文**：田村さんは、はっとしました。自分には、やりたいことなど、ひとつもないと思っていた。本当は、見ないふりをしていただけだったのです。
**画面メモ**：店内、ノートを抱えて立ち尽くす男。表情が変わる瞬間。目が見開かれる。胸に手を当てる。

## 【シーン08】
**ナレーション本文**：翌朝、彼は小さなノートを買いました。そして、ためらいながら、最初の一行を書きました。「もう一度、パンを焼きたい。」
**画面メモ**：朝の光。新しいノートに万年筆で一文字目を書く手元のクローズアップ。窓から差す柔らかな光。

## 【シーン09】
**ナレーション本文**：それから二年。田村さんの小さなパン屋には、朝早くから行列ができるようになりました。あの娘も、隣でエプロンを結んでいます。
**画面メモ**：朝の小さなパン屋。湯気の立つパン。エプロン姿の父と成長した娘。明るい笑顔。客の行列。姿勢がまっすぐ。

## 【シーン10】
**ナレーション本文**：人生に、遅すぎるということはありません。失ったと思ったその場所こそ、新しい一歩が始まる場所なのです。あなたの「やりたかったこと」は、まだ、そこにありますか。
**画面メモ**：夕暮れの店先。並んだパンと、店の前に立つ父娘の温かい後ろ姿。空に一番星。希望に満ちた余韻。
