# 手動制作ランブック（最初の5本用）

> **目的**：自動化を組む前に、まず手で5本出して「当たりの型」を体感する。
> 脚本・画像プロンプト・ナレーション原稿・YouTubeメタは **第1〜5話とも作成済み**
> （`docs/picture-book/episodes/ep001〜ep005/`）。
> だから社長の手作業は **STEP4〜7だけ**。下のチェックを上から順に潰すだけでいい。
>
> 鉄則：**1本に凝らない。1本あたり画像生成8分・スライド7分でタイムボックス。**
> 粘りそうになったら「Real Artists Ship」と唱えて出す。

---

## 事前に1回だけ（全話共通の準備）

- [ ] **Google Flow** にログインできる状態にする
- [ ] **ElevenLabs**（本命・日本語/Multilingual v2）でナレーション声を**1声に固定**して決める ※代替：Google Cloud TTS Neural2
- [ ] **スライド化＆編集ツール = Filmora（確定）**。スライド化に加え、**ナレーションの切り取り（不要な間・言い直し・呼吸音のカット）も Filmora で完結**する。テンプレ（プロジェクト）を1つ作れば全話使い回す
- [ ] **BGM 3曲**だけストック（探さない。毎回この3曲から選ぶ）
- [ ] 字幕テンプレ（太ゴシック・白＋黒縁・下12%）を1つ作って保存
- [ ] OP3秒（タイトル＋「これはフィクションの物語です」）／ED3秒（チャンネル名＋登録誘導）のテンプレを作る

## 1本ぶんの手順（ep0XX）

### STEP4 画像10枚（Google Flow）— 目標8分
- [ ] 新規プロジェクト `ep0XX_タイトル` を作成
- [ ] `episodes/ep0XX/image-prompts.md` のプロンプトを**シーン1から順に**投入（各プロンプト先頭の共通画風ブロック＋キャラシートはそのまま使う）
- [ ] 各シーン2〜4枚出し、前シーンと**主人公の顔・服が連続する1枚**を採用
- [ ] 顔が別人化したら、引き構図（後ろ姿・遠景・手元・風景）に逃がす。**1シーン最大3回まで**で粘らない
- [ ] 採用画像を `img01.png`〜`img10.png` にリネームし `episodes/ep0XX/assets/` に保存

### STEP5 ナレーション音声（ElevenLabs）— 目標3分
- [ ] `episodes/ep0XX/narration.md` を**そのまま**貼り付けて生成
- [ ] 速度はやや遅め（0.9倍感覚）。固定した声で
- [ ] `assets/narration.mp3` として保存
- [ ] ※細かい切り取り（言い直し・不要な間・呼吸音）は STEP6 の Filmora 上でまとめて行う（ここで完璧にしない）

### STEP6 スライド動画化＆ナレーション編集（Filmora）— 目標7分（凝らない）
- [ ] Filmora の保存済みテンプレを開き、img01〜10 ＋ narration.mp3 を流し込む
- [ ] **ナレーションの切り取り**：不要な間・言い直し・呼吸音をカットし、各画像の尺に合わせる（凝らない・1本7分の枠内で）
- [ ] 各画像に**緩いズーム5%**だけ。トランジションはクロスフェード0.5秒の1種類
- [ ] 字幕は**各シーンのキーフレーズ1行だけ**（全文は出さない）
- [ ] OP3秒・ED3秒・BGM（ナレ時 -26dB）を乗せる
- [ ] 尺は2〜3分（`pipeline.md §5.2` の配分に従う）
- [ ] `assets/ep0XX.mp4` として書き出し

### 承認ゲートB → STEP7 投稿（YouTube）— 目標3分
- [ ] **社長が最終確認**：誤字・主人公の顔の連続性・流れ・フィクション明示
- [ ] `episodes/ep0XX/youtube-meta.md` の**推しタイトル**・説明文・タグを設定
- [ ] サムネ（meta記載の文言案）を設定 ※サムネ文字は大きく2行まで
- [ ] 公開 or 予約投稿（投稿枠は Google Calendar に従う）

## 5本ぶんの進め方（おすすめ運用）

1. **まず画像だけ5本分まとめて**生成する（Google Flowの頭が温まり速くなる）
2. 次にナレーション5本分をまとめて生成
3. 最後にスライド5本分をテンプレに流す
4. 投稿は**1日1本ペースで小出し**（同日に5本同時公開しない＝アルゴリズム的にも分析的にも不利）
5. 5本出したら必ず**数字を見る**：再生数・視聴維持率・クリック率（CTR）。
   - CTRが低い＝**タイトル/サムネの問題**（中身ではない）→ タイトル型を変えて再挑戦
   - 維持率が序盤で落ちる＝**冒頭15秒**の問題 → 脚本の掴みを強くする

## やってはいけない（時間泥棒リスト）

- ❌ 画像1枚に4回以上粘る（→引き構図に逃がす）
- ❌ BGMを新たに探す（→ストック3曲から選ぶ）
- ❌ トランジションや演出を増やす（→クロスフェード1種類で固定）
- ❌ 1本でバズろうと作り込む（→5本で型を探すデータゲーム）
