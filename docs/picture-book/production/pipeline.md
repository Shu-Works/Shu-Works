# AI感動絵本チャンネル 制作パイプライン

**チャンネル名**: 人生が変わる3分絵本（CEO確定）
**作成日**: 2026-06-17
**事業区分**: 新規事業（人生タイムラプス事業とは別事業）
**検証フェーズ**: 静止画＋ナレーションの 2〜3 分動画で、まず「刺さるか」を検証する。最初から凝った動画は作らない。

---

## 0. この事業の鉄則（CLAUDE.md より）

| 原則 | この事業での運用 |
| --- | --- |
| 22. Real Artists Ship | 80% で出す。完璧を待たない。1 本 20〜30 分で量産する |
| 11. One home run | テンプレ（画風・字幕・OP/ED）は **1 つだけ作り込む**。以降は全話使い回す |
| 6. シンプル | ツール候補を並べない。本命 1＋代替 1 のみ。判断を増やさない |
| データゲーム | 凝らずに本数を出し、再生数で「当たりテーマ」を見つける |
| 禁則 | 実在しない出来事を「事実」として人を欺かない。**フィクション絵本である旨を毎回明示** |

> 手抜きと安っぽさは別。BGM 探しに 30 分かけるのは禁止だが、画風の一貫性が崩れた動画を出すのも禁止。

## 1. 制作フロー全体図（7 STEP）

```
STEP1 ネタ決め
   ↓ テーマ＋一行ログライン
STEP2 脚本（10シーン・約1000文字）
   ↓ script.md
STEP3 画像プロンプト生成（10個）
   ↓ image-prompts.md（共通画風ブロック付与）
STEP4 Google Flow で画像10枚生成
   ↓ assets/img01〜10.png（16:9）
STEP5 AIナレーション生成
   ↓ assets/narration.mp3
STEP6 静止画スライド化（2〜3分）
   ↓ assets/ep0XX.mp4
STEP7 YouTube投稿
   ↓ 公開
```

**人間（社長）の確認は 2 点のみ**：
- ① 物語GO（STEP2 完了時 = 脚本の出来）
- ② 投稿GO（STEP6 完了時 = 動画の最終確認）
- それ以外は全自動で進める。確認待ちで止めない。

## 3. STEP4 Google Flow：画像10枚の一貫性をどう担保するか

Google Flow は同一プロジェクト内で画像生成を行うが、10枚の絵がバラバラの画風・別人の主人公になると絵本として破綻する。一貫性を **3点固定** で担保する。

### 3.1 一貫性の3点固定

| 固定項目 | やり方 |
| --- | --- |
| **① キャラ設定の固定** | 主人公の外見を脚本冒頭で「キャラシート」として文章固定する（年齢・髪型・髪色・服装・体型・特徴）。全プロンプトに同一文を貼る。例：`a 10-year-old Japanese boy, short black hair, round face, wearing a faded navy school uniform` |
| **② 画風の固定（共通画風ブロック）** | `episode-template.md` の「画風固定ブロック」を全10プロンプトの先頭に必ず付与。色調・タッチ・光・質感を統一 |
| **③ アスペクト比 16:9 固定** | 全画像 `--ar 16:9` 相当で生成。YouTube 横型に合わせ、後工程のトリミングを無くす |

### 3.2 生成の手順（Google Flow）

1. 新規プロジェクト「ep0XX_タイトル」を作成
2. `image-prompts.md` のプロンプトを **シーン1から順に**投入
3. 各シーンで 2〜4 枚出して、キャラの顔・服が前シーンと連続する1枚を採用
4. 主人公の顔が崩れた／別人になったシーンは、キャラシート文を強めて再生成（1シーンで最大3回まで。それ以上は粘らない＝Real Artists Ship）
5. 採用画像を `img01.png`〜`img10.png` にリネーム保存

### 3.3 一貫性が出ない時の割り切り

- 顔の同一性に固執しすぎない。**「同じ世界観・同じ画風」が保てていれば合格**とする
- どうしても破綻するシーンは、引きの構図（後ろ姿・遠景・手元・風景）に逃がす。絵本は主人公の顔を毎カット見せる必要はない

## 4. STEP5 AIナレーション 指針

### 4.1 ツール（本命1＋代替1）

| 区分 | ツール | 理由 |
| --- | --- | --- |
| **本命** | **ElevenLabs（日本語・Multilingual v2）** | 日本語の自然さ・感情表現・間が最も高い。落ち着いた語りに向く |
| 代替 | Google Cloud Text-to-Speech（Neural2 日本語） | 安定・低コスト。ElevenLabs が使えない/コスト超過時のフォールバック |

### 4.2 語りの仕様

| 項目 | 指定 |
| --- | --- |
| 言語 | 日本語 |
| 声質 | 落ち着いた・低めで温かい語り部（男女どちらでも可。チャンネルで1声に固定） |
| 読み速度 | やや遅め（標準の 0.9 倍程度）。感動は「間」で作る |
| 無音間 | シーンの変わり目に **0.8〜1.2 秒の無音**。クライマックス前は 1.5 秒 |
| 抑揚 | 説明調にしない。一文ずつ語りかける |

### 4.3 原稿の渡し方

- `narration.md` は **音声生成にそのまま投げられる形**で書く
- 間は改行（空行）で表現。読点で取りたい間は「、」、長い間は段落分け
- 数字・固有名詞は読み間違いが起きやすいので、ひらがな or カタカナで補助表記

## 5. STEP6 静止画スライド化 最小構成

> ここが「凝りすぎ禁止」の最重要ゾーン。最小構成で 2〜3 分を成立させる。

### 5.1 構成

| 要素 | 仕様 |
| --- | --- |
| 尺 | 2〜3 分（10シーン × 約13〜16秒） |
| 画面 | 16:9・1920×1080 |
| 動き | **Ken Burns 風の緩いズーム（可）**。各画像を 5% ゆっくりズームイン or パンするだけ。派手な動きは禁止 |
| トランジション | クロスフェード 0.5 秒のみ。1種類で統一 |
| 字幕 | ナレーション全文は出さない。**各シーンのキーフレーズ1行だけ**を下部に表示（読み手の負担を増やさない） |
| OP | タイトル＋「これはフィクションの物語です」明示 3 秒 |
| ED | チャンネル名「人生が変わる3分絵本」＋次回予告/チャンネル登録誘導 3 秒 |
| BGM | あらかじめ **3 曲だけストック**しておき、その中から選ぶ（探さない）。-20dB 程度、ナレーション時 -26dB |

### 5.2 尺配分（例：合計 2 分 50 秒）

```
00:00 OP（タイトル＋フィクション明示）           3 秒
00:03 シーン1〜3（導入：主人公と日常）          各15秒＝45秒
00:48 シーン4〜6（葛藤・どん底）                各15秒＝45秒
01:33 シーン7〜9（転機・挑戦）                  各15秒＝45秒
02:18 シーン10（救い・気づき）                  20 秒
02:38 余韻（無音1秒＋ナレ締め）                  9 秒
02:47 ED（チャンネル名＋登録誘導）               3 秒
合計 約 2:50
```

### 5.3 字幕デザイン（テンプレ固定・全話共通）

| 項目 | 値 |
| --- | --- |
| フォント | 太めのゴシック（源ノ角ゴシック Heavy 等）。可読性最優先 |
| サイズ | 56〜64pt |
| 位置 | 下から 12%・中央 |
| 色 | 白 #FFFFFF＋黒縁取り 4px＋ソフト影 |
| 表示 | キーフレーズのみ。フェードイン 0.3 秒 |

## 6. 1本あたり所要時間内訳（合計20〜30分に収める）

| STEP | 作業 | 所要 |
| --- | --- | --- |
| 1 | ネタ決め（ログライン1行） | 2 分 |
| 2 | ChatGPT 脚本生成 | 3 分 |
| ①物語GO | 人間確認 | （並行・カウント外〜2分） |
| 3 | ChatGPT 画像プロンプト生成 | 2 分 |
| 4 | Google Flow 画像10枚生成・選別 | 8 分 |
| 5 | ナレーション音声生成 | 3 分 |
| 6 | スライド化（テンプレに流し込み） | 7 分 |
| ②投稿GO | 人間確認 | （並行・カウント外〜2分） |
| 7 | YouTube メタ設定・投稿 | 3 分 |
| | **作業合計** | **約 28 分** |

- STEP6 がテンプレ化で安定すれば、20 分台前半まで短縮可能
- 画像の再生成に粘ると時間が爆発する。STEP4 は「1シーン最大3回・全体8分」を死守

## 7. リスクと対応

| リスク | 対応 |
| --- | --- |
| 主人公の顔が話の途中で別人になる | キャラシート文を全プロンプトに固定／崩れるシーンは引き構図に逃がす（§3.3） |
| 画像生成に時間が溶ける | 1シーン最大3回・STEP4 全体8分でタイムボックス |
| フィクションを事実と誤認される | OP と説明文で「フィクション」を毎回明示（禁則遵守） |
| ナレーションが棒読みに聞こえる | 速度0.9倍・間を改行で設計・本命 ElevenLabs を使う |
| BGM 探しで時間浪費 | 事前に3曲だけストック。動画ごとに新規探索しない |
| テーマがスベる | 凝らず本数を出し、再生数データで当たりを見極める（データゲーム） |
