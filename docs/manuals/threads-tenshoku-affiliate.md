# Threads × 転職アフィリエイト 実践マニュアル

> 出典：YouTube 動画（https://youtu.be/1r2xriBT1e8、話し手：定治）の文字起こし全文を、手順書として整理したもの。
> 収益額（「1日で100万円超」「月100万円」「今は月50万円を切る方が難しい」など）とフォロワー数・再生数は、話し手の自己申告で、検証していない。目標の目安として扱う。

---

## 0. このマニュアルのゴール

**Threads に仕事・転職の投稿をし、コメント欄に置いた無料の転職エージェントのリンクから登録してもらい、月10万円の報酬を得る。そのあと、月100万円まで伸ばす。**

| 目標 | 必要な成果件数（単価 8,000円で計算） |
| --- | --- |
| 月10万円 | 約13件／月（1日 約0.5件） |
| 月100万円 | 約125件／月（1日 約4件） |

比較：楽天アフィリエイトで月100万円を稼ぐには、5,000個以上売る必要がある。

仕組みは次の1行で表せる。

```
Threads 投稿 → コメント欄のリンク → 転職エージェントに無料登録 → ASP の承認 → 報酬
```

**転職の経験や専門知識はいらない。** 話し手によれば、転職を知らない人こそ狙い目。ただし、いきなり月100万円は無理で、段階を踏む必要がある。

## 1. なぜこの組み合わせなのか（判断材料）

### 転職ジャンルが稼げる3つの理由

| # | 理由 | 中身 |
| --- | --- | --- |
| 1 | 報酬単価が高い | 楽天・Amazon の美容・育児商品は1件100〜200円。転職案件は1件8,000円〜1万円超。月13件で10万円になる |
| 2 | 無料登録だけで成果になる | 転職エージェントは登録する人が無料。お金を払うハードルがないので、「とりあえず登録してみよう」となりやすい |
| 3 | Threads で伸びやすい | 「給料が上がらない」「残業がきつい」「将来が不安」といった共感される投稿が、Threads ではよく伸びる |

### なぜ今が穴場なのか

- Threads は主婦層（ママ）のユーザーが多く、発信者のほとんどが「楽天アフィリエイトをやりましょう」と言っている
- そのため、ASP の転職案件をやっている人はまだ少ない

### なぜ Instagram ではなく Threads なのか

| | Instagram | Threads |
| --- | --- | --- |
| 1投稿の手間 | 画像・動画作りで3〜4時間 | 文章だけ |
| フォロワー0のとき | ほとんど誰にも届かない | フォロワー以外にも届く仕組み |

話し手の実例：画像なし・文章だけで1日2〜3投稿。約1か月半でフォロワーが約5,000人に増え、100万再生を何度も出した。

## 2. 月10万円までの4ステップ

### ステップ1：ポジションとターゲットを決める

**ポジションとターゲット ＝ 誰に向けて発信するか。**

- [ ] 「転職したい人全般」を狙わない。広すぎて、刺さらない投稿ばかりになる
- [ ] 転職の中でも、さらにどんな人に向けるかを絞る

**今 Threads でおすすめのポジション（11個）**

1. 20代の年収アップ転職
2. 30代のキャリアチェンジ
3. 未経験から IT 業界への転職
4. ブラック企業からの脱出
5. ワーキングママの転職・復職
6. パパの転職
7. 第二新卒に特化した転職
8. 地方在住者のリモート転職
9. 40代のセカンドキャリア
10. 公務員からの転職
11. 転職 × 年収術

**選び方の軸：「自分が共感できるテーマ」×「転職したい人が多い」が重なるところ**

- 例：自分が20代なら「第二新卒に特化した転職」。共感できて、転職したい人も多い。続けやすく、ネタも思いつきやすい

**初心者に一番おすすめなのは、次の2つ**

| ポジション | 選ぶ理由 |
| --- | --- |
| 20代の年収アップ転職 | doda やマイナビの調査でも、転職者が一番多い年代は20代。案件が豊富で、報酬単価も高い |
| ブラック企業からの脱出 | 多くの人が一度は感じたことがある悩みで、共感されるテーマが多い |

**完了の目安**：プロフィール文に「誰に向けて」「何を発信するか」を1行で書けている。

---

### ステップ2：ASP に登録して案件を選ぶ

転職アフィリエイトは、楽天や Amazon と違い、**ASP**（いろいろな案件が入っている箱のようなサイト）に登録して使う。ASP には複数登録できる。

**登録する ASP（4つとも必ず登録）**：案件が豊富で、知名度があって安全だから。

- [ ] A8.net
- [ ] afb
- [ ] TCSアフィリエイト
- [ ] seedApp

**案件に提携するまでの手順**

1. ASP の中で「転職」と検索する
2. 出てきた転職案件の一覧から、条件に合うものを選ぶ
3. 「提携申請」を押す
4. 承認されたら、自分専用のリンクを発行する

**案件の選び方（2つとも満たすもの）**

1. **承認率70%以上**：報酬額だけで選ぶと危ない。承認率が10%なら、登録してもらえてもその10%しか報酬にならない
2. **知名度がある**：登録してもらいやすい。大手のサービスは報酬単価も高い傾向がある

**完了の目安**：条件を満たすメイン案件を1〜2つ決め、提携が承認されている。

---

### ステップ3：売れる投稿を作る（一番大事なステップ）

**投稿のネタは4種類だけ。「①認知＋②興味関心」を約7割、「③検索＋④行動」を約3割にする。**
この比率で投稿すると、フォロワーと信頼が積み上がり、着実に成約と報酬につながる。

| 種類 | 目的・読む人 | ネタの例 |
| --- | --- | --- |
| ① 認知 | アカウントを知ってもらう。まだ転職を考えていない人でも手が止まる「へえ」となる情報 | 業界の平均年収ランキング／転職で年収が上がりやすい職種ランキング／実は転職した方が得になる年代のデータ |
| ② 興味関心 | 転職を考え始めた人に「これ使えそう」と思わせる。再現できるネタで、足を止めた人を離さない | 転職で年収を50%上げた3つのコツ／転職エージェントの正しい使い方／面接で年収交渉を成功させる方法 |
| ③ 検索 | 紹介するエージェントについて調べたくさせる。そのエージェントに絞った実例 | doda を使って年収300万円から500万円になった方法／doda は何をしてくれるサービスかを分かりやすく解説／doda と他のエージェントを比べてみた |
| ④ 行動 | 迷っている人の背中を押す。登録直前の「面倒」「不安」を先回りして消す | doda の登録画面のスクリーンショットで3ステップ解説／「入力は名前と希望条件だけ、3分で終わる」と目安を示す／登録後すぐに来る電話で、実際にどんな連絡が来るかを先に伝える |

- 始めたばかりでアカウントが知られていないうちは、①認知の投稿を多めに入れる

#### ネタの探し方

**方法1：X で探す（定番）**

Threads の中だけでネタを探すと、他のアカウントと同じような投稿になって埋もれる。だから X を中心に探す。

1. X の検索窓に次のように入れる
   - `転職 min_faves:1000`
   - `年収 min_faves:1000`
   （そのキーワードを含み、いいねが1,000以上の投稿だけを出すコマンド）
2. 出てきた伸びた投稿の中から、まだ Threads に持ち込まれていないネタを先に拾う
3. Threads 向けに書き直す。**文章をそのまま写さない**

**方法2：Threads の競合アカウントを分析する**

1. Threads で「転職」「年収」と検索し、フォロワーの多いアカウントを見つける
2. 投稿をタップすると再生回数が見えるので、伸びた投稿を10個ほど選ぶ
3. 「なぜ伸びたのか」を分析する（例：ビフォーアフターが多い、データ系のネタ）
4. 見つけた傾向を自分の投稿に取り入れる

**完了の目安**：4種類それぞれの下書きが揃い、7:3 の比率で1週間分の投稿予定がある。

---

### ステップ4：アフィリエイトリンクを紹介文と一緒に貼る

稼げない人に共通するのは、紹介の仕方を間違えていること。ここを押さえれば、早い人は1か月以内に成果が出る（話し手の見立て）。

**リンクの置き場所**

- [ ] ASP の管理画面でリンクを取り、**Threads のコメント欄**に貼る
- [ ] **本文には貼らない**。アルゴリズム上よくなく、投稿自体が伸びなくなる

**投稿の中身と、紹介するものをそろえる**

- 本文と紹介する転職エージェントがずれていると、読み手の熱が冷め、リンクはタップされない
- NG 例：転職の準備についての投稿なのに、自己分析アプリを紹介する
- **この投稿を読んだ人が次に欲しいものを置く**

**紹介文は PASONA の法則で書く**

| 順番 | 書く内容 |
| --- | --- |
| 1. 問題 | 読み手の悩みを言葉にする |
| 2. 共感 | その悩みに寄り添う |
| 3. 解決策 | 何で解決できるかを示す |
| 4. 提案 | 具体的なサービスをすすめる |
| 5. 背中を押す | 行動のハードルを下げる |

動画の例文（コメント欄の最後に置く）：

> 給料が低くて悩んでいる人へ。私も同じ悩みがありました。
> そこで気づいたのが、転職エージェントに相談すれば、自分の市場価値に合った求人を紹介してもらえるということです。
> その中でも、1,000人の担当者が非公開求人まで無料で紹介してくれる doda を使うのがおすすめです。
> 完全無料で、登録は1分で済むので、ぜひ使ってみてください。

> ⚠ この例文をそのまま使わない。理由は2つ。
> - 「私も同じ悩みがありました」は、**本当に自分が経験したときだけ**使う。経験していないのに体験談として書くと、景品表示法に触れるおそれがある
> - 「1,000人の担当者」「登録は1分」はサービスについての事実の主張。**ASP の案件ページや公式サイトで確かめた数字だけ**を書く
>
> 詳しくは「6. 法令・規約」を参照。

**完了の目安**：すべての投稿のコメント欄に、PR 表記・本文とそろった紹介文・リンクが揃っている。

## 3. 月100万円まで伸ばす3つのコツ

### コツ1：伸びた投稿の型を量産する

伸びた投稿を、そのままにしない。

1. 伸びた投稿を分解し、**どんな悩み**に**どの型**で刺さったかをメモする
2. 構成は同じまま、切り口だけを変えた投稿を量産する
   → ゼロから作らなくていいので効率が上がる。もともと伸びた投稿がもとなので、また伸びやすい

**例**

伸びた投稿：
> 年収が上がらない人に共通する特徴3つ
> ① 今の給料に不満はあるけど、転職活動はしていない
> ② 年収の相場を調べたことがない
> ③ いつか異動で給料が上がるかもと思っている
> これ全部当てはまる人、5年後も同じ給料です

分解すると：
- **悩み**：「自分は年収が上がらないままなのでは」という不安
- **型**：「〇〇な人の特徴3選」で並べ、最後に警告の一言で締める

同じ型で切り口だけ変えた投稿：
> 転職で失敗している人に共通する特徴3つ
> ① とりあえず求人サイトを見るだけで終わる
> ② 今の会社の不満を言うだけで動いていない
> ③ 今より条件が悪くなったら嫌だと、一歩も踏み出せない
> これ全部当てはまる人、来年も同じ場所にいます

### コツ2：転職する人が増える時期に投稿を集中させる

転職を考える人の数は、時期によってかなり偏る。

| 時期 | 理由 |
| --- | --- |
| **1〜3月** | 年度末の退職と、4月入社に向けた転職活動が活発になる |
| **9〜10月** | 下期に向けた動きが重なり、転職を考える人が一気に増える |

→ この時期に投稿を集中させる。前の月に投稿を作りためておく。

**コツ1とコツ2を組み合わせれば、月10万円は十分狙える。** ただし、ここまでは1人で作る場合の限界で、報酬に天井がある。

### コツ3：AI で量産する仕組みを作る（月100万円に必須）

- 本業や育児がある中で、根性だけで投稿数とリサーチ時間を増やすのは難しい
- **投稿作り**と**リサーチ**を AI に任せる
  - 伸びた投稿のデータを AI に読ませ、勝ちパターンの投稿を量産させる
  - リサーチも自動化する
- 1アカウントにかかる時間が大きく減り、本業があっても複数アカウント・複数ジャンルを同時に回せる（話し手の例：1時間で5アカウント）

## 4. 毎日・毎週・毎月の運用チェックリスト

**毎日**
- [ ] 1日2〜3投稿する（4種類を 7:3 の比率で）
- [ ] コメント欄に PR 表記・本文とそろった紹介文・リンクがあるか確かめる

**毎週**
- [ ] 伸びた投稿を3つ選び、「どんな悩み×どの型」かを記録する
- [ ] 記録した型から、切り口だけ変えた投稿を量産する
- [ ] X（`min_faves:1000`）と Threads の競合で、新しい伸びた投稿を探す

**毎月**
- [ ] ASP の管理画面で、成果件数・承認率・報酬額を確かめる
- [ ] 承認率が70%を切った案件は差し替える
- [ ] 翌月が繁忙期（1〜3月・9〜10月）なら、投稿を作りためておく

## 5. よくある失敗

| 失敗 | 対策 |
| --- | --- |
| ターゲットが「転職したい人全般」 | ステップ1に戻り、1つのポジションに絞る |
| 報酬額だけで案件を選び、承認率を見ない | 承認率70%以上を先に確認する |
| 行動投稿ばかりで、宣伝の色が強すぎる | 認知＋興味関心を7割に戻す |
| Threads の中だけでネタを探し、他と同じ投稿になる | X の検索コマンドで、まだ持ち込まれていないネタを拾う |
| リンクを投稿の本文に貼る | コメント欄に移す |
| 投稿の中身と紹介する案件がずれている | 読んだ人が次に欲しいものを置く |
| 伸びた投稿の文章をそのまま写す | 型だけを取り出し、文章は自分で書く |
| 繁忙期に投稿が足りない | 前の月に作りためておく |

## 6. 法令・規約（動画では触れていないが、必ず守る）

- **PR 表記（ステマ規制）**：2023年10月から、広告であることを隠した宣伝は景品表示法違反になる。リンクがある投稿やコメントには、`#PR` や「広告」などをはっきり書く
- **ウソの体験談を書かない**：経験していない転職話や、盛った年収アップの数字（例：「300万円から500万円」）を、自分の事実として書かない。他人の事例を使うなら、出典を明らかにする
- **サービスについての数字は確かめる**：「担当者1,000人」「登録1分」「非公開求人」などは、案件ページや公式サイトで確かめたものだけを書く
- **ASP と案件の規約を読む**：SNS での宣伝が禁止されている案件や、使ってはいけない表現が決まっている案件がある。提携する前に確かめる
- **X の投稿を写さない**：ネタ（切り口）を参考にするのはいいが、文章をそのまま使うと著作権侵害になりうる
- **Threads の利用規約**：同じような内容の大量投稿や、複数アカウントの自動運用は、スパムとして判定されるおそれがある。AI で量産するときも、自動投稿ツールを使うかどうかは規約を確かめてから決める
- **確定申告**：会社員の副業で、所得が年20万円を超えたら確定申告が必要になる

## 7. 動画の最後の案内について

動画の最後は、公式 LINE で特典を配る案内だった（期間限定とのこと）。

- AI × Threads アフィリエイトの攻略動画
- Threads で稼げるジャンル100
- 自分のジャンルが決まるセルフ診断ツール
- Threads でよく売れる note ジャンル50選
- Threads で最も稼げる楽天の商品50選
- ジャンル別の伸びている投稿の型10選

このマニュアルの手順は、特典がなくても進められる。ただし、コツ3の「AI で量産する具体的なやり方」は、動画では説明されていない（特典の攻略動画に回されている）。
