# Threads × 転職アフィリエイト 実践マニュアル

> 出典：YouTube 動画（https://youtu.be/1r2xriBT1e8）を社長が要約した内容を、手順書として整理したもの。
> 収益額（「1日100万円超」など）は動画投稿者の自己申告で、検証していない。目標の目安として扱う。

---

## 0. このマニュアルのゴール

**Threads に仕事・転職の投稿をし、1通目のコメントに置いた無料の転職エージェントのリンクから登録してもらい、月10万円の報酬を得る。**

| 目標 | 必要な成果件数（単価 8,000円で計算） |
| --- | --- |
| 月10万円 | 約13件／月（1日 約0.5件） |
| 月100万円 | 約125件／月（1日 約4件） |

仕組みは次の1行で表せる。

```
Threads 投稿 → 1通目のコメントのリンク → 転職エージェントに無料登録 → ASP の承認 → 報酬
```

---

## 1. なぜこの組み合わせなのか（判断材料）

| # | 理由 | 中身 |
| --- | --- | --- |
| 1 | 報酬単価が高い | 物販アフィリエイトは1件100〜200円。転職案件は1件8,000〜10,000円超 |
| 2 | 成果が出やすい | ユーザーは完全無料で登録するだけ。お金を払うハードルがない |
| 3 | Threads と相性がいい | 給料・残業・将来の不安は共感されやすく、アルゴリズムで伸びやすい |
| 4 | ライバルが少ない | Threads は主婦層と楽天アフィリエイトが中心で、ASP の転職案件を本気でやる人はまだ少ない。文章だけで投稿でき、画像・動画を作る手間がない |

## 2. 月10万円までの4ステップ

### ステップ1：ポジションとターゲットを決める

- [ ] 「転職したい人全般」を狙わない。広すぎると誰にも刺さらない
- [ ] **「自分が共感できるテーマ」×「転職したい人が多い市場」** が重なる1つに絞る

**初心者向けのおすすめ**

| ポジション | 選ぶ理由 |
| --- | --- |
| 20代の年収アップ転職 | 転職者数が一番多い層 |
| ブラック企業からの脱出 | 多くの人が共感しやすい悩み |

その他の候補：未経験から IT、第二新卒、子育て中の親の転職、地方からのリモート転職、公務員からの転職。

**完了の目安**：プロフィール文に「誰に向けて」「何を発信するか」を1行で書けている。

---

### ステップ2：ASP に登録して案件を選ぶ

**登録する ASP（4つ）**

- [ ] A8.net
- [ ] afb
- [ ] TCSアフィリエイト
- [ ] seedApp

**案件の選び方（2つとも満たすもの）**

1. **承認率70%以上**：低いと、成果が未確定のまま報酬にならない
2. **有名な大手サービス**（doda など）：知られているので登録のハードルが低く、成約しやすい

**完了の目安**：条件を満たすメイン案件を1〜2つ決め、提携が承認されている。

---

### ステップ3：売れる投稿を作る

**投稿は4種類。「①認知＋②興味関心」を約7割、「③検索＋④行動」を約3割にする。**

| 種類 | 読む人 | 中身の例 |
| --- | --- | --- |
| ① 認知 | まだ転職を考えていない人 | データ系：平均年収ランキング、どの年代が得するか |
| ② 興味関心 | 転職を考え始めた人 | 誰でも再現できるノウハウ：年収を50%上げるコツ、エージェントの使い方 |
| ③ 検索 | 使うサービスを比べている人 | 具体的な事例と比較：doda で年収が上がった話、他社との比較 |
| ④ 行動 | 登録する直前の人 | 不安と面倒を先に消す：スクリーンショットで手順を解説、「登録は3分」、「電話が来る」ことを事前に伝える |

**ネタの探し方**

1. X で検索コマンドを使い、伸びた投稿を探す
   - `転職 min_faves:1000`
   - `年収 min_faves:1000`
   → 伸びた理由（切り口と構成）だけを取り出し、Threads 向けに書き直す。**文章をそのまま写さない。**
2. Threads の競合アカウントで、閲覧数が多い投稿を分析し、型を取り出す

**完了の目安**：4種類それぞれの下書きが揃い、7:3 の比率で1週間分の投稿予定がある。

---

### ステップ4：アフィリエイトリンクを紹介文と一緒に貼る

- [ ] リンクは **投稿の本文に貼らない**。**必ず1通目のコメント**に置く（本文にリンクがあると、アルゴリズム上不利とされる）
- [ ] 紹介文は **PASONA の法則** で組む

| 段階 | 書く内容 | 例文 |
| --- | --- | --- |
| 問題提起・共感 | 読み手の悩みを言葉にする | 「残業が多いのに給料が上がらない人へ」 |
| 解決策 | 何で解決できるかを示す | 「転職エージェントを使えば、市場価値に合った求人が見つかります」 |
| 提案 | 具体的なサービスをすすめる | 「非公開求人を無料で紹介してくれる doda がおすすめです」 |
| 後押し | 行動のハードルを下げる | 「完全無料・1分で登録完了」 |

> ⚠ 動画の例文は「私も同じでした」。**本当に自分が経験したときだけ**使う。経験していないのに体験談として書くと、景品表示法に触れるおそれがある（下の「6. 法令・規約」を参照）。

**完了の目安**：すべての投稿の1通目のコメントに、PR 表記・紹介文・リンクが揃っている。

## 3. 月100万円まで伸ばす3つのコツ

### コツ1：伸びた投稿の型を量産する

1. 伸びた投稿を分解する：**どんな悩み**に、**どの型**が刺さったのか
2. 型（構成）はそのままにして、切り口だけを変える
   - 例：「年収が上がらない人の特徴3選」 → 「転職で失敗する人の特徴3選」

### コツ2：転職の需要が高まる時期に投稿を集中させる

| 時期 | 理由 |
| --- | --- |
| **1〜3月** | 一番の繁忙期。年度末で辞めて、4月に入社する人が多い |
| **9〜10月** | 下期の採用に向けて、転職を考える人が急に増える |

→ この時期の前月に投稿の在庫を用意しておき、投稿の本数を増やす。

### コツ3：AI でリサーチと投稿作りを仕組みにする

- 1人で作業すると、時間と投稿数に上限がある
- **リサーチ**と**伸びた型からの投稿作り**を AI に任せる
- これで本業と両立しながら、複数アカウント・複数ジャンルを回せる（動画の例：1時間で5アカウント）

## 4. 毎日・毎週・毎月の運用チェックリスト

**毎日**
- [ ] 投稿する（4種類を 7:3 の比率で）
- [ ] 1通目のコメントに PR 表記・紹介文・リンクがあるか確かめる

**毎週**
- [ ] 伸びた投稿を3つ選び、「どんな悩み×どの型」かを記録する
- [ ] 記録した型から、切り口だけ変えた投稿を量産する
- [ ] X と Threads で新しい伸びた投稿を探す

**毎月**
- [ ] ASP の管理画面で、成果件数・承認率・報酬額を確かめる
- [ ] 承認率が70%を切った案件は差し替える
- [ ] 翌月が需要期（1〜3月・9〜10月）なら、投稿の在庫を積み増す

## 5. よくある失敗

| 失敗 | 対策 |
| --- | --- |
| ターゲットが「転職したい人全般」 | ステップ1に戻り、1つのポジションに絞る |
| 承認率を見ずに単価だけで案件を選ぶ | 承認率70%以上を先に確認する |
| 行動投稿ばかりで、宣伝の色が強すぎる | 認知＋興味関心を7割に戻す |
| リンクを投稿の本文に貼る | 1通目のコメントに移す |
| 伸びた投稿の文章をそのまま写す | 型だけを取り出し、文章は自分で書く |
| 繁忙期に投稿の在庫がない | 前月に在庫を用意しておく |

## 6. 法令・規約（動画では触れていないが、必ず守る）

- **PR 表記（ステマ規制）**：2023年10月から、広告であることを隠した宣伝は景品表示法違反になる。リンクがある投稿やコメントには、`#PR` や「広告」などをはっきり書く
- **ウソの体験談を書かない**：経験していない転職話、盛った年収アップの数字を事実として書かない
- **ASP と案件の規約を読む**：SNS での宣伝が禁止されている案件、指名検索が禁止されている案件、特定の表現が禁止されている案件がある。提携する前に確かめる
- **Threads の利用規約**：同じ内容を大量に投稿したり、複数アカウントを自動で運用したりすると、スパムとして判定されるおそれがある。AI で量産するときも、自動投稿のツールを使うかどうかは規約を確かめてから決める
- **確定申告**：副業の所得が年20万円を超えたら、確定申告が必要になる
