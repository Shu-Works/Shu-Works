## 1. なぜ「ギフト需要」を独立して育てるか

### 自己購入とギフト購入の違い

| 軸 | 自己購入（終活） | ギフト購入（贈答） |
| --- | --- | --- |
| 購入者 | ご本人（高齢） | お子様世代（40〜60 代） |
| Web リテラシー | 低い | **高い**（検索・SNS 利用） |
| 単価感覚 | コストに敏感 | **「特別な日」予算は緩い** |
| 購入決定 | 一人で熟考 | **家族で相談**（複数人で出し合うケースも） |
| 動機 | 自分の終末を整理したい | **「親孝行したい」** |
| 季節性 | 年中 | **明確なピーク**あり |

→ **ギフト需要は、より高単価・高頻度で動かしやすい市場**

### 市場規模の試算（参考）

- 日本の還暦祝い贈答市場：年間 **約 1,200 億円**規模（業界推計）
- 父の日・母の日ギフト市場：**約 2,000 億円**（合計）
- 敬老の日ギフト市場：**約 200 億円**

→ ニッチにシェアを取れば月数十万円規模の売上は十分視野に

## 2. ギフト需要の 3 つの軸

### 軸 A：長寿のお祝い（年齢節目）

| 年齢 | 名称 | 色 |
| --- | --- | --- |
| 60 歳 | 還暦 | 赤 |
| 70 歳 | 古希 | 紫 |
| 77 歳 | 喜寿 | 紫 |
| 80 歳 | 傘寿 | 金茶 |
| 88 歳 | 米寿 | 金茶 |
| 90 歳 | 卒寿 | 紫 |
| 99 歳 | 白寿 | 白 |
| 100 歳 | 百寿 | 金 |

- **季節性なし**（誕生月に集中）
- **計画的購入**が可能（半年〜1 年前から準備するケースも）
- **当社の中核ギフト需要**

### 軸 B：日本の年中行事ギフト

| 行事 | 時期 | 主な対象 |
| --- | --- | --- |
| 母の日 | 5 月第 2 日曜 | お母様 |
| 父の日 | 6 月第 3 日曜 | お父様 |
| 敬老の日 | 9 月第 3 月曜 | 祖父母・両親 |
| クリスマス | 12 月 25 日 | 家族全般 |

- **季節性ピークあり**（広告投下のタイミングが重要）
- **直前購入が多い**（高速納品オプションの活躍場面）
- **既存のプレゼント候補に飽きた人**を狙う

### 軸 C：人生の節目（結婚・出産・退職等）

| イベント | 主な対象 |
| --- | --- |
| 結婚式 | 新郎・新婦の親への感謝 |
| 退職祝い | 上司・先輩 |
| 喜寿・米寿同窓会 | 同窓会記念ムービー |
| 法人記念日 | 創業者・経営者 |

- **B2C より B2B 寄り**
- 別途、企業向け営業として開拓可能（後述）

## 3. ターゲット顧客像（ペルソナ）

### ペルソナ 1：「親孝行 40 代姉妹」

- 45 歳女性、夫と中学生 2 人と都市部マンション在住
- 父（68 歳）の古希祝いを 2 ヶ月後に控える
- 兄弟 3 人で予算 5〜10 万円を出し合い、特別な贈り物を探している
- 「モノは何でも持っている父に、何を贈ればいいか分からない」
- **Instagram で「古希祝い プレゼント」と検索**

### ペルソナ 2：「敬老の日に焦る娘」

- 38 歳女性、ワンオペ育児
- 9 月の敬老の日が近いことに 2 週間前に気づく
- 例年は子供から手紙を書かせていたが、今年は祖母が体調を崩していて特別な何かを贈りたい
- **「敬老の日 ギフト 特別」で慌てて検索**
- **高速納品オプション**が刺さる

### ペルソナ 3：「結婚式で両親へのサプライズ」

- 32 歳新婦、結婚式 1 ヶ月後
- 披露宴の余興として、両親の自分史ムービーを流すサプライズを企画
- 結婚式場のプランナーから「人生タイムラプス」を紹介される
- **B2B 経由（結婚式場提携）**で来訪
- 単価感覚は高め（プレミアム 7 万円 OK）

## 4. 価格戦略（ギフト需要）

### 基本方針：**ギフトは値引きしない**

- ギフトは「**値段の高さが価値**」になる側面がある
- 自己購入の方を「お得感」で集めつつ、ギフト需要は単価を維持

### ギフトパッケージのアップセル

| パッケージ | 追加料金 | 利益率 |
| --- | --- | --- |
| スタンダード（メッセージカード + 視聴リンク） | 0 円 | 既存 |
| プレミアム（桐箱 + DVD） | +3,000 円 | 約 70% |
| プレミアムプラス（桐箱 + 風呂敷 + 3 形式メディア） | +5,000 円 | 約 65% |

→ ギフト需要では **「プレミアム以上」を選ぶ率が高い**と想定

### お祝い金額の心理ライン

参考：長寿祝いの**ご祝儀相場**

| お祝い | 子から親 | 孫から祖父母 |
| --- | --- | --- |
| 還暦 | 3〜10 万円 | 1〜3 万円 |
| 古希 | 3〜10 万円 | 1〜3 万円 |
| 喜寿 | 3〜10 万円 | 1〜3 万円 |
| 米寿 | 5〜10 万円 | 1〜3 万円 |

→ 当社の **「スタンダード（39,800）+ プレミアムギフト（3,000）= 42,800 円」**は、子→親の予算感に合致

→ **兄弟 3 人で出し合う場合**：プレミアムプラン（74,800 円）+ プレミアムプラス（5,000 円）= 79,800 円 ≒ 一人 26,600 円という心理的に許容される単価に

## 5. 早期予約割引（先行予約特典）

長寿祝いは計画的購入が多いため、**「3 ヶ月以上前の予約で 5% OFF」**等の特典で予約を促進。

| 予約タイミング | 特典 |
| --- | --- |
| お祝い日の 3 ヶ月以上前 | 5% OFF |
| 2〜3 ヶ月前 | 通常価格（おすすめタイミング） |
| 1〜2 ヶ月前 | 通常価格（やや慌ただしい） |
| 1 ヶ月以内 | 高速納品オプション必須（+10,000 円） |

→ **早期予約特典は当社にもメリット**：制作スケジュールが平準化される

## 6. ご家族間連携サポート（独自価値）

ギフト需要特有の課題：**「本人に内緒で進めたい」**

### 当社のサポート内容
- **代表者 1 名がやり取り**（兄弟全員に毎回連絡しない）
- **ご本人に届かない範囲でのみ写真をやり取り**（ご本人のスマホは経由しない）
- **完成動画は当日まで秘匿**（オンラインリンクの発行タイミング指定可）
- **当社からのメールが「○○祝い」等のキーワードを含まないよう配慮**（うっかり本人に見られた時の対策）

### 兄弟複数名での協力
- 写真は兄弟複数人から集める可能性が高い
- 全員分の写真を Google Drive 案件フォルダで一元管理
- 「○○家 兄弟代表 □□様」として一人を窓口にしていただく

## 7. ギフト経由の B2B 提携先

### 結婚式場・ブライダル
- 新郎新婦から両親へのサプライズ商材として提案
- 提携モデル：紹介型 / 取次型（提案資料：別途、`b2b/06-bridal.md` として今後追加検討）

### 退職記念品メーカー
- 退職祝いの新商材として
- B2B 経由

### 法人記念品商社
- 創業者・経営者の記念ムービーとして
- 高単価が見込める

## 8. KPI（ギフト需要関連）

### 月次
- ギフト用途での問い合わせ件数
- 平均単価（プラン + ギフトパッケージ込み）
- 季節キャンペーン期間中の問い合わせ集中度
- 早期予約率（3 ヶ月以上前の予約 / 全予約）

### 年次
- ギフト用途売上の構成比（全売上に占める割合）
- 各長寿祝い年齢の受注件数
- 季節 3 大行事（父・母・敬老）の総売上

### 目標
- 半年後：ギフト用途売上が**全体の 30%**
- 1 年後：ギフト用途売上が**全体の 50%**
- 2 年後：季節キャンペーンが**月平均の 2 倍**を達成
