## 2. 各プラットフォームの詳細評価

### 2.1 楽天市場（★★☆☆☆）

#### メリット
- **国内 EC 最大手**、シニアでも利用率が高い
- 「楽天市場で買えば安心」というブランド信頼
- 検索流入が大きい（特に長寿祝いギフト）
- レビュー機能で他のユーザーの声を活用

#### デメリット
- **初期コスト・月額固定費が高い**（最低でも月 5 万円程度）
- 出店審査が厳しく、サービス系（無形商材）はハードル高
- **値引き競争に巻き込まれる**
- 楽天ポイント分のコスト負担
- 「楽天モール内の 1 ショップ」としての埋没リスク
- お客様情報が楽天 ID 経由となり、独自の顧客接点が築きにくい

#### コスト試算
| 項目 | 月額 |
| --- | --- |
| 出店料（がんばれプラン） | 19,500 円 |
| 月会費 | 約 16,500 円 |
| システム利用料 | 売上の 3.5〜6% |
| 楽天ポイント原資 | 売上の 1% |
| **合計** | **約 4 万円〜＋売上連動** |

→ 月 10 件の受注で 40 万円売上として、コストは 6〜8 万円
→ **「楽天で 10 件売る」のは初期は極めて困難**

#### 結論
- **事業初期は不向き**
- 月 20 件以上の安定受注が出てから検討（2 年目以降）
- まずは自社サイトと低コストプラットフォームで実績作り

---

### 2.2 Yahoo! ショッピング（★★★☆☆）

#### メリット
- **初期費用・月額固定費が無料**
- Yahoo! 検索からの流入
- 楽天より参入ハードルが低い
- 「PayPay モール」との連携で若年層〜中年層にもリーチ

#### デメリット
- 楽天より検索ボリュームが少ない
- 同様にお客様情報は Yahoo ID 経由
- 出品ジャンルとして「サービス・体験」が比較的弱い
- 競合との価格比較に晒される

#### コスト試算
| 項目 | コスト |
| --- | --- |
| 出店料 | 無料 |
| ストアポイント原資 | 売上の 1〜15%（任意） |
| キャンペーン原資 | 売上の 1.5% |
| 決済手数料 | 売上の 3〜3.5% |
| **実質** | **売上の 6〜10%** |

#### 結論
- **半年〜 1 年後の第二段階で検討**
- 出店試験運用として活用可
- 「楽天より先に Yahoo」がスタートアップ向けには合理的

---

### 2.3 ココナラ（★★★★★）

#### メリット
- **サービス系商材に最適化された日本最大手プラットフォーム**
- 個人クリエイター（写真復活本舗など）が既に「人生動画」を出品して実績多数
- 出品料・月額無料
- お客様レビューが信頼形成に寄与
- 「個人スタイル」と「事業者スタイル」両方の出品が可能

#### デメリット
- **手数料が高い（22%）**
- お客様との直接連絡が制限されている（基本はチャット）
- 独自ブランドが育ちにくい
- 大型受注（プレミアム）に向いていない側面

#### 採用方針
- **ライトプラン（19,800 円）を中心に出品**
  - お客様価格 19,800 円 → 当社受取 約 15,400 円（粗利 約 12,200 円）
- **スタンダード以上は自社サイトに誘導**
- ココナラは**「お試し・実績作り」のチャネル**として位置づけ

#### 出品テンプレ案（ココナラ）
```
タイトル：
たった10枚の写真から、AIで人生をたどる自分史ムービー制作します

サブタイトル：
還暦・古希・米寿・敬老の日に｜実写の写真が動き出す、世界にひとつの物語

カテゴリ：動画・アニメーション > 動画編集
価格：19,800 円（基本）／オプション設定で対応

サービス内容：
（gift.html / index.html の内容を簡潔にまとめる）
```

---

### 2.4 BASE（★★★★☆）

#### メリット
- **完全無料で自社ショップを開設可能**
- 独自ブランドで運営できる
- カスタマイズの自由度が高い（独自ドメイン設定可）
- 手数料も低水準（合計 6.6% + 40 円/注文）
- お客様情報を自社で持てる

#### デメリット
- 自分で集客しないと売上は立たない（モール集客力なし）
- お問い合わせフォームなど機能はシンプル
- 海外配送に弱い

#### 採用方針
- **「自社サイトと並走するもう一つの販売チャネル」として活用**
- 商品ページ URL を Instagram・note 等のリンク先として活用
- 決済機能（クレジット・コンビニ払い・後払い等）を自社サイトに組み込むより楽

#### 出品商品案（BASE）
- ライトプラン
- スタンダードプラン
- プレミアムプラン
- 各種オプション（想い出補完・ナレーション・高速納品）
- ギフトパッケージ（プレミアム / プレミアムプラス）

---

### 2.5 STORES（★★★☆☆）

#### メリット
- BASE と類似（無料 / 月額有料 のプランあり）
- 5% 手数料（無料プラン）と低めの設定

#### デメリット
- BASE と機能差が小さい
- どちらか一方で十分

#### 結論
- **BASE で十分。あえて両方使う必要なし**

---

### 2.6 自社サイト + Stripe / PayPay / 楽天ペイ（★★★★★）

#### メリット
- **手数料が最も低い（決済手数料 約 3.6% のみ）**
- 完全な独自ブランド
- お客様情報・データを自社で完全保有
- LP のデザイン自由度 100%

#### デメリット
- 集客は完全に自前
- 決済システムの構築・運用が必要
- 不正注文・チャージバックリスクへの対応

#### 構築の容易さ
- **Stripe** や **Square** で簡単に決済組み込み可能
- 既存の `contact.html` フォームに決済ステップを追加するだけで完結
- 数日で構築可能

#### 結論
- **メイン販売チャネルとして最重要**
- 自社サイトに来訪 → フォーム送信 → メール対応 → 後日決済リンク送付、という現状フローを継続

## 3. 段階別 EC 戦略

### Phase 1：開業〜半年
| チャネル | 役割 |
| --- | --- |
| **自社サイト**（contact.html） | メイン受注窓口（フォーム → 個別対応 → 後払い） |
| **ココナラ** | ライトプラン中心の集客チャネル・実績作り |
| **BASE** | SNS・note からのリンク先として活用 |

→ **月固定費：ほぼゼロ（決済手数料のみ）**
→ **コストリスク最小化、撤退も容易**

### Phase 2：半年〜 1 年
| 追加チャネル | 役割 |
| --- | --- |
| **Yahoo! ショッピング** | 試験出店、Phase 1 と並行 |
| **B2B 経由** | 葬儀社・写真館経由の安定流入 |

→ **月固定費：1 万円以内**

### Phase 3：1 年〜 2 年
| 追加チャネル | 役割 |
| --- | --- |
| **楽天市場（要再検討）** | 売上が月 60 万円超なら検討 |
| **自社サイトの強化**（カート機能追加） | 自社決済比率を上げる |

→ **月固定費：5〜10 万円**（楽天分）

## 4. ココナラ出店の具体的アクションプラン

### Week 1：出店準備
- [ ] ココナラアカウント作成（事業者プロフィール作成）
- [ ] サンプル動画 2〜3 本を YouTube 限定公開で準備
- [ ] サンプル画像（メッセージカード等）を撮影
- [ ] 出品ページ原稿作成（gift.html を流用）

### Week 2：出品開始
- [ ] ライトプラン（19,800 円）を出品
- [ ] オプション設定（ナレーション・高速納品・想い出補完）
- [ ] 価格戦略：**最初の 5 件は 15,000 円特価**で実績作り

### Week 3〜4：流入施策
- [ ] Twitter/X、Instagram で「ココナラ出品しました」告知
- [ ] note でサービス紹介記事執筆（ココナラへの導線）

### Month 2 以降：運用最適化
- [ ] レビューが 5 件以上溜まったらサムネ・タイトル最適化
- [ ] 上位表示を狙うキーワード対策（「自分史 動画」「還暦祝い ギフト」等）

---

## 5. BASE 出店の具体的アクションプラン

### Week 1：構築
- [ ] BASE アカウント作成
- [ ] 独自ドメイン設定（gift.example.jp 等のサブドメイン推奨）
- [ ] ショップデザイン（既存サイトと統一感）
- [ ] 各プラン・オプションを商品として登録
- [ ] 決済方法設定（クレジット・コンビニ・PayPay 等）

### Week 2：連動
- [ ] index.html / gift.html から BASE 商品ページへのリンク追加
- [ ] 「カートでお支払いをお済ませください」フロー作成
- [ ] Notion 案件管理ボードと BASE 受注の連携ルール策定

## 6. EC 全体の月次運用負担

| プラットフォーム | 月次運用時間 |
| --- | --- |
| 自社サイト + 個別対応 | 5 時間（既存運用） |
| ココナラ | 3 時間（受付・チャット対応） |
| BASE | 2 時間（受注処理） |
| **合計** | **10 時間/月** |

→ **本業を持ちながらでも十分にこなせる範囲**

---

## 7. リスクと対応

| リスク | 対応 |
| --- | --- |
| ココナラで価格競争に巻き込まれる | スタンダード以上は出品せず、自社サイトに誘導 |
| BASE で集客できない | あくまで「決済窓口」と割り切り、集客は自社サイト・SNS で |
| 楽天/Yahoo の手数料が想定より高い | 出店前に詳細試算、撤退ルールを事前に決める |
| プラットフォーム規約変更 | 半年ごとに規約・手数料の見直し |

## 8. 結論まとめ

### ✅ 早期に始める
- **自社サイト**（既存・継続強化）
- **ココナラ**（ライトプラン中心、実績作り）
- **BASE**（決済窓口、SNS リンク先）

### 🔄 半年〜 1 年後に検討
- **Yahoo! ショッピング**（試験出店）

### ⏳ 1 年〜 2 年後に再評価
- **楽天市場**（売上 60 万円超なら検討）

### ❌ 当面は出店しない
- Amazon、Creema/minne、メルカリ Shops

→ **「自社サイト＋ココナラ＋ BASE」**の 3 軸で、月固定費ほぼゼロで開始可能。
事業成長に応じて段階的にチャネルを増やすのが最適。
