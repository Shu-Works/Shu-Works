# 施設様向け：別添 ご説明書

> パンフレットとは別に、施設の管理職様・スタッフ様向けの説明資料を別途お渡しします。

## 施設様にお願いしたいこと

1. **パンフレットの設置**
   - 玄関ロビー、面会室、相談室など、ご家族の目に触れる場所への設置
   - 月 1 回程度の補充（在庫は当社から無料で配送）

2. **ご相談者へのお取り次ぎ**
   - ご利用者様・ご家族から相談された場合、当社のメールアドレスをご案内ください
   - 当社から直接ご連絡し、対応します

3. **【任意】施設名のスタンプ追加**
   - パンフレット裏面の「ご紹介ありがとうございます」欄に施設様のスタンプを押印いただくと、ご紹介経由として識別できます

## 施設様へのご還元

| 内容 |
| --- |
| ご紹介経由で成約した案件について、**成約金額の 15% を施設様へ還元** |
| もしくは、**施設様の催事用ムービー制作を 1 本無料**でご提供（季節のレクリエーション動画、施設紹介ムービー等） |
| **ご還元方法は、施設様のご希望に応じて選択可能**です |

## 施設運営の負担にならない仕様

- 受注・制作・納品・修正対応は**すべて当社が直接ご家族と行います**
- 施設様の事務作業はパンフレット設置のみ
- ご利用者様・ご家族のプライバシーは当社が責任を持って保護
- 制作風景の撮影や、施設名の宣伝利用は一切いたしません（ご希望される場合のみ実施）

# 地域包括支援センター向け 追加メッセージ

地域包括支援センター様には、以下の追加価値をご提供できます。

### 1. 高齢者向け「終活」相談の充実
- 「自分史を残す」というテーマで、終活相談の幅を広げられます
- エンディングノートと並ぶ、新しい終活の選択肢としてご紹介可能

### 2. ご家族からの相談に応える商材
- 「親に何かしてあげたい」と相談されるご家族に、具体的な選択肢を提示できます

### 3. 地域連携（介護施設・葬儀社等）の媒介
- 当社の B2B ネットワーク（介護施設・葬儀社）と地域包括との橋渡しが可能
- 地域包括支援センター様の地域連携機能を補完

### 4. 公的利用への配慮
- 公的機関へのご紹介でマージンを受け取れない場合、**完全無料での情報提供**も可能
- 「業務提携」ではなく「**情報提供協力**」というスタンスで連携可能
