## スライド 6：コラボの種類

ご希望に応じて、以下から選択いただけます。

### Type A：**ミニ講演型**（推奨）
- 既存セミナーの 20〜30 分枠で登壇
- 集客は御社が実施
- 当社マージン：成約金額の 85%、御社マージン：15%

### Type B：**共催イベント型**
- 「終活＋人生動画」をテーマに、共催でイベント企画
- 集客・会場費は折半 or 別途協議
- 当社マージン：成約金額の 70%、御社マージン：30%

### Type C：**講師派遣型**
- 御社のクライアント企業・自治体での終活セミナーに、当社が講師派遣
- 当社マージン：成約金額の 70%、御社マージン：30%＋講師派遣手数料

### Type D：**動画コンテンツ提供型**
- 御社のオンライン講座に、当社の解説動画を提供
- 当社マージン：成約金額の 80%、御社マージン：20%

# 終活セミナー業界の特性 — 注意点

### 信頼性を最重視
終活市場は **「胡散臭い業者」** への警戒心が強い領域です。以下の表現は絶対に避けます：

| NG 表現 | OK 表現 |
| --- | --- |
| 「AI で故人を蘇らせる」 | 「写真の歩みを動画として残す」 |
| 「終活ビジネスチャンス」 | 「終活の選択肢の拡充」 |
| 「儲かる」「収益化」 | 「お客様の満足度向上」「セミナー価値向上」 |
| 「最新テクノロジー」 | 「写真の世界を、新たな形で」 |

### 公的・準公的セミナーへの対応
- 自治体・社会福祉協議会・地域包括支援センター主催のセミナーは、**マージン受取不可**の場合があります
- その場合は「**地域貢献として無償提供**」の姿勢で対応します
- 「収益目的でない情報提供」として、信頼を獲得することを優先

### 同業・競合の登壇
- FP・士業の方は中立性を重視されるため、**当社サービスのみを推奨することへの抵抗**があります
- 解決策：「**動画化サービスの一例として**」と紹介いただき、他社例も併記する形でご了承いただく
- 結果的に当社が選ばれるかは、サンプル動画の品質次第
