# メールテンプレート集

**作成日**: 2026-05-26
**対象**: 写真受付システム運用時のお客様向けメール
**利用方法**: Gmail のテンプレート機能（旧「返信定型文」）に登録して使用

各テンプレートの `〔〕` 部分を案件ごとに置換してください。

## テンプレ登録時の注意

### Gmail のテンプレート機能の有効化

1. Gmail を開く
2. 右上の歯車アイコン → 「すべての設定を表示」
3. 「詳細」タブ → 「テンプレート」を有効
4. 新規メール作成画面の右下「︙」→「テンプレート」→「下書きをテンプレートとして保存」

### 件名は必ず案件番号付きで統一

「【人生タイムラプス】〇〇〇〇（〔JT-XXXX-XXXX〕）」の形式で統一しておくと、
お客様側もメール検索しやすく、当社側も Gmail 検索で案件履歴を一覧化できます。
