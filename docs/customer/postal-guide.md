## 4. お写真の梱包方法

大切なお写真を傷つけないために、以下のようにご梱包ください。

### 必須
- アルバム・封筒・専用ケース等に入れたまま発送いただいて構いません
- 緩衝材（プチプチ／ティッシュ）で挟んで折れを防止
- ジッパー付き袋に入れて湿気から保護（雨天時の配送事故対策）

### 推奨
- 折れ・曲がりが心配な場合は段ボールに薄い板を入れて補強
- 大量の写真の場合は、おおまかな年代別にクリアファイルで分けていただくと、当社での作業が早くなります（必須ではありません）

---

## 5. 紛失・破損が心配な場合の対策

### A. 事前にスキャン or スマホ撮影をしておく
スキャナやスマホで複製を作成しておけば、万一の事故でも復元できます。
ご家庭のスキャナでも 300 dpi 以上で取り込めば動画用途には十分です。

### B. 原本ではなくコピーを送付する
コンビニ（セブンイレブン・ローソン等）の写真コピー機能を利用すれば、1 枚 30 円程度で複製できます。
当社では複製でも動画化が可能ですので、特に貴重な原本はお手元に残してください。

### C. 当社の補償について
当社は、お預かりした写真の物理的な滅失・損傷について、当社の故意または重大な過失による場合に責任を負います。配送中の事故は、配送業者の補償範囲となりますので、補償付きの配送方法をお選びください。

---

## 6. 受領・返送について

### 受領後の流れ
1. お写真到着後、当日中にメールにて受領確認をご連絡します
2. 受領確認メール内に、お預かりした写真の枚数・状態を記載
3. 万一不足や破損があった場合、ご相談させていただきます

### 返送について
- 完成動画の納品後、**30 日以内** にご返送いたします
- 配送方法：**レターパックプラス**（追跡可能・対面受取・送料当社負担）
- 返送後、追跡番号をメールでお知らせします

# B. 社内向け「郵送受付・返送チェックリスト」

> 写真が郵送で届いた際の標準作業手順

---

## B-1. 受領時チェックリスト（到着当日に実施）

### 受領作業
- [ ] 配送方法と追跡番号を案件カードに記録
- [ ] 外装の損傷有無を撮影記録（万一のクレーム対応用）
- [ ] 開封し、同梱の写真送付チェックシートを確認
- [ ] 実際の写真枚数を概算カウント
- [ ] チェックシート記載と実枚数に大きな差異がないか確認

### 受領後すぐの対応
- [ ] 案件専用の保管箱（密閉可・防湿）に格納
- [ ] 保管棚の所定位置に置き、案件 ID 札を貼付
- [ ] 受領写真の全体を上から 1 枚撮影（後の枚数確認用）
- [ ] 「写真受領確認メール」（テンプレ 4 番）を送信

### Notion 案件カードを更新
- [ ] ステータス：「写真受領済み」
- [ ] 受領日付・受領方法・写真枚数を入力
- [ ] 配送追跡情報のスクショを添付

## B-2. スキャン作業

### 推奨機器
- A4 フラットベッドスキャナ（**Epson DS-C480W** 等、約 4 万円）
- または ScanSnap iX1600（高速・両面対応・約 6 万円）

### スキャン設定
| 項目 | 推奨値 |
| --- | --- |
| 解像度 | 600 dpi（古い小さな写真）／300 dpi（一般用） |
| カラー | カラー（モノクロ写真もカラーモードで取り込み、後で補正） |
| 形式 | PNG または高品質 JPEG |
| ファイル命名 | `JT-2026-XXXX_001.png` から連番 |

### 保存先
- Google Drive の `02_受領写真_郵送スキャン/` フォルダ
- スキャン完了後、原本は元の保管箱に戻す

## B-5. 配送事故時の対応フロー

### 受領前の事故（お客様 → 当社の発送中）
1. 配送業者（日本郵便等）への調査依頼
2. お客様への状況報告
3. 補償交渉のサポート（補償書類記入支援）
4. 再送が難しい場合は契約のキャンセル可（料金全額返金）

### 返送中の事故（当社 → お客様の返送中）
1. 配送業者への調査依頼
2. お客様への謝罪・状況報告
3. 補償交渉
4. 当社の責任範囲内で誠意ある対応（賠償・お見舞い金等）
