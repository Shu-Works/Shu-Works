# 人生タイムラプス ～あなたの自分史を、動画で残す～

## プロジェクト概要

「人生タイムラプス」は、終活を進める高齢者の方や、長寿のお祝い（還暦・古希・喜寿・傘寿・米寿など）を迎えるご家族のための、**自分史ムービー制作サービス**です。

幼少期から現在までのお写真をお預かりし、AI と専門編集者の手で時系列に整えた **タイムラプス形式の動画** に仕上げてお届けします。一枚一枚の写真がなめらかに流れることで、ご本人の人生そのものが「一本の物語」として浮かび上がります。

## 当サービスの差別化ポイント

**「写真を並べるだけ」では、誰でも作れます。** 私たちが提供するのは、その先の体験です。

| 一般的な「思い出ムービー」 | 人生タイムラプス |
| --- | --- |
| 止まった写真がパッパッと切り替わるスライドショー | **一枚一枚の写真が AI で動き出す**（微笑む・まばたき・ゆっくりズーム） |
| BGM に合わせて並べるだけ | **「5歳 七五三」「20歳 成人式」「60歳 還暦」** など、人生の節目を字幕で明示 |
| 機械的に順番に流すだけ | 編集者が **物語のリズム**（章立て・余韻・BGM の起伏）で人生を一本の物語に編む |

### 核心技術：「動き × 編集」方式
- お預かりするのは **基本すべてご本人の実写写真**（基本プランでは AI による顔の改変は行いません）
- 各写真に AI で **自然な動き**（3〜5 秒の微動）を与え、止まっていた瞬間を生き返らせます
- 写真間の時間の流れは、**章立て字幕・トランジション・BGM の物語編集**で表現
- 条件の合う写真同士（年齢差が小さく撮影条件が近い場合）に限り、AI トランジションでなめらかに接続

> 改訂メモ（2026-07）：旧版の「写真と写真の間を AI が補間する」方式は、実機検証の結果、
> 年齢差の大きい写真間では品質が成立しないことが判明したため、上記方式に再設計しました。
> 詳細：`docs/production/02-ai-bridging.md` v2.0

### 想い出補完オプション（別料金）
高齢の方は、戦中戦後・経済的事情・家族の事情などで「**写真が残っていない時期**」があることが少なくありません。
そうした空白を埋めるため、**実存する前後の写真から AI が当時の姿を想像生成する**オプションをご用意します。
- 「もし写真が残っていたら、こんな姿だったかも」というご本人・ご家族との対話から制作
- 動画内では **「想い出補完シーン」と分かる演出**（淡い色調・コーナーに「memory」マーク等）を施し、実写と AI 補完を明確に区別
- ご本人・ご家族の事前確認を経た上で組み込みます（同意なしには絶対に挿入しません）

## サービスの背景

- 高齢化社会の進展により、「自分の人生をかたちに残したい」という終活ニーズが高まっています。
- 一方で、長寿のお祝いには「モノ」より「想い出」を贈る傾向が強まっています。
- アルバムは場所を取り、見返す機会も限られますが、動画なら家族・親族で何度でも共有できます。
- スマホ・タブレット・テレビで気軽に視聴でき、葬儀・法要・記念パーティーでも活用可能です。

## サービス内容（制作フロー）

1. **写真のお預かり**：紙焼き写真は郵送、デジタル写真は専用アップローダーで受付
2. **デジタル化・補正**：色あせ・キズの補正、AI による高解像度化
3. **時系列の整理**：年代別に並べ替え、ご本人・ご家族へのヒアリングで人生の節目を確認
4. **AI で写真を動かす**：一枚ずつに自然な動き（微笑む・まばたき・ズーム）を AI で付与
5. **チャプター演出・物語編集**：「○歳 入学式」など節目の字幕と、章立て・トランジションで人生を一本の物語に
6. **BGM・ナレーション**：思い出の曲や、ご本人/ご家族の語りを挿入
7. **品質確認・最終編集**：専門編集者が一本の物語として整える
8. **納品**：DVD／Blu-ray／USB／オンライン視聴リンクから選択可能

## 組織図（AI 会社）

本事業は、人間 CEO（社長）＋ **AI CEO（Steve Jobs）＋ 4 名の AI 部長**で運営されます。
社長は厳密モードで **AI CEO Jobs とだけ対話**し、Jobs が部長を統率します。

```
              ┌──────────────────┐
              │ CEO（人間／社長） │
              └────────┬─────────┘
                       │ ← 対話はここだけ
              ┌────────┴─────────┐
              │ AI CEO Jobs       │
              │ （経営判断・統括）│
              └────────┬─────────┘
                       │ ← Task tool で召喚
    ┌──────────┬───────┴───────┬──────────┐
    ▼          ▼               ▼          ▼
┌────────┐ ┌────────┐ ┌──────────────┐ ┌──────────┐
│接客部長│ │制作部長│ │営業・マーケ部長│ │管理部長  │
└────────┘ └────────┘ └──────────────┘ └──────────┘
```

各 AI 社員の役職定義：`.claude/agents/`
