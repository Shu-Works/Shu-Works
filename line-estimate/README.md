## 1. プロジェクト概要（工務店プラン）

**サク索くん｜工務店プラン** は、従業員10名以下の小規模工務店のために開発された、LINE上で動く"スマート右腕AI"です。

過去の見積書・請求書・図面・現場写真などを AI が学習し、社長や職人さんが**普段使い慣れたLINE**に話しかけるだけで、必要な情報を瞬時に取り出します。新しいアプリのインストールも、複雑な操作も不要です。

### サービスのコア機能

| アイコン | 機能名 | 概要 |
| --- | --- | --- |
| 🔍 | **見積検索** | 「山田健一の見積もりは？」と聞くだけで、金額・工期・施工内容を即答 |
| 📷 | **写真日報** | 現場写真を送るだけで AI が日報を自動作成し、案件別に整理 |
| 🎙 | **音声議事録** | 打ち合わせの録音をアップすると、要点・宿題・期限を自動で抽出 |
| ❓ | **質問・FAQ** | 「足場の単価いくらだっけ？」など社内ナレッジに即時アクセス |

## なぜ小規模工務店なのか

### 業界の課題

- **書類が散乱**：PDF・Excel・紙が混在し、過去案件の見積もりを探すのに毎回30分〜1時間
- **属人化**：社長の頭の中にしか情報がなく、社長不在時に現場が止まる
- **事務員不在**：10名以下の工務店では事務専任者を置く余裕がなく、社長や奥様が兼務
- **高齢化**：60〜70代の職人さんが多く、複雑なクラウド業務システムは敬遠される
- **既存ITツールへの不信**：「導入したけど誰も使わなかった」という過去の挫折経験

### 「LINE」だからこそ解決できる理由

- 日本の工務店業界での **LINE 普及率は実質100%**（協力会社・施主との連絡もLINEが主流）
- 新しいアプリのダウンロード・ログインが不要
- 高齢の職人さんも家族との連絡で日常的に使っている
- 現場・移動中・休憩中、いつでも片手で操作できる
