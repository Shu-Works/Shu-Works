# サク索くん｜小規模工務店のためのLINE見積もり検索AI

「山田さんの見積もり、いくらだったっけ？」
— 現場の職人さんが、**LINEで一言聞くだけ**で答えが返ってくる。
そんな"右腕"のような存在を、10名以下の小規模工務店向けにお届けするサービスです。

---

## プロジェクト概要

**サク索くん（さくさくくん）** は、従業員10名以下の小規模工務店のために開発された、LINE上で動く"スマート右腕AI"です。

過去の見積書・請求書・図面・現場写真などを AI が学習し、社長や職人さんが**普段使い慣れたLINE**に話しかけるだけで、必要な情報を瞬時に取り出します。新しいアプリのインストールも、複雑な操作も不要です。

### サービスのコア機能

| アイコン | 機能名 | 概要 |
| --- | --- | --- |
| 🔍 | **見積検索** | 「山田健一の見積もりは？」と聞くだけで、金額・工期・施工内容を即答 |
| 📷 | **写真日報** | 現場写真を送るだけで AI が日報を自動作成し、案件別に整理 |
| 🎙 | **音声議事録** | 打ち合わせの録音をアップすると、要点・宿題・期限を自動で抽出 |
| ❓ | **質問・FAQ** | 「足場の単価いくらだっけ？」など社内ナレッジに即時アクセス |

---

## なぜ小規模工務店なのか

### 業界の課題

- **書類が散乱**：PDF・Excel・紙が混在し、過去案件の見積もりを探すのに毎回30分〜1時間
- **属人化**：社長の頭の中にしか情報がなく、社長不在時に現場が止まる
- **事務員不在**：10名以下の工務店では事務専任者を置く余裕がなく、社長や奥様が兼務
- **高齢化**：60〜70代の職人さんが多く、複雑なクラウド業務システムは敬遠される
- **既存ITツールへの不信**：「導入したけど誰も使わなかった」という過去の挫折経験

### 「LINE」だからこそ解決できる理由

- 日本の工務店業界での **LINE 普及率は実質100%**（協力会社・施主との連絡もLINEが主流）
- 新しいアプリのダウンロード・ログインが不要
- 高齢の職人さんも家族との連絡で日常的に使っている
- 現場・移動中・休憩中、いつでも片手で操作できる

## 利用イメージ

```
👷 職人「山田健一の見積もりは？」

🤖 サク索くん「山田 健一 様宛てのお見積もり内容は以下の通りです。
   ・工事名称：山田様邸 外壁・屋根塗装工事
   ・見積金額（税込）：¥1,122,000
   ・見積日：2025年6月1日（EST-2025-0601）
   ・工期：2025年7月14日〜8月8日（約18日間）」
```

社長が現場にいなくても、奥様がパソコンを開かなくても、
**過去の案件情報が誰でも・どこからでも・即座に**引き出せます。

## 目標

### 短期目標（〜6ヶ月）
- LP公開と公式LINEアカウント開設
- 試験導入工務店 **10社** を獲得（無料モニター）
- 見積検索精度 90% 以上を達成
- 商工会議所・地域工務店組合との連携 3団体

### 中期目標（〜1年）
- 有料契約 **100社** 達成
- 写真日報・音声議事録機能の本リリース
- 建材商社・職人マッチングサービスとの提携によるリード獲得チャネル確立
- MRR（月次経常収益） **70万円**

### 長期目標（〜3年）
- 有料契約 **1,000社**、MRR **800万円**
- 全国の小規模工務店の "標準ツール" としてのポジション確立
- 業界特化AI（建築用語・職人言葉）の独自モデル開発
- 同業種（電気工事・水道工事・板金など）への横展開

- **主要ペルソナ**：従業員2〜10名の地域密着工務店の経営者（50〜65歳）
