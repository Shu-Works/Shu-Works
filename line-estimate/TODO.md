## 🛡 知的財産・商標（5契約獲得後に着手）

> 日本は **先願主義**（先に出願した者勝ち）。模倣ブランド防止のため、5契約見えた段階で即出願する。

### Phase 1：事前調査（5分・無料）

- ☐ J-PlatPat（https://www.j-platpat.inpit.go.jp）で類似商標調査
  - ☐ 「サクサクくん」
  - ☐ 「サク索くん」
  - ☐ 「Shu Works」
  - ☐ 「シュウ ワークス」
- ☐ 競合商標が無いことを確認 → 出願可否判定

### Phase 2：商標出願（タイミング：6月の5契約獲得後）

- ☐ 出願方針決定：自力 or 弁理士依頼
  - **自力出願**：1区分 ¥12,000＋登録料 ¥32,900 = 約 **¥45,000／件**
  - **弁理士依頼**：上記＋手数料 ¥6〜10万円 = 約 **¥11万円／件**
- ☐ 区分選定（候補）
  - 第9類：ソフトウェア・モバイルアプリ
  - 第42類：SaaS・クラウドサービス
  - 第35類：経営コンサルティング（事務サポート版（BackOffice）用）
- ☐ 出願書類作成・特許庁へ提出
- ☐ 審査結果待ち（通常 6〜12ヶ月）
- ☐ 登録完了 → ®マーク使用開始

### Phase 3：継続管理

- ☐ ロゴが完成したら、ロゴ商標も別途出願検討
- ☐ ドメイン名（sakusaku-kun.com / shu-works.co.jp）は取得済みのため放棄禁止
- ☐ 10年ごとの更新管理（カレンダー登録）
- ☐ 海外展開時：マドリッド協定加盟国に国際出願検討

### 著作権（自動発生・出願不要）

- ✅ LP・利用規約・契約書・スライド・キャラ画像はすべて **自動的に著作権発生**
- ☐ AI 生成物の著作権整理（ChatGPT 名刺・Codex リッチメニュー等の権利帰属確認）
- ☐ 重要素材は GitHub 等で **作成日タイムスタンプ** を残す（証拠保全）
