## 4. リッチメニュー（画面下のボタン）

LINE Manager → リッチメニュー → 作成

### サイズ：大（2500×1686px）4分割

スクショで見たレイアウト：左右2×上下2 の4ブロック。

| 位置 | アイコン+テキスト | アクション |
| --- | --- | --- |
| 左上 | 🔍 見積検索 | テキスト「見積検索」を送信 |
| 右上 | 📷 写真日報 | テキスト「写真日報」を送信 |
| 左下 | 🎙 音声議事録 | テキスト「音声議事録」を送信 |

CEOで Canva 等で作成 or 俺がドラフト案を作る。

- 背景：LINE グリーン（#06C755）グラデ

- フォント：「Noto Sans JP Bold」

## 5. タグ・セグメント設定

LINE Manager → 設定 → タグ管理

将来の配信を分けるため、最初から3タグだけ作っておく：

| タグ名 | 用途 |
| --- | --- |
| `見込み顧客` | 興味あり返信があった人 |
| `モニター契約済` | 5社の開発パートナー |
| `一般契約済` | 6社目以降の通常顧客 |

→ 商談化したら手動で `見込み顧客` を付与。契約締結で `モニター契約済` に昇格。

---

## 6. Push 通知ポリシー（月200通 無料枠）

開発パートナー5社が運用に乗ったら、配信が増える。**枠を節約する設計**：

| 配信タイミング | 頻度 | 月通数（5社想定） |
| --- | --- | --- |
| 取込完了通知 | 顧客ごと1回 | 5通 |
| 月次サマリ | 月1回 | 5通 |
| 新機能リリース | 必要時のみ | 0〜5通 |
| 障害・メンテ通知 | 必要時のみ | 0〜10通 |
| **小計** | | 約 25〜35通／月 |

→ **無料枠200通の中に余裕で収まる**。
→ 10社まで増えても無料枠OK。10社超でStandard プラン（¥5,000/月）検討。
