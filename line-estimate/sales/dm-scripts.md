# サク索くん（サクサクくん）Instagram DM スクリプト集（コールド対応）

> サービス名の読み方：**サク索くん**＝「サクサクくん」と読みます。
> DM 初出時は **「サク索くん（サクサクくん）」** と必ず両方表記してください。

> 知人ゼロからの初回アプローチ用。すべてコピペで使えるよう、変数（[ ]部分）のみ
> 差し替えて送信できる形式で記述。
> Day 1 から200社にこのスクリプトで届ける。

---

## 使い分けの原則

| パターン | 対象 | 返信率予想 |
| --- | --- | --- |
| **A：施工事例褒め型** | 施工事例を頻繁に投稿している社長 | 20〜25% |
| **B：課題直撃型** | 投稿は少ないが、地域密着で活動しているアカウント | 12〜15% |
| **C：限定オファー型** | 法人アカウント、または1社目で結果を見せられる段階 | 8〜12% |

**初期100社は A:B = 70:30 で配分。** C は地域カバー完了後の追撃に温存。

## パターンA：施工事例褒め型（コア）

施工事例の投稿に【先に "いいね"】 → 翌日DM、の2段構え。

```
[社長名]様

突然のメッセージ失礼いたします。
サク索くん運営事務局の[CEO名]と申します。

[社長名]様の[具体的な投稿内容：例 "○月○日投稿の和室リフォーム"]、
[具体的に何が良いか：例 "障子の桟の収まりが本当にきれいで"]、
拝見していて勉強になりました。

実は弊社、小規模工務店さま向けに
「過去の見積もりをLINEで一言聞くだけで検索できる」AIを
開発しており、6月末まで【先着10社限定】で開発パートナーを
募集しています。

通常 月額29,800円のところ、お試し3ヶ月は14,800円。
それも合わなければ4ヶ月目に解約していただいて構いません。

15分だけ、画面共有でデモをお見せする時間、
いただけないでしょうか？

押し売りは一切いたしません。
「うちには合わない」と思われたら、その場で
お止めいただいて結構です。

ご検討いただけますと幸いです。

──────────────────
サク索くん（サクサクくん）運営事務局
[CEO名]
[メール] / [電話]
──────────────────
```

### 「具体的に何が良いか」の表現サンプル
- 写真撮影の構図の良さ「真上からの構図、図面みたいで分かりやすいです」
- 文章の読みやすさ「お施主様への配慮が文章から伝わります」
- 仕事の丁寧さ「下地処理の写真まで上げる工務店さん、なかなかいらっしゃらない」
- 地域への愛「『○○市で○○年』のフレーズ、地元への思いが伝わります」

→ **必ず投稿を3〜5本見てから書く。**「素晴らしいですね」だけはNG（テンプレ感が出る）。

## パターンB：課題直撃型

投稿数が少ないアカウント・反応が読みづらい相手向け。短く本題に入る。

```
[社長名]様

はじめまして。
サク索くんの[CEO名]と申します。

突然で恐縮ですが、1つだけお聞かせください。

「過去の見積もりを探す」のに、
毎月、どれくらいの時間使っていますか？

弊社は、その時間を【ほぼゼロ】にする
LINE 上の AI を開発しています。

「山田さんの見積もりは？」とLINEで聞くだけで、
3秒で答えるサービスです。

現在、先着10社で開発パートナーを募集中。
月額14,800円・初期費用14,800円・3ヶ月のお試し制です。

少しでもご興味あれば、15分でデモをお見せします。
ご不要なら「不要」とだけご返信ください、
それ以上ご連絡しません。

──────────────────
サク索くん（サクサクくん）運営事務局
[CEO名]
──────────────────
```

### このパターンの強み
- 「不要なら不要と返信ください」のフレーズで **断る心理ハードルを下げる**
- 質問形式 → 返信率が上がる（人は質問されると返したくなる）
- 短い → 忙しい社長に読まれる

## 送信ペースとリスク管理

### Instagram の規約・スパム判定回避
- **1日あたり最大 20件**（新規DM）
- 同じ文章をそのまま使わず、**毎件 [社長名]・[投稿内容]・[評価部分] を必ず差し替える**
- 連続送信はせず、1件送ったら5〜10分空ける
- 朝（9-11時）・昼（13-15時）・夕（17-19時）に分散させる

### 5日間で100社のスケジュール
- 月：20件
- 火：20件
- 水：20件
- 木：20件
- 金：20件
- 計 100件

### CEO の時間配分
- 朝20分：10件送信＋返信対応
- 夜30分：10件送信＋商談日程調整
- 計 1日 50分。週10時間の制約内に収まる

## 想定 NG パターン（やってはいけない）

| NG | 理由 |
| --- | --- |
| 同じ文章を一斉送信 | Instagram のスパム検知に引っかかる |
| 「無料です」と虚偽の文言 | 信頼を一発で失う |
| 1日30件以上の送信 | アカウントBAN リスク |
| 営業時間外の送信（21時以降） | 嫌われる |
| 投稿のない相手にA型を送る | 「適当に送ってる」と即バレ |
| 何度もしつこいリマインド | ブロックされる、悪い口コミの種 |
