## 使い方ガイド

### 商談（Zoom / 訪問）での進め方

| 時間 | やること | スライド |
| --- | --- | --- |
| 0:00〜0:02 | 自己紹介・アジェンダ説明 | #1 表紙 |
| 0:02〜0:05 | 御社の現状ヒアリング（質問のみ） | スライドなし |
| 0:05〜0:08 | 業界の典型課題を提示 | #2 |
| 0:08〜0:12 | 解決アプローチ＋コア機能 | #3 #4 |
| 0:12〜0:18 | デモ（実際の LINE 画面で見せる） | スライドなし |
| 0:18〜0:22 | ROI 説明 | #5 |
| 0:22〜0:25 | 開発パートナー条件 | #6 |
| 0:25〜0:27 | 拡張性 & 法人化の説明 | #7 |
| 0:27〜0:29 | 次のステップ | #8 |
| 0:29〜0:30 | クロージング | #9 |

### メール送付時
- PDF化して送付（PowerPoint をそのまま送らない）
- 件名：「【サク索くん】開発パートナー資料のご送付」
- 本文には資料の見どころを3行で
- 開封後24時間以内に「ご感想いかがでしたか？」フォロー

### Instagram DM フォロー時
- スライド1の画像だけ送る → 「もっと詳しい資料ご覧になりますか？」
- 興味反応あればフル PDF 送付
