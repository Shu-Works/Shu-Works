# サク索くん｜工務店プラン 申込書（請書）

> 工務店経営者が「請書」と聞いて慣れている形式で、A4 1枚で完結する申込書テンプレ。
> 顧客がメールで返送するだけで契約成立する設計。

## 3. 顧客返信後の手順

### Step 1：契約成立メール送付（30分以内）

```
件名：【サク索くん】契約成立のご連絡＆お振込ご案内

[社長名]様

ご返信ありがとうございます。
本日付で開発パートナー契約 成立とさせて
いただきます。

【契約番号】SK-PARTNER-2026-XXXX

つきましては、初月分（初期費用＋月額）の
お振込のご案内です。

─────────────────────
お振込金額：[金額]（税抜）
　内訳：
　　初期費用 ¥14,800
　　1ヶ月目  ¥14,800

お振込先：
　[銀行名] [支店名]
　[預金種別] [口座番号]
　名義：Shu Works　ミズノ ヒデヒコ

お振込期限：契約日から7営業日以内
─────────────────────

お振込確認後、データ取込のご案内を
別途お送りします。
3営業日以内に検索可能な状態でお渡しします。

引き続きどうぞよろしくお願いいたします。
```

## 5. 既存契約書テンプレ（contract-template.md）との関係

| 用途 | 使うファイル |
| --- | --- |
| シンプルな申込・営業時の標準 | **本ファイル（application-form.md）** ⭐ |
| より詳細な契約条項が必要な場合 | `contract-template.md`（13条構成） |
| 詳細権利義務の参照 | `https://sakusaku-kun.com/terms.html`（利用規約） |

→ **通常は本申込書で進める**。契約書スタイルは要望時のみ提示。
