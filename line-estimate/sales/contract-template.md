# サク索くん（サクサクくん）開発パートナー契約書（モニター契約）

> サービス名「サク索くん」の読みは **「サクサクくん」** です。
> 契約書本文では正式名称「サク索くん」を使用し、メール送付時の冒頭で
> 「読みはサクサクくんです」と一言添えてください。

> 本テンプレートは、開発パートナー先着10社向けのモニター契約書です。
> モニター期間中は **メール上での合意をもって契約成立**とし、電子サインツール不要で運用します。
> 4ヶ月目以降の正規移行時に、必要に応じて GMOサイン等の電子契約に切り替えます。

## 契約書本文

```
─────────────────────────────────────
サク索くん 開発パートナー契約書

【契約番号】SK-PARTNER-2026-XXXX
【契約日】 　 2026年○月○日
─────────────────────────────────────

サク索くん運営事務局（以下「甲」）と、
[正式社名] （以下「乙」）は、以下の通り
「サク索くん」サービスの開発パートナー契約を締結します。


第1条（目的）
本契約は、甲が提供する LINE 上の業務支援AIサービス
「サク索くん」（以下「本サービス」）について、
乙が開発パートナーとして導入・利用することに関する
条件を定めるものです。


第2条（契約期間）
1. 契約期間：契約日から 12ヶ月間（自動更新）
2. うち、モニター期間（1〜3ヶ月目）は途中解約不可とします
3. 4ヶ月目以降は、解約希望月の前月末までに通知することで
　 翌月末日をもって解約可能とします


第3条（料金）

【契約プラン】

  サク索くん｜工務店プラン（開発パートナー価格）
     ・初期費用：¥14,800（通常 ¥49,800 から 70%OFF）
     ・月額料金：¥14,800／月（通常 ¥29,800 から 50%OFF）

【将来オプション】
　 サク索くん｜事務サポート版（BackOffice）は、2026年後半リリース予定。
　 リリース時は別料金にて追加可能とし、開発パートナーの乙には
　 優先導入権・先行案内を付与します。
　 具体的な料金・条件はリリース時に別途書面（メール可）でご案内します。

【価格据え置き保証】
　 ★ 上記特別価格は、契約期間中ずっと永続適用されます。
　 　 値上げや、契約更新時の料金変更はありません。

【支払方法】
　モニター期間中：銀行振込（月末締・翌月10日支払）
　4ヶ月目以降　：銀行振込 または クレジットカード（Stripe）

【消費税】
　上記金額はすべて税抜表示です


第4条（提供機能と上限）

本サービスは以下の機能を提供します：

  ✓ 見積データ検索（LINE上で過去見積を即座に検索）
  ✓ 写真日報（現場写真からAIが日報を自動作成）
  ✓ 音声議事録（打ち合わせ録音から要点を抽出）
  ✓ 質問・FAQ（社内ナレッジへの即時アクセス）

【ご利用上限（モニター期間）】

| 項目 | 上限 |
| --- | --- |
| 見積データ保管 | 200件 |
| 写真日報 | 月30件 |
| 音声議事録 | 月10件（1件30分以内） |
| ユーザー数 | 5名 |
| ストレージ | 5GB |

上限を超える場合は、超過分の追加オプションをご案内します。


第5条（開発パートナー特典）

乙は開発パートナーとして、以下の特典を受けます：

  ✓ 乙の要望を優先的に機能開発へ反映
  ✓ 甲の公式サイト「導入事例」ページに乙のロゴ・社名掲載
  ✓ 新機能を一般リリースの2週間前に先行利用
  ✓ 四半期に1回の優先要望ヒアリング（甲の代表が対応）
  ✓ 業界向けセミナー登壇時に「導入事例」として乙を紹介
  ✓ 「サク索くん認定 IT先進工務店」バッジを贈呈
　　（乙の名刺・HP等への掲載可）
  ✓ 2026年後半リリース予定の **サク索くん｜事務サポート版（BackOffice）**
　　（経理・人事・総務向け）の先行案内・優先導入権


第6条（取込データの取扱い）

1. 取込対象データ
　 過去見積書（PDF・Excel・紙の写真含む）、
　 現場写真、議事録音声、社内マニュアル等

2. 取込完了の保証
　 200件以内の見積データは、契約から3営業日以内に
　 検索可能な状態でご提供します

3. データの所有権
　 取込データの所有権は乙に帰属します
　 甲はサービス提供目的でのみ使用します

4. データの返却・削除
　 解約時は、乙の希望に応じて30日以内に
　 全データを返却（CSV形式）または完全削除します


第7条（個人情報・機密保持）

1. 甲は乙から預かるデータを業務目的以外に使用しません
2. 第三者への提供は乙の事前同意なく行いません
3. データは暗号化された状態で保管し、
　 アクセスログは1年以上保管します
4. 万一の情報漏洩時は、24時間以内に乙へ報告します


第8条（サービスレベル）

1. 稼働率目標：99.0%以上（月間）
2. 計画停止：原則月1回まで、土日深夜帯に限定し
　 事前に72時間前までに通知します
3. 障害発生時の連絡先：info@shu-works.co.jp
　 営業時間内（平日9〜18時）2時間以内に一次対応します


第9条（フィードバック義務）

開発パートナーとして、乙は以下にご協力いただきます：

  ✓ 月1回（30分程度）のZoomチェックイン
  ✓ 四半期に1回の要望ヒアリング
  ✓ サービス改善のためのアンケート回答（年4回程度）

これらは契約期間中の最低限の協力事項です。
（タダ働きをお願いするものではなく、優先要望反映の権利として
　位置付けます）


第10条（契約解除）

以下の場合、相手方への通知をもって契約を解除できます：
  - 重大な契約違反があった場合
  - 当事者の経営破綻・解散
  - 反社会的勢力との関係が判明した場合


第11条（契約承継）

甲（Shu Works）は2026年7月中に Shu Works株式会社へ法人化を予定しています。
本契約は、法人化完了をもって自動的に Shu Works株式会社へ承継されます。
乙の追加同意は不要とし、甲から書面（メール可）にて通知します。
なお、契約条件・料金・特典・契約期間に変更はありません。


第12条（合意管轄）

本契約に関する一切の紛争は、
東京地方裁判所を第一審の専属管轄裁判所とします。


第13条（その他）

本契約に定めのない事項は、両当事者が誠実に協議の上、
書面合意のうえで解決します。

─────────────────────────────────────
```
