# 1️⃣ クラウドワークス用

## 自己紹介文（300字版）

```
中小企業の事務を熟知する立場から、
AI による業務自動化システムを実装しています。

「立派なシステム」を作る人ではなく、
「現場で本当に使われる小さな仕組み」をデザインすることを得意としています。

私自身が "毎日業務を回す側" だったからこそ、
何を自動化すべきかが感覚的にわかります。

【コアメッセージ】
あなたが学ぶのではなく、
AIが御社の業務を学びます。

【得意領域】
・経理業務の自動化（請求書一括生成・メール文面自動化）
・LINE 公式アカウント × AI Bot
・社内文書検索AI（RAG / Vector Search）
・OCR + 構造化（請求書・見積書・伝票）

【納品形式の特徴】
✓ HTML / JavaScript ローカル完結（情報漏洩リスク最小）
✓ サーバー不要・追加コストなし
✓ ZIP1つで納品・コピペで動作

【こだわり】
・「使えるもの」しか納品しません
・進捗を週1回以上ご報告
・運用後のサポートも丁寧に
```

## サービスタイトル候補（5パターン）

```
1. 【経理担当の救世主】請求書発行・メール文面 一括自動化システム
2. 中小企業の月末経理 地獄を AI で完全自動化します
3. 御社の業務を AI が学ぶ「業種特化AI」を構築します
4. LINE × AI Bot 構築【業務を知る人が作る】
5. ローカル動作で安心・社内文書検索AIを構築
```

```

【返信目安】24時間以内
```

# 🛡 5つの地雷源（動画から・実践指針）

| # | 地雷 | 対策 |
| --- | --- | --- |
| 1 | 最初から企業案件を取りに行く | **個人事業主・小規模ECオーナーに絞る**。機密保持・支払スパンが複雑な大企業案件は実績作ってから |
| 2 | 特定環境だけでしか動かない設計 | **HTML/JavaScript ローカル完結**で納品。クライアント環境依存を最小化 |
| 3 | 納品後のサポートを「無料・無制限」 | **サポートチケット制 or 期間制限**。7日間無償→以降課金 |
| 4 | 実績前に値上げする | **最初は信頼の貯蓄期間**。3〜5案件で実績作ってから段階的に値上げ |
| 5 | AI 丸投げで自分の確認怠る | **必ず自分で動作確認**してから納品。クライアントPCでテスト |
