# 💡 マスク原則的に正しい姿勢

> 原則4-1：スケジュールが長いなら、それは間違っている

```
✗ 「半年勉強してから案件を取る」
✅ 「案件取りながら、必要な技術を学ぶ」
```

最初は **粗くてもいい、出荷する**。
1件目の経験が、2件目を10倍速くする。

> 原則5-1：完璧主義より、出荷主義

```
✗ 「完璧な LINE Bot を作ってから納品」
✅ 「動くものを納品 → フィードバックで改善」
```
