# 🏭 The Coloring Book Factory

A repeatable, scalable system for producing and selling high-quality printable
adult coloring books on **Etsy** and **Payhip**.

This is not a coloring book. It's a factory — a documented workflow that produces
**2 books/week, 50 pages each**, designed as series and packaged into bundles to
build a compounding digital asset library.

## How to use this repo

Work through the files in order. Files 01–05 set strategy & pick the niche;
06–09 produce and quality-check the book; 10–12 list it and plan bundles. To make
the next book, repeat the loop with a new niche from `03_Top10_Niches.csv`.
